# AI老汤·Skill工坊 4.1.0：对话创建与改进版

安装整个方法包，或者在支持Skill的客户端导入看板下载的`.skill`文件，然后说“帮我做个Skill”或“这个方法不好用，帮我改”。
具体导入按钮依学校配置的客户端而定，本包不假设固定安装目录。客户端不支持安装时，可以把SKILL.md正文作为本次对话的方法说明使用。

包内包含：SKILL.md、方法模板、对话示例、本说明与来源元信息。无必装脚本或第三方CLI。
先澄清当前任务，再给样稿，通过典型任务修正；老师决定是否分享。
文件生成、ZIP导出是客户端可选能力；没有时交付完整可复制正文，不冒充实际生成文件。
技术检查与模拟走查不证明每个客户端都安装成功，也不代表教育效果。

本版从4.0.0-S整理为自包含对话版。原工程版的缺失脚本不再被当作本包能力；未经核清许可的第三方内容不能由此获得再分发授权。
