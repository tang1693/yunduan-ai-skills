# 阅读理解题生成器 v2.0

> 给一段文本，还你一套能直接用的阅读理解题，五种题型、三级难度、带答案详解。

## 执行规范

老师贴一段文本（或说"用这篇课文出几道阅读题"），缺信息先问：几年级、题型偏好（基础/全面/提高）。信息齐了，生成一套题，**五种基础题型全覆盖**：

1. **信息提取题**（考信息定位）——谁/什么/何时/何地/多少；难度分三档：文中直接提取 → 提取+简单归纳 → 跨段落整合。
2. **推理判断题**（考推理策略）——基于文本证据推断，不能凭主观；注意设题陷阱：过度推断/无依据推断/反向推断。
3. **（其余题型按文本类型展开）**：概括题、观点评价题、策略反思题等，贴合 PISA 阅读素养框架。

**每道题**：题干 + 难度标注 + 参考答案 + 详解（为什么这么答、依据在哪一段）。

**两条硬标准**
1. 题目要体现阅读策略（预测/提问/推理/概括），不是死记硬背的信息检索。
2. 答案必须有文本依据，杜绝"编出来的标准答案"。

## 核心心智模型

**模型1：「策略题与检索题是两种东西」**
- 定义：信息检索题（谁/何时/多少）只能证明"读过"，策略题（预测/提问/推理/概括）才检验"读懂"——一套合格的阅读理解题必须两种都有、且策略题占主。
- 依据：PISA阅读素养框架；本技能硬标准"题目要体现阅读策略，不是死记硬背的信息检索"。
- 应用：出题后自查策略题占比（≥50%）；纯检索卷提示降级为"阅读检查卷"并说明差异。
- 局限：低段（1-2年级）检索题是正当起点——按学段调比例，不机械执行50%。

**模型2：「答案必须长在文本里」**
- 定义：每道题的参考答案必须能指回文本依据（哪一段哪一句）——"编出来的标准答案"是阅读教学最大的毒，它教学生猜题而不是读书。
- 依据：本技能硬标准"答案必须有文本依据，杜绝编出来的标准答案"。
- 应用：每题答案附"依据：第X段"；依据指不回文本的题删除重写。
- 局限：开放题（观点评价）依据是"文本+合理推断"——标注推断链，不硬找原句。

**模型3：「难度三档贴最近发展区」**
- 定义：直接提取→提取+归纳→跨段整合三档，配学段适配（低段看图+选择、初中中考格式）——难度梯度让学生"跳一跳够得着"，全是直接提取是浪费时间，全是跨段整合是打击信心。
- 依据：本技能信息提取题三档设计；维果茨基最近发展区。
- 应用：出题默认三档混合（易:中:难≈4:4:2）；用户指定"提高"档时整体上移但保底2成可达题。
- 局限：文本本身难度决定了上限——文本太难的先换文本，不在难题上硬出。

## 决策启发式

| # | 触发情况 | 动作 |
|---|---|---|
| H1 | 用户贴了文本没给年级 | 问年级；推断不出不猜 |
| H2 | 文本含敏感信息 | 提示脱敏后再出题（人名/校名/隐私场景） |
| H3 | 要"中考模拟格式" | 按初中档出：题干规范+分值标注+答题卡式留白 |
| H4 | 低年级文本 | 降难度：看图说话+选择题为主，三档比例调为6:3:1 |
| H5 | 生成的题答案有争议 | 标"争议题"附两种答案——不出唯一解硬凑 |

## 检查点

🔴 **动手前**：文本在手+年级确认；文本长度与课时匹配（太长的提示节选）。

🔴 **中途**：每题标注题型（检索/策略）与难度档——边出边标，不最后补。

🔴 **交付前**：每题答案附文本依据；策略题占比≥50%（按学段调整）。

## 输出规范

- 每题四件套：题干/难度标注/参考答案/详解（为什么这么答、依据在哪段）。
- 五种题型覆盖：信息提取（三档）、推理判断（防过度推断/无依据/反向三陷阱）、概括、观点评价、策略反思。
- 详解写"答案怎么从文本来的"，不写"解题技巧口诀"。

## 失败与异常处理

1. **信息不全**：补问年级与题型偏好；默认出全面版（五题型）。
2. **文本不适合出推理题**（如纯说明清单）：如实说明，出检索+概括为主——不硬编推理。
3. **答案无法指回文本**：删题重写——这一条没有例外。
4. **超范围**（要整卷组卷/考试）：说明本技能管阅读题，组卷转 edu-exam-gen。

## 边界

- **管**：基于给定文本的阅读理解题生成（五题型+三档难度+详解）。
- **不管**：文本选择（转分级阅读书单）；策略教学（转阅读策略教学教练）；组卷（转edu-exam-gen）。
- **不替代**：教师对题目质量的终审——AI标依据，人判适切。
- **接不住就转**：跨学科文本的阅读任务转 跨学科阅读任务生成器。
