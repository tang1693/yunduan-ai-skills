# 文献综述 Skill · v2.0

## 一句话启动

打开就说「**写文献综述**」，不用先描述格式。

## 核心心智模型

**模型1：综述是"研究地图"，不是"文献清单"**——综述的功能是画出一片研究领域的地形图（哪里是共识高原、哪里是分歧峡谷、哪里是空白荒原），为自己的研究定位。罗列"张三说、李四说"的流水账没有地图功能。依据：文献综述的论证功能定位；评审"综述像记账本"的高频批评。应用：每段综述段末必须有一句"评"——这批文献合起来说明了什么/没说明什么。局限：背景性综述（学位论文第一二章）允许更大比例的梳理，但仍需评述性小结。

**模型2：主题聚类优先于时间顺序**——按研究主题/流派/方法聚类组织，时间脉络只在主题内部呈现。依据：认知负荷理论（读者按主题检索）；时间流水账掩盖了学术对话结构。应用：框架设计先做主题聚类表（主题×代表文献×核心结论×分歧点），再扩写成文。局限：学科史类综述（如"XX研究三十年"）以时间为主线是合理的，主题作副线。

**模型3：空白是从分歧与不足里长出来的**——"前人没研究过"不是空白，"前人研究了但存在X不足/分歧在Y未决/方法有Z局限"才是有说服力的空白。依据：研究缺口的论证逻辑；"无人研究"式空白在评审眼里往往意味着"没查全"。应用：点空白段按"不足→缺口→本研究切入点"三步走，每步有文献支撑。局限：真正的开创性领域（无前人）用实践需求与应用价值替代文献空白论证。

## 决策启发式

1. **近5年为主体，经典单列**——教育类综述近5年文献占70%以上；奠基性经典（如某概念的原始提出）单独成段呈现。
2. **每个论断带来源**——无来源的说法不写入综述；用户未提供的文献只按已给信息组织，缺口标"待补检索"。
3. **呈现"共识—分歧—空白"三层**——只写共识的综述是教科书，三层俱全才是研究地图。
4. **述评比例不低于3:1**——每三四句"述"配一句"评"；全述不评等于没消化。
5. **综述的落脚点是自己的研究**——最后一段必须回答"所以本研究做什么、为什么非做不可"。

## 执行规范

老师说"帮我写文献综述"即可。缺信息先问：什么研究方向、综述用途（课题申报/论文/开题）、手上已有哪些文献。信息齐了，按三步走：

1. **搭框架**：按主题聚类组织（不按时间流水账）——核心概念界定 → 国外研究脉络 → 国内研究现状 → 已有研究的不足 → 本研究的切入点。
2. **填文献**：每一段观点标注来源（作者/年份），找不到出处的说法不写入；呈现"共识—分歧—空白"三层，而不是文献罗列。
3. **点空白**：综述的价值在最后一段——前人没做什么、做得不够的是什么、本研究为什么恰好补这个缺口。

**格式规范**：参考文献格式按用途适配（课题申报按申报要求，期刊投稿按目标期刊格式）。

## 检查点

🔴 **动手前**：确认文献池——用户手上有多少篇、覆盖哪些主题；缺口先列"待补检索清单"，不用AI编文献凑数。

🔴 **中途**：框架定稿前做一次"主题聚类表"自检——每个主题下至少2篇支撑，单篇孤证的主题合并或标注证据薄弱。

🔴 **交付前**：最后一段空白论证三步齐全（不足→缺口→切入点）；缺切入点的是半成品。

## 失败与异常处理

1. **用户手上的文献太少（<10篇）**：先出"检索策略与检索式"（数据库/关键词组合/纳入排除标准），让用户补检索后再写，不硬写。
2. **文献之间结论打架**：这正是综述的素材——呈现分歧本身（两派各自的方法差异可能是分歧根源），不强行调和。
3. **用户要求"帮忙找文献"**：AI 给检索式与数据库建议，检索与下载是用户在图书馆/数据库做的事；AI 不编造"已检索到"的条目。
4. **查重压力**：转述改写指导（换句式/换主语/归纳多篇合一），但核心观点转述仍需标注来源——降重不降学术诚信。

## 边界与提醒

- **不编造文献**：AI 不能虚构作者、期刊、年份；用户没提供的文献只用其给出的信息组织，缺口如实标注"待补检索"。
- 文献的时效性：教育类综述近5年文献应占主体，经典文献单独呈现。
- 查重口径：综述是"述+评"，复制比高的段落要重写为自己话的转述。
- **不替代**：系统检索与文献管理（EndNote/Zotero）——AI 组织与写作，检索与核对是作者的责任。
- **接不住就转**：综述写完要投稿，润色转 edu-polishing；申报书里的综述章节转 课题申报书/edu-research-project。
