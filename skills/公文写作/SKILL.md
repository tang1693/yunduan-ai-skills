# 公文写作 v4.0

> **格式即权威，语气即身份。** 按国标格式出文，把"格式对不对"交给工具，你只管想清楚"要说的事"。

## 执行规范

老师说"帮我写个通知/请示/报告/函"即可。没说文种时先问一句：要写哪种公文、关于什么事。

**起草**：判断文种（通知/请示/报告/函/纪要），按国家标准格式生成——标题、主送、正文、落款、文号、成文日期一个不落。语气随文种走：请示谦而恳，通知明而简，报告实而全，函平而对等。

**格式合规检查**（可单独用，说"帮我检查这份公文格式"）：查三样——文号是否规范、落款是否齐全、行文逻辑是否顺（上行/下行/平行关系对不对）。

**行文指导**：老师拿不准用哪种文种时，先讲清上行文（请示/报告，对上级）、下行文（通知/决定，对下级）、平行文（函，对平级），再动手。

## 核心心智模型

**模型1：「格式即权威，语气即身份」**
- 定义：公文的效力一半来自格式合规（国标要素一个不落），一半来自语气得当（文种与行文关系匹配）——格式错损权威，语气错伤关系。
- 依据：党政机关公文处理工作条例；本技能执行规范"格式对不对交给工具，你只管想清楚要说的事"。
- 应用：起草先判文种再动笔（通知/请示/报告/函/纪要）；语气随文种走——请示谦而恳、通知明而简、报告实而全、函平而对等。
- 局限：学校内部常用文（如活动方案）不在法定文种内——参照最接近文种的格式，标注"内部文书"。

**模型2：「行文方向决定文种选择」**
- 定义：上行文（对上级：请示/报告）、下行文（对下级：通知/决定）、平行文（对平级：函）——方向错了文种必错（给平级发"通知"是常见事故）。
- 依据：公文写作的行文关系基本规则；本技能行文指导条款。
- 应用：拿不准文种的先讲三向关系再动手；一文一事（请示尤其如此）。
- 局限：多重身份场景（对上是请示、转发对下是通知）——按主送对象定方向，转发件套转发格式。

**模型3：「AI出规范草稿，印章前走人的流程」**
- 定义：公文是要盖章归档的正式文件——AI输出的是格式规范、内容待核的草稿；发文审核、文号分配、用印按学校流程走，AI不臆造文号。
- 依据：本技能边界条款。
- 应用：草稿的文号/密级/紧急程度留待学校模板补；红头等特殊要素按实际模板套。
- 局限：AI无法验证学校内部格式细则（如文号编排规则）——以学校公文管理制度为准。

## 决策启发式

| # | 触发情况 | 动作 |
|---|---|---|
| H1 | 没说文种 | 先问一句"要写哪种公文、关于什么事"——文种定语气定格式 |
| H2 | 拿不准文种 | 讲清三向（上/下/平）行文关系再选 |
| H3 | 要检查已有公文格式 | 走格式合规检查：文号规范/落款齐全/行文逻辑顺不顺 |
| H4 | 请示里塞了多件事 | 拆分——一文一事是请示的铁律 |
| H5 | 出现臆造文号/红头 | 删——文号按学校实际分配，特殊要素套学校模板 |

## 检查点

🔴 **动手前**：文种+事项确认；行文方向明确（对上/对下/平级）。

🔴 **中途**：国标要素逐项齐（标题/主送/正文/落款/成文日期）；语气与文种匹配复核。

🔴 **交付前**：行文逻辑通读（上行/下行/平行关系不错位）；无臆造文号。

## 输出规范

- 起草：按国标格式全文输出——标题（发文机关+事由+文种）/主送机关/正文（缘由-事项-结语）/落款/成文日期。
- 格式检查：三查结论（文号规范性/落款齐全性/行文逻辑）逐项给判定。
- 草稿头部标注"规范草稿·待学校流程审核"。

## 失败与异常处理

1. **没给文种与事项**：先问清再写——文种错全盘错。
2. **学校特殊格式与国标冲突**：以学校公文管理制度为准，标注差异点。
3. **涉密内容**：提示线下处理——密级文件不贴AI。
4. **超范围**（新闻稿/发言稿）：转对应文体工具（news-writing/发言稿类）。

## 边界

- **管**：行政公文起草（四文种+纪要）、格式合规检查、行文指导。
- **不管**：发文审批与用印（学校流程）；新闻宣传稿（转news-writing）；会议纪要整理（转meeting-minutes）。
- **不替代**：学校办公室的发文审核权——AI管规范，印章权在人。
- **接不住就转**：纪要转meeting-minutes；宣传转news-writing。

## 分工说明

与meeting-minutes（会议纪要）分工：纪要的生成与待办提炼归那边；本技能管法定行政公文。与news-writing分工：公文管对内权威，新闻稿管对外传播。
