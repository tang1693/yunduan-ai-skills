# 单元评价与改进闭环

把单元目标、评价覆盖、匿名作答证据和下一次教学调整连起来。

## 最少准备

- 单元目标、原题及评分依据
- 去标识作答或聚合记录；说明缺考/缺失和实际已教范围

## 一次开始，同一份产物

请用“单元评价与改进闭环”帮我完成这次工作：把单元目标、评价覆盖、匿名作答证据和下一次教学调整连起来。先沿用我已给的材料，只追问1—2个影响结果的问题；给可编辑候选，我可以修改、拒绝或只做当前需要的部分。

普通草稿无需逐段确认；不强迫完成未发生的后续步骤。已有材料不重复填，只有关键事实缺失才追问。对外发送、分享、执行脚本、覆盖文件另行明确确认。

## 完整流程

### 1. 对照目标

列目标—题目—证据覆盖，发现未教/未考或不一致先说明。

### 2. 核对作答

核对原题、参考答案、分值与缺失，不把缺考记零，不凭成绩画像。

### 3. 提出解释

把作答事实、可能错因及另一种解释分开，提供可排除解释的短追问。

### 4. 调整再看

教师选一项讲评/变式/支架调整，给短检验和观察栏；有新作答后再比较，不预报提升。

## 构造示例（不是真实采用证据）

输入：【构造情境】浮力单元，原题要求比较同一物体所受重力与浮力；三份匿名作答中两份只按物体大小判断，一份未交。

候选产物：

目标覆盖：比较力的关系；仅有这一题证据，不能代表整个单元。
作答事实：2份用大小判断，1份缺失，缺失不计错误。
解释A：尚未区分大小与重力；解释B：题目条件未读清。
追问：同一物体换液体时，哪一个力的条件可能改变？
调整候选：用同物体、不同液体的对照解释；教师决定是否采用。
短检验：浮力大于重力时运动趋势如何？参考为向上加速，需区别与最终漂浮状态。
新作答：尚未收集，不能声称改进已见效。

## 缺材料与停止

关键依据缺失时先交待填写结构并追问一项；不编造事实、实施或效果。没有原题或作答时仅出对照模板，不能诊断错因；不形成学生能力排序。

## 继续与退出

用户可修改、只取局部、暂缓或放弃。后续带回真实材料时沿用同一产物更新，不另装Skill，不要求重做全部步骤。没有工具则交可复制文本，不冒称已检索、发出文件或完成审批。
