# 考试数据核对与试题分析

启动：“帮我核对这次考试的数据，看看哪些题需要复核，最后给下节课可用的建议。”
服务于教师复核本次试题与教学材料，不能用一次得分推断能力、性格、情绪或教学质量。

## 最少输入

从本次材料提取学段学科、考试范围、题号、题目满分、逐题得分、缺失原因与评分规则。
只问会影响结论的缺项。没有试卷或标准答案时只能核对数据，不能判定题目科学性或错因。
仅有总分时只给汇总与需补充的材料，不编造逐题表现。

输入应去掉姓名、学号、联系方式等身份字段，采用本次临时代号。
代号与真实人员的对应表留在学校获准环境，不发给AI或共享广场。
教师先确认当前客户端与其背后模型允许处理该类材料；不能确认时只用虚构样例或汇总数据。
不自动读取历史文件、不建立个人长期档案、不默认保存或上传本次数据。

## 快速路径

1. 对齐题号、满分、单位与缺失标记；异常先列出，原始表不修改。
2. 核算每题可用人数、得分合计与平均得分率，写清分母。
3. 列出最值得教师复核的三处，给“重看题干／抽看答卷／补问学生”的下一步。
4. 教师选定后再整理为可复制报告，允许修改、拒绝或暂不处理。

## 完整路径

### 一、数据核对

重复临时代号、超满分、负数、总分与分项不符均暂停对应项，待教师更正。
空值表示未知或待补，不直接当零分。只有教师确认“真实作答且该题得零分”才计零。
缺考、漏录、无法辨认与真实零分分列；各题统计标注有效人数及排除原因。

### 二、试题描述

平均得分率 = 已确认有效得分之和 ÷（有效作答人数 × 该题满分）。
它只描述这批作答，不能单独证明题目质量、超纲、学生能力或心理状态。
同题得分异常低或完全相同时，候选解释包括题干歧义、评分口径、录入错误、未教学、真实作答困难；逐项用材料核对，不能直接淘汰题目。

需要区分度或内部一致性时，先由教研人员确认使用目的、样本、缺失处理和计算口径。
只有具备可复核计算工具和足够有效数据时才算，并交付计算过程；否则明确“未计算”。
总分方差为零、项目不足或缺失未处理时不输出Alpha数值；Alpha不能代替效度或评分者一致性证据。
统计分组只可用于匿名汇总，不输出个人名次、能力组别或名单，不按固定正确率推断焦虑、无聊、心流。

### 三、教学复核

把题目、观察到的作答与教师提供的教学经历分开。原因只作候选推断。
例如“未写单位”是事实；“不懂单位”是待追问的解释，需用一个新任务验证。
每条建议给一项短任务与观察点，由教师决定对象、时机和是否采用。

## 可编辑产物

```text
材料范围／本次版本／统计口径：
数据核对：题号｜有效人数｜缺失人数及原因｜异常｜需谁确认
试题描述：题号｜满分｜有效得分和｜分母｜平均得分率｜复核限制
证据与解释：观察事实｜材料位置｜可能解释（可多选）｜缺少的证据
教学候选：当前任务｜一道追问或变式｜教师观察点｜是否采用（待教师选）
尚未核实／暂停项／下一步：
```

## 完整去标识示例

全部为虚构材料，三份作答仅演示核算，不作试卷质量判断。
两题各5分：T01为5、2；T02为0、空白（漏录待补）；T03为5、4。

核对结论：Q1有效3份，合计10，分母15，平均得分率约66.7%；
Q2有效2份，合计6，分母10，平均得分率60%，另有1份漏录，不能当0分。
T01两题和7，T03两题和9；T02材料不完整，不输出完整总分、名次或“下降”结论。
样本只有3份，区分度及Alpha均未计算。没有题干和答卷，不能说明具体错因。
下一步候选：先补录Q2，再由教师抽看原答卷；如涉及单位，出一道相近题，请学生说清换算理由。
教师可选择只补数据、暂不出报告，或撤回建议。

## 失败与停止条件

| 情况 | 处理 |
|---|---|
| 只有总分却要求定位某学生概念错误 | 说明证据不足，改做汇总及追问设计 |
| 要按名次给教师或学生评级 | 不输出，转为匿名材料与教学任务复核 |
| 数据异常或规则冲突 | 保留原表、列冲突、暂停相关计算 |
| 模型无法可靠计算 | 给公式、可编辑表与待人工核算项，不填猜测数值 |
| 要自动写共享状态或调用其他Skill | 默认不执行；仅给人工交接摘要 |
