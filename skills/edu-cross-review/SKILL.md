# 交叉审题（第二意见）

用另一个视角二次审阅试卷，和初次审题结果对比，找出单一模型没发现的盲区。

## 工作流程

1. **读输入**：试卷 HTML/Markdown + 元数据 + edu-review 的初次审题报告。
2. **独立再审**：不参考初次结论，独立审一遍，找题目错误、超纲、歧义、难度失衡。
3. **对比**：和初次报告对比，标出「两边都发现」（重叠）和「只有一边发现」（独有）。
4. **出交叉报告**：重叠矩阵 + 差异分析 + 综合评分。

## 检查点

🔴 **动手前**：这一步不对齐，后面全是返工。先确认手上有没有被评对象、评价标准、原始材料；缺哪项就直接问，不带着假设往下做。

🔴 **中途**：等级定稿前，先把「证据」一栏逐行填满；有等级没证据的行退回重评。

🔴 **交付前**：看一遍等级分布是不是被平均分带偏，异常档位单独说明理由。

以上三处只要有一处没过，就停在原地把缺口补上，不带着问题进入下一步。

## 输出规范

- 交叉报告：重叠发现 + 各自独有发现，标清哪些是「两边都抓到」的硬伤。

## 失败与异常处理

1. **信息不全**：如果用户没给被评对象、评价标准（量表/细则）和原始材料，先问清「评谁、按哪套标准评、手上有哪些材料」，问清再动手；实在拿不到，就按最保守的假设出一版，并在开头标注「假设：…」，不编造未提供的信息。
2. **材料读不到**：如果上传的文件打不开、为空或格式不支持，说清具体原因（损坏/需转换/内容为空），并给替代路径（截图、粘贴文本、换格式重传）；不猜文件里的内容。
3. **条件冲突**：如果用户的要求与已给材料或学校规定冲突，不直接照做也不直接拒绝，先列出冲突点，给 2 个可选处置方案，等用户选。
4. **超出范围**：如果请求属于替代学校正式评审结论、给学生贴标签，说明这部分不在本技能范围，按「转成绩分析类技能」处理，不硬答。


## 边界

- 依赖 edu-review 的初次结果做对比基准，不独立出完整审题报告。
- 两模型意见冲突时，标记出来交人工裁决，不擅自调和。
