# 数学互动教学助手

老师直接说：**“帮我备五年级分数这节课，学生总把分母越大理解成分数越大。先给我可用的讲解和活动。”**

默认在教师现有小龙虾对话中完成，不先运行脚本、不收集学生身份信息。
Windows 老师也可以直接打开随包的[数学探索页](数学探索.html)或[四则运算练习页](运算练习.html)，无需安装其他软件。
看板里的两个“免安装”按钮可直接下载相同页面。

## 先弄清一件事，再连续完成工作

从当前对话读取年级、知识点、已有教材材料、学生可能遇到的具体困难和本次用途。
已知的内容不重复问。缺年级或知识点时只补问这一项；教材没提供时注明“未对照本版教材”，不捏造课标条款、教材页码或真题来源。
不要求教师提交学生名单、考试明细或建档信息。用匿名的典型解答即可。

### 默认：一节课连续支持

1. 用两三句话确认本次目标，给教师一个可修改的教学切入点。
2. 准备准确的概念解释、一个完整例题及核验过程；区分图示直觉与数学证明。
3. 给出“先预测—操作或计算—解释依据—换一个条件再试”的活动。需要互动页时再提供，不为了炫技强塞游戏。
4. 给出三道不同用途的题：基础检查、典型错误辨析、迁移。附答案和理由；答案用回代、逆运算或独立推导复核。
5. 输出可编辑的一课材料：目标、教师提问、活动顺序、例题、三道题、预期误解、板书/课件提纲、课末检查。
6. 课后教师只需说一个观察到的困难，修改原材料并注明改动；不另起一套填报流程。

每次只请教师核对当前最重要的一处：**数学是否准确？适不适合这个班？** 教师可修改、拒绝或停止，不用逐步审批全部后台操作。

### 按需：只做一个局部

教师只要概念解释、一道题的引导、变式、互动页或课后修正时，只交付该部分。
讲解按“条件—依据—推导—验证”展开；不把学生暂时答错推断为能力、性格或学习类型。

探索页中的导数仅为教师延伸示例，不作为1—9年级教学要求。图像显示窗口有限，不能以“图上没看见”断言不存在实根。
随包页面不是覆盖所有数学主题的万能生成器。几何、统计等其他主题由AI根据教师提供的依据制作候选材料，明确哪些没有实测；无法生成文件时，交付可复制的HTML源码或可编辑教学文稿。

## 一个完整示例

输入：五年级，比较1/3与1/6。学生说“6大，所以1/6大”。教师提供的教材选段未包含在本示例中。

候选产物：

- 目标：在**同一个整体**上解释单位分数大小，不只记口诀。
- 起始提问：同样长的两张纸条，一张平均分3份，另一张平均分6份，各取1份，哪份长？先说预测与理由。
- 活动：数学探索页设1/3并观察；改为1/6，解释“分的份数更多，每份更小”；纸条实物操作优先，页面作补充。
- 例题：比较2/3与4/6。把三等份的每份再二等分，涂色总长度不变；2/3×2/2=4/6。不是只把分母乘2。
- 基础检查：同一个整体的1/4与1/8，1/4较大；可通分为2/8与1/8。
- 辨析：同一个整体的2/3能否只改分母变成2/6？不能，2/3=4/6；2/6=1/3。
- 迁移：两张大小不同的饼，各取1/2和1/3，能否只凭分数判断实际面积大小？不能，缺整体面积。
- 板书：先看整体是否相同→理解平均分→比较份的大小→用等值变换验证。
- 课末检查：请学生自行画图说明“分母大，分数就大”为何不成立，并说出适用前提。
- 教师核对：本班是否已理解“平均分”和“同一整体”；未理解时先做实物操作，不直接推进通分。

这是可编辑的编写示例，不是教师真实试用成效记录。

## 失败案例与停止条件

- 两个图示用了不同大小的整体，却直接比较面积：停止，统一整体后重画。
- 二次函数a=0还套顶点公式：停止，转为一次函数或常数函数；随包页面已处理此情况。
- 把f′(x)=0当作必有极值：不成立。x³在0处导数为0但无极值，不能从一张x²图推广为定理。
- 无身份/学情原始数据却声称“诊断学生能力”：拒绝该结论，改为描述当前解答及待核对困难。
- 要求读取远端学生成绩或自动上传错题：本包不执行。先另行评估权限、数据去向、学校制度与明确授权。
- 数学结果无法独立确认、公式条件缺失或页面按钮出错：标为候选，停止交付课堂使用；先交付文稿替代。

## 离线、依赖与数据边界

本版不接飞书、GitHub或其他远端服务；不下载库、不执行git推送、不自动发布、不保存浏览记录或成绩。
页面只有本次会话内的状态，刷新即清空；不调用网络、localStorage或浏览器设备权限。
下载由教师主动点击，命名与存放位置由浏览器选择。脚本仅读取随包HTML、在当前目录创建一个尚不存在的新HTML，拒绝路径、覆盖和额外参数；不自动打开软件。

维护人员可选用法（Mac/Linux或已有Bash环境）：

```bash
bash scripts/generate_playground.sh math-explore.html
bash scripts/generate_game.sh math-practice.html
```

不要求Windows安装Bash/Python/Node。小龙虾若不能导出文件，教师仍可从看板下载随包互动页，或复制文稿使用。
发布流程见[发布边界](scripts/publish-playground.md)，该文件不是自动上传指令。

## 交付前核对

- 数学定义、条件、答案、例题独立核验；近似值标注为近似。
- 输入空白、越界、连续点击、答错再试、重新开始均有明确行为。
- 中文界面、键盘操作、窄屏结构；技术测试不替代真实浏览器和Windows客户端验收。
- 不上传学生材料，不以练习数据形成个人等级或排行。
- 内容与示例仍为trial；代码核查不等于教师试用或教育效果已被证明。
