# 课末收口（老道理第 23 条）

> 下课前三分钟，把「老师总结」换成「学生说 + 你闭嘴等 10 秒」。成本 0 分钟——那三分钟本来就有。

## 一句话启动

打开就说「**收口**」。示例：「这节课最后三分钟怎么收」——把你的收口脚本（或教案最后一段）粘进来，AI 按三问改写成学生说的版本，标注「问完闭嘴，等满 10 秒」。

## 工作流程

1. **收脚本**：收三样——学科年级、这节课最关键的那一句话、你教案上最后 3 分钟写的什么。没有脚本的，口述一句「我最后打算说什么」也行。
2. **改三问**：把老师总结改写成学生说的版本，三问逐字照念：
   - ① 「今天最关键的那一句话，是什么？」
   - ② 「你是怎么想到那一步的？」
   - ③ 「哪里卡过？」
   改写后在脚本上标注一句：「问完闭嘴，等满 10 秒。」
3. **出门条**：附一条学生本子上写的话（三选一）：「今天我学会了____／我还卡在____／我想问____」。
4. **明早开场**：拿到出门条照片或文字后，说「汇总出门条」，AI 出三样——学会 X 人／卡在 Y 处／新问题 Z 个；卡点 TOP3；明天开场的三个问题（每个一句话，老师照着问）。

## 核心心智模型

**模型1：「那三分钟本来就有，只是换了谁在说话」**
- 定义：收口不需要新增时间——下课前的三分钟客观存在，变革只是把"老师总结"换成"学生说+老师闭嘴等10秒"。成本为零，这是它成为全册第一条该做的原因。
- 依据：《二十三条AI用法手册》第23条"成本0分钟新增"；三问逐字稿的设计。
- 应用：任何老师任何学科明天就能用——不改变教学设计，只改最后三分钟的说话人。
- 局限：零成本≠零难度——"闭嘴等满10秒"对教师是真实的自控挑战，第一周冷场是正常反应。

**模型2：「假总结都热闹、都准时、都没有整理」**
- 定义：三种假总结（课本缩短念一遍/结论再重复一遍/报流水账）在课堂上完全合规——时间准、气氛好、什么都没发生。检验只有一句：让学生合上本子自己画出来，画得出才是真收口。
- 依据：二十三条第23条的三种假货清单；收口三问的设计对照。
- 应用：改写收口脚本时对照三假自查；出门条汇总时"卡在Y处"落不到具体知识点的，多半刚经历了一场假总结。
- 局限：真总结的颗粒度因人而异——画得粗糙但结构对也算过，不追求美观。

**模型3：「出门条是明天的地基」**
- 定义：学生本子上写的一句话（学会了/还卡在/想问）不是给老师的交代，是第二天开场三问的原料——收口的价值在24小时后才完全兑现。
- 依据：本技能工作流第4步（汇总出门条→明早开场三问）；"今天收得好的东西就是明天的地基"。
- 应用：出门条汇总输出三样——学会X人/卡在Y处/新问题Z个 + 卡点TOP3 + 三个开场问题（每个一句，照着念）。
- 局限：收不齐也照常——先收一半；驻地教师在学科群回一句"本班：学会X/卡Y/新问题Z"也算数。

## 决策启发式

| # | 触发情况 | 动作 |
|---|---|---|
| H1 | 脚本里还有老师长段总结 | 退回重改——三问必须是学生说的版本 |
| H2 | 第一周冷场没人开口 | 正常——闭嘴等满10秒本身就是处理；第二周换第一问"这节课哪个地方你走神了"（更好答） |
| H3 | 老师没有教案 | 口述"我最后打算讲什么"也能改；实在没有就按课题给通用三问模板 |
| H4 | 低年级写不动出门条 | 改"举手示意三选一"，教师口头数数记便签 |
| H5 | 学生全写"学会了" | 警惕假总结信号——抽查两个学生当场复述，复述不出的是没整理不是真会 |

## 输出规范

- 改写版收口脚本：三问逐字（①今天最关键的那一句话是什么②你是怎么想到那一步的③哪里卡过）+「问完闭嘴，等满10秒」标注，一屏能投影。
- 出门条模板：三选一句式（今天我学会了____/我还卡在____/我想问____），学生抄作业本末页即可，不用印。
- 明早汇总：三行数字（学会X/卡Y/问Z）+ 卡点TOP3 + 三个开场问题（每个一句、可照念），不超过半页。
- 交付提醒附三种假货清单——把课本念一遍/把结论重复一遍/报流水账，都热闹都准时都没有整理。

## 检查点

🔴 **动手前**：先确认这节课"最关键的一句话"是什么——说不清就先帮老师找出来，收口收的就是这一句。

🔴 **中途**：三问必须是学生说的版本——脚本里残留老师长段总结即退回。

🔴 **交付前**：出门条汇总的"卡在Y处"落到具体知识点——"部分学生掌握不牢"这类空话重写。

## 失败与异常处理

1. **没有教案**：口述收口意图也能改；全没有就按课题出通用三问模板，先跑起来。
2. **学生不说**：闭嘴等满10秒就是处理办法；两周仍冷场换第一问（走神题更好答）。
3. **出门条收不齐**：收一半也开汇总；驻地教师学科群回一句也算数。
4. **拖堂没时间收口**：最小可用版30秒——只问"今天最关键的一句话是什么"，也比没有强。

## 边界

- **管**：收口脚本改写、出门条模板与汇总、明早开场三问。
- **不管**：课堂纪律与现场节奏——闭嘴等10秒这件事 AI 替不了，它不在教室里。
- **不替代**：教师对本班的判断——TOP3卡点出来后，明天先重讲哪个是老师的决定。
- **接不住就转**：整节课教学设计转备课类技能；成绩分析转考试与成绩分析助手。
- **分工说明**：化学学科教师可直接用 chem23-lesson-cycle（备课12条+收口3条一体化）；本技能面向全学科，两者方法论同源（二十三条第4/23条）。
