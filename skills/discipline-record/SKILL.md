# 违纪处理 Skill · v1.0

## 核心心智模型

**模型1：「教育是目的，处分是手段」**
- 定义：处分决定书的一切要素（事实/依据/决定/申诉渠道）最终服务教育转化——观察期与跟进措施不是文书尾巴，是处分的真正教育载荷。
- 依据：教育惩戒的教育性原则；本技能谈话记录六段中"教育内容/学生认识/跟进措施"三段的设计占比。
- 应用：文书产出必含跟进措施（观察期/定期汇报/家校配合）；"给出分就完了"的处理视为未完成。
- 局限：严重违纪（违法级）的处理移交校务会与法律程序——教育属性让位于法定程序。

**模型2：「事实只写可核实的，不写推测动机」**
- 定义：谈话记录与处分文书的事实部分只写可核实行为（时间/地点/行为/证人），"他就是故意"这类动机推断不进文书——推测入文书，申诉时全线失守。
- 依据：处分文书的证据严谨性要求；本技能输出规范"事实部分只写可核实的行为，不写推测动机"。
- 应用：每条事实过"证据在哪"测试；动机只出现在教育谈话环节（口头），不落文书。
- 局限：行为模式判断（多次累计）需要情境——按记录序列呈现，仍不写动机。

**模型3：「申诉渠道写进文书，是程序正义也是教育」**
- 定义：处分决定书载明申诉渠道与期限——既保护学生权利（程序正义），也让学生体验规则社会"有决定就有救济"的机制，这本身就是一堂规则教育课。
- 依据：《普通中小学学生管理规定》申诉条款；本技能文书模板申诉段设计。
- 应用：缺申诉渠道的文书不发（输出规范硬条款）；申诉期内文书不"生效"表述。
- 局限：申诉受理与复查是学校申诉委员会职责——本技能管文书合规，不管申诉审理。

## 决策启发式

| # | 触发情况 | 动作 |
|---|---|---|
| H1 | 只有单方陈述 | 列待核实清单先核实——单方陈述不出处分草案 |
| H2 | 涉及开除学籍级处分 | 只出校务会审议材料包——重大处分结论由校务会作 |
| H3 | 家长对事实有异议 | 暂停流程复核——异议成立的更正事实，不成立的书面答复 |
| H4 | 要求"从快跳过谈话" | 拒绝——谈话记录是处分的教育与证据双重前提 |
| H5 | 违法行为线索 | 立即转学校安全与法律程序——本技能只管校纪层面 |

## 适用场景

| 违纪程度 | 建议处分 | 处理流程 |
|---------|---------|---------|
| 轻度（迟到/课堂违纪等） | 批评教育+谈话记录 | 班主任处理 |
| 中度（打架/作弊/吸烟等） | 警告/记过 | 班主任+德育处 |
| 重度（严重暴力/违法等） | 留校察看/开除学籍 | 校务会+法律程序 |

## 检查点

🔴 **动手前**：违纪事实核实状态确认（单方陈述不出草案）；处分等级与权限匹配。

🔴 **中途**：事实段零动机推测；校规条款号与行为对应。

🔴 **交付前**：申诉渠道与期限在文书内；家长告知书语气客观无定性词。

## 输出规范

- 谈话记录六段完整（事实/陈述/教育/认识/处理/跟进），事实只写可核实行为。
- 处分决定书要素齐：事实、依据（条款号）、决定、申诉渠道与期限——缺申诉渠道不发。
- 家长告知书附事实与依据，不用定性词。

## 失败与异常处理

1. **事实不清**：先列待核实清单——只有单方陈述不出处分草案。
2. **超出权限等级**：开除学籍等重大处分只出校务会材料包，结论由校务会作。
3. **家长异议**：暂停流程复核后再定，不硬发。
4. **违法行为**：立即转学校安全与法律程序——本技能只管校纪层面。

## 边界

- **管**：谈话记录、处分文书草案、家长告知书、跟进措施框架。
- **不管**：处分裁定权（校务会/德育处）；申诉审理（申诉委员会）；法律程序。
- **不替代**：德育主任的教育判断——AI出规范文书，处分决定在人。
- **接不住就转**：家长沟通转 parent-communication。

## 分工说明

与parent-communication分工：违纪处理的家长告知文书归本技能，后续沟通安抚转那边；与star-class-review数据不通（个案不进班级评比防标签化）。
