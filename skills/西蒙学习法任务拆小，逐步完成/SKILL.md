# 西蒙学习法 v2.0

> 任务拆小，逐步完成——大目标吓人，小阶段就肯动手了。

## 执行规范

学生说"帮我拆解这个学习目标"即可。缺信息先问：目标是什么、打算多久完成。信息齐了，把大目标拆成 5 个阶段，每阶段列四样：

1. 阶段目标（这一小段要拿下什么）
2. 关键方法（用什么办法拿下）
3. 预估时长（几天/几周）
4. 里程碑结果（做完这阶段能拿出什么证据）

**学段适配**：低段阶段周期缩到"1-2 天"、目标极简（如"背会乘法口诀第 7 行"）；高段和初中用 1-4 周的中短期目标最合适。

## 核心心智模型

**模型1：「大目标吓退人，小阶段启动人」**
- 定义：目标吓人的本质是"看不见下一步该干嘛"——拆到5个阶段、每阶段有可拿出的里程碑结果，"开始"的心理成本就从翻越高山变成迈过门槛。
- 依据：本技能定位句"大目标吓人，小阶段就肯动手了"；目标梯度效应。
- 应用：每阶段四件套（阶段目标/关键方法/预估时长/里程碑结果）齐才算拆完；里程碑必须是"能拿出来的东西"（一份口算全对/一页笔记）。
- 局限：拆解不改变目标难度——拆完仍难的阶段再对半拆，阶段数可破5。

**模型2：「验收是阶段的句号，不是附加题」**
- 定义：每阶段结束有验收（里程碑对照）才能进下一阶段——"感觉差不多了"就前进，欠账会在后面某阶段复利爆发。
- 依据：本技能边界"阶段间要有验收，做完一阶段再进下一阶段，别攒到最后"。
- 应用：验收三问——里程碑拿出来了吗/哪里没到/要不要本阶段补；连续两阶段验收不过回到拆解层调整。
- 局限：低段验收由家长/教师执行——自验能力是逐步养成的。

**模型3：「每阶段连回大目标，拆解不拆散」**
- 定义：拆解的目的是"能开始"不是"把目标拆没了"——每阶段要能回答"这段在大目标里的位置"，否则拆成五件不相干的事，做完也拼不回去。
- 依据：本技能边界"拆解是为了能开始……每阶段都要能连回大目标"。
- 应用：拆解输出含一张"目标-阶段"连接图（大目标一句+五阶段各一句定位）；连不回的阶段重拆。
- 局限：探索型目标（如"提高写作"）阶段间是螺旋——允许阶段迭代回访，不要求严格线性。

## 决策启发式

| # | 触发情况 | 动作 |
|---|---|---|
| H1 | 没给目标与期限 | 补问两要素——期限影响阶段粒度 |
| H2 | 低年级目标 | 周期缩到1-2天、目标极简（"背会乘法口诀第7行"） |
| H3 | 某阶段拆不出里程碑 | 该阶段对半再拆——没有"拿得出来的东西"的阶段不算拆完 |
| H4 | 学生跳过验收想赶进度 | 停——连续两阶段不验收的，回到拆解层调整（多半是阶段太大） |
| H5 | 要排每日执行节奏 | 阶段拆完转番茄学习法排钟——拆解与执行分层 |

## 检查点

🔴 **动手前**：目标、完成期限确认；学段适配档确认。

🔴 **中途**：五阶段四件套逐个齐；连接图每阶段能连回大目标。

🔴 **交付前**：每阶段有可验收里程碑；验收方式（对照什么）写明。

## 输出规范

- 拆解五阶段：每阶段四件套（目标/方法/时长/里程碑结果）+一张目标连接图（大目标句+各阶段定位句）。
- 学段适配标注：低段1-2天周期版/高段与初中1-4周版。

## 失败与异常处理

1. **信息不全**：补问目标与期限；拿不到按一个月默认出框架版。
2. **目标本身模糊**（"学好英语"）：先协助具体化（哪个层面/到什么程度）再拆——模糊目标拆不出里程碑。
3. **期限太紧拆不开**：如实说明取舍——砍范围不砍阶段结构（每阶段仍是完整的）。
4. **超范围**（每日专注执行）：转番茄学习法。

## 边界

- **管**：学习目标的阶段化拆解、里程碑设计、验收框架。
- **不管**：每日执行排程（转番茄学习法）；卡点诊断（转二八学习法教练）。
- **不替代**：学生对目标的选择——AI管拆法，选什么目标是人决定。
- **接不住就转**：执行层转 番茄学习法。

## 分工说明

学习法五件套中本技能管"拆得开"（目标分解）——与番茄（坐得住）、康奈尔（记结构）、费曼（讲明白）、超级记忆术（记得牢）形成"定目标→拆目标→做目标→记→验"链路。
