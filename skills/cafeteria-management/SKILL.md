# 食堂管理 Skill · v1.0

## 一句话启动

打开就说「**管食堂**」，不用先描述格式。

## 执行规范

老师说"帮我管食堂 / 出食品安全检查表"即可。缺信息先问：管什么环节（制度/检查/留样/满意度）。信息齐了，按需做四样：

**食堂管理事项清单：**
- 食堂管理制度
- 食品安全检查清单（每日/每周）
- 食品留样记录表
- 餐具消毒记录
- 从业人员健康档案
- 菜谱制定参考
- 学生用餐满意度调查
- 食材采购验收记录
- 食堂财务台账

**四张核心表的做法**：
1. 每日检查清单：晨检（人员健康/体温）/食材验收（索证索票/感官）/加工（生熟分开）/留样（每样125g、48小时、专柜）/试尝与陪餐登记。
2. 每周检查：设备消毒/库存效期/卫生死角/虫害防治。
3. 满意度调查：口味/分量/卫生/服务四维，月度一次，结果反馈菜谱调整。
4. 菜谱参考：营养搭配原则 + 每周不重样参考谱（成本与份量按学校实际调）。

## 核心心智模型

**模型1：「留样与索证是法定的两根救命稻草」**
- 定义：食品留样（每样125g、48小时、专柜）与索证索票（供货商资质+检验单）是《食品安全法》对学校的刚性要求——平时是流程，出事时是学校免责与溯源的唯一依据。
- 依据：学校食堂管理法规；本技能每日检查清单的留样与索证设计。
- 应用：每日检查表这两项独立列示（不并入"其他"）；留样记录缺一顿即红牌。
- 局限：合规不等于安全——合规是底线，原料与加工质量是更高的线。

**模型2：「每日检查表是防火墙，不是走过场」**
- 定义：晨检（人员健康/食材验收/加工规范/留样/试尝陪餐）逐项打勾的意义在"逼着每天看一遍"——食品安全事故几乎都发生在"检查表空着"的日子。
- 依据：本技能每日检查清单设计；食品安全危害分析的日常控制原理。
- 应用：检查表由当日责任人签字；空项与异常项当日整改闭环。
- 局限：检查表防得住疏漏防不了故意（投毒）——门禁与监控是另一层。

**模型3：「满意度是修正 compass，不是考核棒」**
- 定义：月度满意度调查（口味/分量/卫生/服务）的价值在指导菜谱与流程修正——把它变成对食堂员工的考核棒，问卷就会变成人情分。
- 依据：本技能满意度调查设计。
- 应用：调查结果反馈给菜谱调整与流程改进；连续低分项转合同履约沟通（与物业/承包方）。
- 局限：学生口味偏好波动大——看趋势不看单月。

## 决策启发式

| # | 触发情况 | 动作 |
|---|---|---|
| H1 | 没说管什么环节 | 补问（制度/检查/留样/满意度）——四件事四套文书 |
| H2 | 发现留样缺失 | 红牌处理——当日整改+记录，不留过夜 |
| H3 | 从业人员健康证临期 | 提前30天预警清单——过期未复证不得上岗 |
| H4 | 满意度连续两月低 | 转合同履约沟通口径——满意度数据是谈判依据 |
| H5 | 要改每日检查表 | 增项可以，法定项（留样/索证）不减不并 |

## 检查点

🔴 **动手前**：环节确认；本校食堂模式（自营/托管）确认——制度文书不同。

🔴 **中途**：法定项独立列示；每张表有责任人签字位。

🔴 **交付前**：每日/每周表分开；记录保存期标注（不少于保质期满后6个月）。

## 输出规范

- 四件核心：每日检查清单（晨检五项逐项打勾）/每周检查表（设备消毒/效期/虫害）/满意度问卷（四维月度）/留样记录表（品名-重量-时间-责任人）。
- 制度框架给可填版；菜谱参考附营养搭配原则。

## 失败与异常处理

1. **信息不全**：补问环节与食堂模式；按自营默认出。
2. **疑似食安事件**：立即转学校应急预案（留样封存/报告监管/配合调查）——本技能文书让位于应急流程。
3. **承包方配合度低**：以合同条款+检查记录为依据转学校与供应商对接——AI不出"变通"检查。
4. **超范围**（经费决算）：转财务口径。

## 边界

- **管**：食堂制度框架、日/周检查表、留样与索证文书、满意度调查、菜谱参考。
- **不管**：食安事件应急（学校预案）；财务决算（财务）；托管合同纠纷（法务口径）。
- **不替代**：食品安全员的现场检查——表是工具，查是责任。
- **接不住就转**：午餐午休管理转 午餐午休技能（就餐秩序口径）。

## 分工说明

与"午餐午休"分工：本技能管食品安全与运营（食堂侧），那边管学生就餐秩序与配餐统计（班级侧）；数据接口是"各班就餐人数"。
