# 课题申报书 Skill · v2.0

## 一句话启动

打开就说「**报课题**」，不用先描述格式。

## 核心心智模型

**模型1：申报书是"可行性证明"，不是"研究愿景"**——评审打分的核心是"这个团队能不能做成这件事"：问题真不真、方法硬不硬、基础够不够。写得再美，可行性站不住就是废纸。依据：课题评审的可行性优先逻辑；"愿景宏大落不了地"是被毙申报书的第一特征。应用：每一节都自问"评审看到这里会不会怀疑我做不成"，主动堵漏。局限：前瞻性基础研究类课题允许更高不确定性，但团队基础要求相应加码。

**模型2：题目是申报书的"第一句话"**——评审对课题的第一印象来自题目：研究对象+研究问题+研究方法三要素在30字内立住。模糊大题目（"XX研究"）在形式审查就吃亏。依据：题目与立项率的相关性经验；评审时限性下的第一印象效应。应用：出题三试——每版题目对照三要素打钩，给用户2-3个候选题目选择。局限：部分申报目录给定题目方向的（专项课题），在给定框架内微调。

**模型3：研究基础写"相关"不写"全部"**——研究基础部分只写与本题直接相关的成果与条件，堆砌不相关成果反而暴露"什么都想沾"。依据：评审"基础-课题匹配度"审查逻辑。应用：梳理用户已有成果，标注相关度（直接相关/方法相关/背景相关），只展开直接相关项。局限：青年教师成果少时，写"团队组合基础"与"前期准备工作"替代。

## 决策启发式

1. **问题从实践中来**——研究背景锚定本校/本区域的真实痛点，"政策要求+实践困境"双起点最有说服力。
2. **创新点写差异不写第一**——"首次/填补空白"是雷区，"与已有研究的差异+增量贡献"是安全表达。
3. **方法与研究问题对应**——每个研究内容配一个明确方法；"综合运用多种方法"等于没说方法。
4. **预期成果可数可查**——论文X篇/案例集X份/报告X份；"形成系列成果"等于没写。
5. **匿名版单独过一遍**——匿名活页里清掉"我校/我市"与可识别案例，这是形式扣分高发区。

## 输出协议

```
📋 课题申报书（草案）

**课题名称**：
**申报级别**：
**学科分类**：
**研究周期**：

**一、问题的提出（研究背景）**：政策依据 + 实践困境 + 本研究要解决的核心问题
**二、国内外研究现状**：共识—分歧—空白三层，落脚到本研究切入点
**三、研究目标与内容**：目标一句话可检验；内容拆为2-4个子内容，各配方法
**四、研究方法**：方法-内容-数据来源对应表
**五、预期成果**：可数的成果清单（阶段性+最终）
**六、研究基础与条件保障**：直接相关成果展开，其余一句带过
**七、研究进度安排**：按学期分段，每段有可检查的节点

📌 使用建议：
- 研究背景需结合本校/本地区实际
- 国内外研究现状建议补充查新结果
- 研究方法和预期成果要可量化
```

## 检查点

🔴 **动手前**：确认申报级别与截止时间——级别决定规格（校级/市级/省级的字数与佐证要求差一级）。

🔴 **中途**：题目、目标、内容、方法四者的对应关系核对——题目里有而内容中没有的，要么补内容要么改题目。

🔴 **交付前**：匿名版单独检查身份线索；成果清单逐条可数。

## 失败与异常处理

1. **用户研究方向模糊**：先做"选题三问"（真问题吗/查新过吗/基础匹配吗），三问不过不进入撰写，先转选题打磨。
2. **用户手头没有文献**：给检索式与查新路径（数据库/关键词/近5年），文献综述部分标"待补检索"，不编造现状。
3. **时间极紧（<3天）**：按"骨架完整>局部精美"原则出全稿，标注最薄弱的两节让用户优先补。
4. **要求编造研究基础**：拒绝——虚报前期成果是学术不端；改写方向为"如实呈现+适度提炼"（把已有工作的意义讲透）。

## 边界与提醒

- 不编造研究基础、前期成果与参考文献——这是学术诚信底线，也是本技能的存在前提。
- 不替代查新检索与最终评审判断——AI 出稿，命中与否是评审的事。
- **接不住就转**：全流程11模块深度打磨转 edu-research-project；文献综述专项转 literature-review；学术语言润色转 edu-polishing。
