# 星级班级评审 v1.0

> 星级班级评审——数据说话、标准透明、公示清楚。

## 执行规范

老师说"帮我做星级班级评审"即可。缺信息先问：评审周期（周/月）、各维度数据。信息齐了，做三样：

1. 评分表：卫生、纪律、考勤、活动等维度，权重和分值说清。
2. 数据汇总：各班各维度得分、总分、排名。
3. 星级公示：星级结果 + 一句话说明，格式规范。

## 核心心智模型

**模型1：「数据说话，AI不评'这个班好不好'」**
- 定义：星级评审的公信来自"评分=各维度数据的机械汇总"——AI的角色是汇总器与呈现器，主观评价（班风印象分）不进入任何环节。
- 依据：本技能边界"评审靠数据说话，AI只汇总、不主观评"。
- 应用：每班星级=Σ(各维度得分×权重)；评分依据可回溯到各维度原始检查记录。
- 局限：维度本身的设置（卫生占多少分）是学校决策——权重由学校定，AI不擅自改标准（边界条款）。

**模型2：「标准与权重学期前定死，评审中不变」**
- 定义：评审维度、权重、星级线在学期初公示后锁定——期中改标准等于让前面的努力作废，评审公信即刻归零。
- 依据：本技能边界"评审维度、权重由学校定，AI不擅自改标准"。
- 应用：AI核对汇总用的是"学期初公示版"权重；发现口径不一致即暂停输出。
- 局限：学期中新增维度（如新增"光盘行动"）——记为附加分单列，下学期并入正式权重。

**模型3：「公示的是结果与依据，不是隐私」**
- 定义：星级结果+一句话说明对全校公示；扣分明细的申诉渠道同步公布——公示的目的是让结果服气，不是让落后班级难堪。
- 依据：本技能执行规范"星级公示：星级结果+一句话说明，格式规范"。
- 应用：公示版不含班级间排名对照表；落后班级的改进建议单独送班主任。
- 局限：争议申诉的处理在学校评审组——AI提供数据回溯支持。

## 决策启发式

| # | 触发情况 | 动作 |
|---|---|---|
| H1 | 没给评审周期与维度数据 | 补问（周/月评+各维度数据来源） |
| H2 | 维度数据缺失（如纪律没查） | 该维度按"缺评"处理并公示标注——不用估算补分 |
| H3 | 权重与学期初公示不一致 | 暂停汇总，提示按公示版核对——口径混乱时不出结果 |
| H4 | 班级对结果有异议 | 给数据回溯路径（哪项检查哪天扣的分）——申诉按学校评审组流程 |
| H5 | 要"调高某班星级" | 拒绝——数据结果不可调；确有误记走数据修正流程（更正原始记录后重算） |

## 检查点

🔴 **动手前**：评审周期、各维度数据、权重口径（学期初版）三样核齐。

🔴 **中途**：每班每维度得分可回溯原始记录；权重锁定版核对。

🔴 **交付前**：评分表+汇总+星级公示三件齐；公示版无敏感对照信息。

## 输出规范

- 三件输出：评分表（维度×权重×分值说明）/数据汇总表（各班各维度得分-总分-星级）/星级公示（结果+一句话说明+申诉渠道）。
- 评审周期建议月评（周评波动大、学期评反馈慢）；"进步星"并列设置（进步最大的班也上公示）。

## 失败与异常处理

1. **维度数据不全**：缺评维度公示标注"本期未评"——不估算、不沿用旧分。
2. **权重口径存疑**：暂停输出，转学校评审组确认——宁可延后发布不可错口径。
3. **申诉成立**（原始记录有误）：更正原始数据后重算并公示更正说明——程序透明。
4. **超范围**（文明学生个人评比）：转学生处个人评优口径——班级与个人评审不同源。

## 边界

- **管**：星级班级的评分汇总、结果呈现、公示文书、数据回溯支持。
- **不管**：标准与权重的制定（学校决策）；原始检查的执行（各维度检查技能）；申诉裁定（评审组）。
- **不替代**：学校评审组的裁定权——AI管算得对，人管评得服。
- **接不住就转**：各维度数据的生产转hygiene-inspection/discipline-record/student-attendance等。

## 分工说明

数据上游：卫生（hygiene-inspection）、纪律（discipline-record）、考勤（student-attendance）、活动（各活动记录）——本技能是这些维度数据的汇总评审口。
