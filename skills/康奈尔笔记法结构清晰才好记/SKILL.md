# 康奈尔笔记法 v2.0

> 结构清晰才好记——三栏一页，笔记不散、复习有纲。

## 执行规范

学生或老师说"帮我用康奈尔笔记法整理 XX"即可。缺内容时先问：整理哪段内容/哪本书。信息齐了，按板书顺序还原成三栏：

1. **笔记区**（主栏）：按逻辑流还原知识点，不是简单罗列要点，而是模拟"老师在黑板上边讲边写"的过程。
2. **提示区**（左栏）：每个要点提炼关键词或一个能勾起回忆的问题。
3. **总结区**（底部）：用 1-2 句话概括整页核心。

**学段适配**：低段不推荐（三栏太抽象，改超级记忆术）；高段在总结区加提示"用一两句话说说你学到了什么"；初中最匹配。

## 核心心智模型

**模型1：「三栏是三次加工，不是三个格子」**
- 定义：笔记区（记录）→提示区（提炼）→总结区（概括）对应认知加工的三级深化——只抄不提炼等于只做了第一级；三栏的价值在使用顺序（先记录、后提炼、再概括），不在格子本身。
- 依据：康奈尔笔记法的生成性加工原理；本技能三栏设计"模拟老师边讲边写"。
- 应用：指导学生按"课上记主栏→课后24小时内填提示区→周末写总结"节奏走；只有一栏的笔记退回。
- 局限：低段做不到三栏——本技能不推荐低段（边界条款），改超级记忆术。

**模型2：「提示区是'考自己的题'，不是关键词装饰」**
- 定义：左栏提示的本质是自测线索——每个提示应能"遮住主栏自问自答"（关键词或问题式）；写满关键词却从不遮盖自测的学生，用了一半功能。
- 依据：测试效应（retrieval practice）研究——提取练习强于重复阅读。
- 应用：提示区生成遵循"能变成问题就不只写词"；使用说明必含"遮盖自测法"一步。
- 局限：自测需要习惯养成——首月教师课堂带练2次。

**模型3：「总结区两句话，逼出结构感」**
- 定义：1-2句话概括整页，迫使学习者从"点"上升到"结构"——写不出两句话说明没懂这页的内在逻辑，总结区是理解的试纸。
- 依据：本技能总结区设计；精加工策略中的概括化。
- 应用：总结写不出时不是硬凑——回主栏找"这页的线是什么"；高段总结加一句"我会怎么用它"。
- 局限：有些课天然散点（如活动课）——允许总结为"本页要点清单"式。

## 决策启发式

| # | 触发情况 | 动作 |
|---|---|---|
| H1 | 学生只交内容没说课程 | 补问学科与内容段——还原需知道"这节课讲什么" |
| H2 | 低年级学生要用 | 建议转超级记忆术——三栏抽象度超出低段 |
| H3 | 一次给整本书内容 | 拆页处理——按课/按节还原，不一次性灌 |
| H4 | 提示区写成了小标题抄写 | 退回重做——提示要能变成自测问题 |
| H5 | 复习场景（不是初次整理） | 出"三遍复习法"：遮盖自测→错点回看→总结重写 |

## 检查点

🔴 **动手前**：内容与学段确认；低段转介。

🔴 **中途**：主栏按逻辑流（非罗列）；提示区可转问题式。

🔴 **交付前**：三栏齐且总结≤2句；附"遮盖自测"使用说明。

## 输出规范

- 三栏结构化输出：主栏（逻辑流还原）/提示栏（关键词或问题，每要点一条）/总结栏（1-2句）。
- 附使用节奏卡（24小时提炼/周末总结/考前遮盖自测三步）；初中版总结区加"怎么用"提示。

## 失败与异常处理

1. **信息不全**：补问内容段与学段；拿不到按初中默认处理。
2. **内容过于零散**：如实按清单式整理，总结区写"本页为要点集"——不硬造逻辑线。
3. **学生抵触三栏**：从两栏起步（主栏+总结），提示区第二周再加——工具迁移循序渐进。
4. **超范围**（教师备课笔记）：本技能面向学生课堂笔记——教师板书设计转备课类技能。

## 边界

- **管**：学生课堂内容的康奈尔式三栏整理、复习用法指导。
- **不管**：低段笔记（转超级记忆术）；错题整理（错题本属各学科工具）。
- **不替代**：学生自己的消化——AI给结构，消化在学生。
- **接不住就转**：低段转 超级记忆术；方法讲解转费曼学习法。

## 分工说明

学习法五件套分工：本技能管"记下来"（结构化），费曼管"讲明白"（输出检验），番茄管"坐得住"（专注），西蒙管"拆得开"（目标分解），超级记忆术管"记得牢"（编码）——按学生卡点选用。
