# 学期班主任评语生成器 v2.0

> 一份好评语：真实有温度、具体有画面感、鼓励为主但不失真诚，家长学生都爱看。

## 执行规范

老师说"帮我写期末评语"即可。缺信息先问：哪个学段、给谁写、每个学生有什么特点（或直接给名单+一两个关键词）。信息齐了，批量生成 + 可个性化定制。

**每条评语守四原则**
1. 真实：有具体事例支撑，不是套话——"那次运动会你坚持跑完 800 米"比"你很有毅力"强。
2. 温暖：让学生感到"被看见、被理解"。
3. 建设性：既肯定优点，也真诚指出改进方向。
4. 成长导向：说"你可以更好"，不说"你还不够好"。

**学段适配**
- 小学低段：鼓励为主，突出进步和闪光点，用孩子能懂的语言。
- 小学高段：肯定 + 建议，加一句自我反思引导。
- 初中：增加青春期特点的个性化描述，批评委婉有建设性，护住自尊。

## 核心心智模型

**模型1：「评语是写给孩子的成长档案，不是给家长的告状单」**
- 定义：期末评语的读者首先是孩子——"被看见、被理解"的温度感是第一属性；向家长"反映问题"的功能放家长会与当面沟通，不塞进评语。
- 依据：本技能边界"评语是写给孩子的成长档案，不是给家长的'告状单'"。
- 应用：每条评语先过"孩子读到会怎样"测试；改进方向用"你可以更好"句式不用"你还不够"。
- 局限：确需家长知情的事项——用"家校配合建议"栏单独呈现，不混入孩子评语正文。

**模型2：「具体事例是评语的血肉」**
- 定义："你很有毅力"是空话，"运动会你坚持跑完800米"是记忆——每条评语至少一个具体事例，学生才能确认"老师真的看见了我"。
- 依据：本技能四原则之"真实：有具体事例支撑"；生成依赖输入的"每生一两个关键词"。
- 应用：无具体事例的评语段退回补素材；事例来自教师观察（不是编造的"通用场景"）。
- 局限：一个班几十人，事例记忆有限——"关键词+一次追问"采集法（名单发下去每人补一件事）。

**模型3：「学段适配决定语气与深度」**
- 定义：小学低段鼓励为主（孩子能懂的话）、高段加自我反思引导、初中护住自尊（青春期批评要委婉有建设性）——同一件事，三个学段的写法不同。
- 依据：本技能学段适配三档设计。
- 应用：批量生成按学段统一定调；跨学段班级（如九年一贯）逐人核对学段档。
- 局限：同班学生成熟度有差异——学段是默认档，教师可逐人微调。

## 决策启发式

| # | 触发情况 | 动作 |
|---|---|---|
| H1 | 只给名单没给关键词 | 出"关键词采集表"（每人一两个词+一件事）——素材先行 |
| H2 | 关键词是"内向/成绩差"类标签 | 追问具体事例——标签不是素材，事例才是 |
| H3 | 批量生成后个别不像 | 单独重生成该生——批量是效率工具不是质量借口 |
| H4 | 家长要求"多写问题" | 温和说明评语定位；需要深谈的约面谈——不在评语里加码 |
| H5 | 评语出现AI味套话（"该生"） | 重写——第二人称"你"，像班主任说话不像档案鉴定 |

## 检查点

🔴 **动手前**：学段确认；每生素材（关键词+事例）到位率检查。

🔴 **中途**：每条评语含至少一个具体事例；语气过学段适配检查。

🔴 **交付前**：四原则逐条过（真实/温暖/建设性/成长导向）；敏感信息脱敏复核。

## 输出规范

- 每生评语120-200字：具体事例+肯定特质+建设性方向（"你可以更好"句式）。
- 批量输出含清单（学号-姓名-评语-素材依据）；素材依据栏供班主任复核（不出现在交付评语里）。
- 低段口头化、高段引导反思、初中委婉建设——学段语气说明附批量稿头部。

## 失败与异常处理

1. **素材不足**：出采集表先收素材——宁慢一天，不出千篇一律。
2. **事例记不清**：生成时留【补一件事：____】占位——教师补齐再定稿。
3. **敏感情况**（家庭变故学生）：评语只写正向稳定内容——特殊情况沟通走线下。
4. **超范围**（素质报告册全表填写）：本技能管评语栏——其他栏目转学籍口径。

## 边界

- **管**：期末评语批量生成（学段适配+个性化）、素材采集表、修改润色。
- **不管**：素质报告册其他栏目；家长会发言（转parent-communication）；成绩分析。
- **不替代**：班主任对每个学生的最终判断——AI草稿，签名负责在人。
- **接不住就转**：家校沟通话术转 parent-communication。

## 分工说明

与parent-communication分工：评语管学期定稿的成长档案，那边管日常家校沟通话术；两者"保护性语言"原则同源。
