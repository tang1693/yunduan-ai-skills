# 来访接待方案 v2.0

> 让每一次来访都井井有条——从"谁要来"到"怎么送走"，一张方案说全。

## 执行规范

老师说"帮我做个接待方案"即可。缺信息先问：谁来访、什么目的、什么时间、多少人、什么规格。信息齐了，生成完整接待流程，六段不缺：

1. 接待方案（总体安排）
2. 议程（时间到分钟的流程）
3. 人员分工（谁接待、谁讲解、谁拍照）
4. 场地安排（会议室/参观路线）
5. 用餐安排（规格、位置）
6. 宣传安排（新闻稿、照片、简报）

**四类场景，规格不同**
- 领导调研：突出汇报材料 + 问题整改态度
- 兄弟学校参观：突出经验分享 + 可复制亮点
- 专家评估：突出材料准备 + 数据支撑
- 日常来访：简洁流程 + 基本礼仪

## 核心心智模型

**模型1：「接待方案是流程编排，规格由规定定」**
- 定义：六段方案（方案/议程/人员/场地/用餐/宣传）是通用骨架，具体规格（陪同层级/用餐标准/场地布置）按学校接待规定执行——AI编排流程，不定规格。
- 依据：本技能边界"方案是起点框架，具体规格按学校接待规定定"；公务接待管理规定。
- 应用：规格相关字段标注"按学校规定填"；规定没有的场景给常见做法参考并标注"参考值"。
- 局限：不同来守权属（上级检查/兄弟学校/合作单位）规格不同——按四类场景分档给。

**模型2：「四类场景四套重心」**
- 定义：领导调研重汇报材料与问题整改态度、兄弟学校重经验分享与可复制亮点、专家评估重材料准备与数据支撑、日常来访重简洁礼仪——重心错配（给调研团安排成参观游）比缺一段更糟。
- 依据：本技能四类场景规格设计。
- 应用：先问来访类型再出方案；每类场景的"重点段"加详版（调研→议程与汇报材料；评估→材料清单与数据）。
- 局限：复合型来访（领导带专家）按最高规格档走，内容按复合准备。

**模型3：「分钟级议程是接待的交付标准」**
- 定义：议程表排到分钟（几点几分到哪、谁陪同、看什么、讲什么）——"上午参观、下午座谈"这种粗议程现场必乱。
- 依据：本技能执行规范"议程（时间到分钟的流程）"。
- 应用：每议程项四要素（时间/地点/内容/责任人）；行进路线标注衔接点（A点到B点几分钟）。
- 局限：领导行程临时变动常见——议程附"弹性预案"一栏（压缩哪段/跳过哪站）。

## 决策启发式

| # | 触发情况 | 动作 |
|---|---|---|
| H1 | 没给来访五要素（谁/为何/何时/多少人/什么规格） | 逐项补问——规格可由学校规定推导 |
| H2 | 领导调研类 | 议程+汇报材料双详版；附整改问题清单准备提示 |
| H3 | 兄弟学校参观 | 亮点路线+可复制经验材料；控制"机密区"不进路线 |
| H4 | 涉及领导行程与安全保密信息 | 提示内部传阅不外发——方案按敏感文件管理 |
| H5 | 时间很紧（明天就来） | 出"最简合规版"六段（每段最短可执行），事后再补详案 |

## 检查点

🔴 **动手前**：来访类型、目的、时间、人数、规格五要素确认。

🔴 **中途**：六段不缺段；场景重心段加详版。

🔴 **交付前**：议程排到分钟且每项有责任人；宣传段经来访方同意（是否可拍照报道）。

## 输出规范

- 六段方案：总体安排/分钟级议程（时间-地点-内容-责任人四要素）/人员分工（接待/讲解/摄影）/场地与路线（含衔接时长）/用餐安排（规格按学校规定）/宣传安排（含来访方同意确认）。
- 四类场景的侧重段加"详版"标注；敏感版注明"内部传阅"。

## 失败与异常处理

1. **要素不全**：补问；规格未知按学校接待规定推导并标注依据。
2. **行程临时变动**：启用议程弹性预案（预设的压缩/跳过方案）——不现场重排。
3. **来访方要求超出学校规定规格**：如实说明规定约束——超规格接待需审批，AI不出变通方案。
4. **超范围**（涉外接待）：转外事口径——涉外有专门规定，本技能不覆盖。

## 边界

- **管**：四类来访的六段接待方案、分钟级议程、人员分工编排。
- **不管**：接待规格审批（学校规定）；涉外接待（外事口径）；费用报销（转finance-review）。
- **不替代**：办公室主任的现场调度——方案防乱，救场靠人。
- **接不住就转**：接待后的新闻稿转 news-writing。

## 分工说明

与news-writing（新闻稿）衔接：接待宣传段的内容生产转那边；本技能管接待流程编排。
