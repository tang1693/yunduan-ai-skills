# 四维三同协同模板手册

> 参考手册：老师说"要一份主辅讲配合表 / 学情采集表"，直接给可填模板。

## 一、同备模板

1. **辅讲学校学情采集表**：学校/班级、学生整体水平、班级氛围、已有知识基础、预计学习难点、本校可用资源、驻地教师建议的调整。
2. **驻地教师适配建议单**：本校学情特点、需调整内容（降难度/加铺垫/换例题/其他）。
3. **外景场景融合单**：可用的真实场景、与课题的关联点、外景活动设计。

## 二、同研模板

1. 三大教研模式选型指南
2. 嵌入式教研半天流程
3. 课例式 4 轮研磨模板
4. 四维课堂观察量表

## 三、同教模板

1. 四维暗号系统
2. 技术检查单（课前 30 分钟）
3. 课中应急响应表
4. 授课复盘模板
5. 驻地教师配合记录表

## 四、思维课堂工具

思维可视化工具推荐 + 思维课堂自查清单。

## 五、学情分析模板

各校学情数据采集表。

## 核心心智模型

**模型1：「模板是给手工协作兜底的，不是给AI用的」**
- 定义：手册里全部模板（学情采集表/适配建议单/暗号系统/观察量表等）服务老师**手工填写**——AI生成方案走对应设计师工具，手册管"没有AI在场时协作不断线"。
- 依据：本手册定位"老师手工填写的模板"；与四维设计师系列的分工条款。
- 应用：用户要"生成方案"时路由到设计师工具；要"打印空白表"时本手册直接给。
- 局限：模板与AI工具共用一套字段——字段变了两边同步改，防止两套语言。

**模型2：「五类模板对应三同全流程」**
- 定义：同备（学情采集/适配建议/外景融合）、同研（模式选型/教研流程/观察量表）、同教（暗号/检查单/应急/复盘/配合记录）、思维工具、学情分析五类，覆盖"课前-课中-课后"闭环——缺哪类，对应环节的协作就退回口口相传。
- 依据：手册目录结构（一至五类）。
- 应用：按环节查表取用；新场景缺模板时记录需求，按月增补进手册。
- 局限：模板是起点框架——按本校实际增删字段，不搞一刀切（边界条款）。

## 决策启发式

| # | 触发情况 | 动作 |
|---|---|---|
| H1 | 用户说"要一份XX表" | 直接给对应可填模板（含字段说明） |
| H2 | 用户要"生成/设计方案" | 路由到对应设计师工具，本手册不管生成 |
| H3 | 要的模板手册没有 | 登记需求+给最接近的模板改造建议，按月增补 |
| H4 | 模板字段与本校实际不符 | 提示"可增删字段"——模板是框架不是法规 |
| H5 | 要整套手册 | 按五类给全套（打印友好版） |

## 检查点

🔴 **动手前**：确认要的是"空白模板"还是"生成方案"——前者给表，后者转工具。

🔴 **中途**：模板字段齐全（对照手册目录同类模板的必备字段）。

🔴 **交付前**：模板可直接打印/复制使用，无需二次加工。

## 输出规范

- 单模板：字段名+填写说明一行+空位，一页以内；表头含使用场景与填写人。
- 成套模板：按"同备/同研/同教/思维/学情"五类分目录输出，注明每类的使用时点。
- 模板均附一句"可按本校实际增删字段"的提示。

## 失败与异常处理

1. **要的模板不存在**：登记需求，给最接近模板的改造建议——不硬编一个没验证过的表。
2. **字段歧义**（老师问"这一栏填什么"）：给一行示例值，示例来自真实场景。
3. **要电子化版本**：说明手册以打印使用为主；电子填写建议用表格工具转录，字段不变。
4. **超范围**（要AI代填）：说明手册是手工模板，生成走设计师工具。

## 边界

- **管**：五类协同模板的提供、字段说明、增补维护。
- **不管**：方案生成（转四维设计师系列）；模板的校本化改造（老师自己定）。
- **不替代**：老师的现场判断——模板降低协作成本，不替代协作本身。
- **接不住就转**：生成方案转对应设计师工具。

## 分工说明

本手册管"手工填的表"；四维协同备课/授课/教研设计师管"AI生成的方案"；两者字段同源，改字段双边同步。
