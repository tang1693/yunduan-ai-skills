# 卫生检查 v1.0

> 卫生天天查——查得准、评得公，孩子才当回事。

## 执行规范

老师说"帮我做卫生检查"即可。缺信息先问：查哪个区域（教室/包干区）、什么频率。信息齐了，做三样：

1. 卫生检查表：地面、桌椅、黑板、门窗、讲台、卫生角等分项。
2. 评分标准：每项分值、扣分点说清楚。
3. 评比结果：各班得分、排名、问题清单。

## 核心心智模型

**模型1：「扣分要具体到'哪一项、什么原因'」**
- 定义：笼统扣分（"卫生差-2分"）不可申诉也不可改进——扣分必须落到具体项（"窗台积尘"）与原因（"未按日清单保洁"），评比才有教育意义而不是挑刺。
- 依据：本技能边界"扣分要具体到哪一项、什么原因，不笼统扣"。
- 应用：检查表每项独立打分；扣分记录三要素（区域/问题/建议）。
- 局限：保洁水平确有整体差异——总分反映差异，但改进入口永远在具体项。

**模型2：「检查标准公开，评比才有公信」**
- 定义：评分标准（分值/扣分点）事先公开给各班——标准透明，结果才服气；事后才亮标准必然生怨。
- 依据：本技能边界"评分标准公开透明"。
- 应用：学期初发布评分标准；学期中标准不变更（确需调整的下学期生效）。
- 局限：突击检查场景（防临时突击打扫）——检查时间可突击，标准仍须是公开的那套。

**模型3：「评比指向改进，不针对学生」**
- 定义：卫生检查的结果用于班级改进与良性评比，不用于点名批评个别学生——"某某值日不认真"式的输出违反隐私与教育原则。
- 依据：本技能边界"检查结果用于改进和评比，不针对个别学生"。
- 应用：结果通报到班级问题清单（不到人）；连续落后的班级给帮扶建议（值日流程优化）而非通报批评。
- 局限：屡次后进确需约谈——那是班主任的工作方法，不进检查技能输出。

## 决策启发式

| # | 触发情况 | 动作 |
|---|---|---|
| H1 | 没说检查区域与频率 | 补问（教室/包干区×日/周/月） |
| H2 | 要"突击检查版" | 可以——时间突击，标准仍是公开版 |
| H3 | 扣分被质疑 | 按记录三要素（区域/问题/建议）回溯——记录清楚质疑自消 |
| H4 | 连续垫底班级 | 输出帮扶建议（值日分工/工具/时段）——不输出批评通报 |
| H5 | 要给个别学生贴"值日差"标签 | 拒绝——结果只到班不到人 |

## 检查点

🔴 **动手前**：区域、频率确认；评分标准版本核对（公开版）。

🔴 **中途**：检查表分项独立（地面/桌椅/黑板/门窗/讲台/卫生角）；每项分值明确。

🔴 **交付前**：评比结果含问题清单（具体项+建议）；无针对个人的表述。

## 输出规范

- 三件输出：分项检查表（六区项×分值×扣分点说明）/评分标准（学期初公开版）/评比结果（各班得分+排名+具体问题清单+改进建议）。
- 结果通报模板含"进步榜"（比上次提升的班）——评比不只比高下，也比特进步。

## 失败与异常处理

1. **信息不全**：补问区域与频率；按教室日检默认出。
2. **标准争议**（某班认为扣分不当）：按记录三要素复核——标准有歧义的项下轮修订，本轮不追溯改分。
3. **检查力量不足**：给学生检查员版简化表（打勾制），教师抽查制衡。
4. **超范围**（食品安全/校医室卫生）：转食堂管理/卫生条线口径——本技能管教学区卫生。

## 边界

- **管**：教室/包干区卫生检查表、评分标准、评比结果、改进建议。
- **不管**：食堂卫生（转cafeteria-management）；传染病防控（转校医口径）；个别学生的教育处理（班主任职责）。
- **不替代**：检查的现场执行——AI出表与汇总，检查靠人走。
- **接不住就转**：星级班级的汇总评比转 star-class-review。

## 分工说明

与star-class-review（星级班级）分工：本技能出卫生维度数据，那边汇总卫生/纪律/考勤多维出星级——数据接口是"各班各维度得分"。
