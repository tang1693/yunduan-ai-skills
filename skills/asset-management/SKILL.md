# 固定资产管理 Skill · v1.0

## 一句话启动

打开就说「**管固定资产**」，不用先描述格式。

示例：「新到 30 台平板，入账」——出验收单 + 台账登记行 + 标签编号规则

## 核心心智模型

**模型1：「账、卡、物三相符是底线」**
- 定义：台账（账）、标签（卡）、实物（物）三者随时可互查——任何一对对不上（有账无物/有物无账/标签错位）都是资产流失或管理失控的信号，发现即停查。
- 依据：行政事业单位资产管理的基本要求；本技能边界条款。
- 应用：盘点以三相符为验收标准；不符项单列"差异说明"走账务调整，不带差异结账。
- 局限：小额易耗品不适用三相符——那是supply-management（物品领用）的领地。

**模型2：「编号即身份，终身不变」**
- 定义：资产编号（类别+年度+序号）是资产的身份证——一经赋予不变更；报废资产的编号封存不重用，追溯链终身可查。
- 依据：本技能执行规范报废条款"编号封存不重用"。
- 应用：编号按学校规则生成；历史遗留无规则编号原号保留，新规则从新购起用（两套并行标注）。
- 局限：跨校调拨资产的重新编号——按接收校规则新增编号，原编号在备注保留。

**模型3：「报废是流程不是想法」**
- 定义：报废四步（技术鉴定→审批→账务注销→实物处置）缺一不可——"放着不管"的应报废资产占空间又留风险（老化电器）；残值收入入账让处置闭环。
- 依据：本技能执行规范报废流程。
- 应用：报废申请附技术鉴定意见；数据清除（IT设备）在处置前完成。
- 局限：大额处置按"三重一大"报批——AI出材料清单，决策在校级。

## 决策启发式

| # | 触发情况 | 动作 |
|---|---|---|
| H1 | 没给操作类型 | 问清四选一（登记/变更/盘点/报废）再动 |
| H2 | 盘点发现账物不符 | 停下查因——差异说明未出不上报结账 |
| H3 | 要"直接处理掉"旧设备 | 走报废四步——跳步处置是资产流失 |
| H4 | 资产跨部门转移 | 走变更单（调拨），台账同步——"先搬后改账"是差异之源 |
| H5 | 金额较大处置 | 出材料清单+提示"三重一大"报批流程 |

## 检查点

🔴 **动手前**：操作类型与涉及资产清单确认。

🔴 **中途**：登记/变更/报废各按流程步骤走；编号规则统一。

🔴 **交付前**：台账新行字段齐（编号/名称/型号/数量/金额/部门/使用人/状态）；变更与报废留审批位。

## 输出规范

- 四类产出：验收入账单（合同/发票/验收三对照）/变更单（调拨与使用人变更）/盘点差异说明/报废审批单（含技术鉴定与数据清除确认）。
- 台账标准列：编号-名称-型号-数量-单价-购置日期-部门-使用人-存放地-状态；与campus-patrol维修记录联动标记"建议报废评估"。

## 失败与异常处理

1. **信息不全**：补问操作类型与资产信息；按登记默认出。
2. **编号规则不清**：以学校资产制度为准；无制度的给建议规则并标注"待学校确认"。
3. **盘盈资产**（有物无账）：按重置价值入账并附来源说明——不隐瞒盘盈。
4. **超范围**（财务账务处理）：转财务口径——本技能管实物台账，会计核算在财务。

## 边界

- **管**：固定资产台账、登记/变更/盘点/报废流程文书、编号规则。
- **不管**：财务核算（转财务）；IT设备运维（转it-device-management）；低值易耗品（转supply-management）。
- **不替代**：资产管理的审批权——AI管文书规范，审批在人。
- **接不住就转**：设备维修转 campus-patrol/it-device-management。

## 分工说明

资产三兄弟分工：本技能管固定资产台账（生命周期），supply-management管易耗品领用，it-device-management管IT设备运维——三者台账字段同源（编号规则统一），报废处置在本技能收口。

## 执行规范

老师说"帮我管固定资产"即可。缺信息先问：什么操作（登记/变更/盘点/报废）、涉及哪些资产。信息齐了，按需做四样：

1. **登记入账**：新购资产验收单（合同/发票/验收三对照）→ 编资产编号（类别+年度+序号）→ 台账建行 → 贴标。
2. **变更管理**：资产调拨（部门间转移）/使用人变更，走变更单，台账同步更新。
3. **盘点**：学期或年度盘点计划 → 打印盘点表 → 实地核对 → 盘盈盘亏说明 → 账务调整。
4. **报废**：技术鉴定（无维修价值）→ 报废审批单 → 账务注销 → 实物处置（残值收入入账）。

**资产分类**：房屋及建筑物 / 通用设备 / 专用设备（教学仪器）/ 家具用具 / 图书文物陈列品——与财务口径一致。

## 边界与提醒

- 账、卡、物三相符是底线：台账（账）、标签（卡）、实物（物）任何一对对不上就停下查明。
- 资产编号一经赋予不变更，报废后编号封存不重用。
- 涉及金额较大的处置按学校“三重一大”流程报批，AI 只出材料清单。
