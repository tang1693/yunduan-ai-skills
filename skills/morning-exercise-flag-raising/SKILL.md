# 升旗仪式与课间操组织 v1.0

> 每周一升旗、每天课间操——流程规范、讲话有分量、集合不散乱。

## 执行规范

老师说"帮我组织升旗 / 写国旗下讲话 / 排课间操"即可。缺信息先问：什么主题、哪个年级、什么场合。信息齐了，做四样：

1. 升旗仪式流程：出旗 → 升旗奏唱国歌 → 国旗下讲话 → 退场，环节顺序和礼仪要求写清。
2. 国旗下讲话稿：主题明确、篇幅合适（3-5 分钟）、贴合学生年龄，传递正确价值观。
3. 集合整队方案：入场路线、站位、口令。
4. 评比表：纪律、队列、礼仪分项。

## 核心心智模型

**模型1：《国旗法》《国歌法》是流程的宪法」**
- 定义：升旗仪式的每个动作（出旗/升旗/奏唱国歌/礼毕）有法定规范——升降旗时间、奏唱要求、在场人员礼仪，按法条执行不随意简化、不自行创造"改良动作"。
- 依据：《国旗法》《国歌法》相关规定；本技能边界"升降旗动作、奏唱要求不写错、不随意简化"。
- 应用：流程文案引用法条口径；AI拿不准的动作细节标【按规定】留给主管教师核实。
- 局限：法条管底线不管优劣——仪式的教育质量（讲话内容/组织效率）由设计决定。

**模型2：「国旗下讲话是每周最重要的3分钟德育课」**
- 定义：全校集中、注意力最高的3分钟——讲话稿质量决定这3分钟是德育黄金还是无效集会；主题贴合时事与学段、篇幅3-5分钟、传递正确价值观是三条硬线。
- 依据：本技能执行规范讲话稿三要求。
- 应用：讲话稿按"主题明确+学段适配+价值观正向"三检；政治性表述引用权威说法不自行发挥。
- 局限：讲话效果依赖演讲者——AI管稿不管气场。

**模型3：「集合效率是仪式感的隐形地基」**
- 定义：入场路线、站位、口令决定集合用8分钟还是3分钟——混乱的集合在讲话开始前就消耗完了仪式感。
- 依据：本技能集合整队方案设计。
- 应用：方案含入场路线图（分楼栋/分批）、站位坐标（班级固定位）、退场顺序；开学首月加练集合。
- 局限：场地约束各校不同——按本校平面图定路线，AI给结构方法。

## 决策启发式

| # | 触发情况 | 动作 |
|---|---|---|
| H1 | 没给主题/年级/场合 | 补问三要素——讲话稿高度依赖学段 |
| H2 | 讲话稿要谈敏感时事 | 转官方口径原文——引用权威表述，不自行评论 |
| H3 | 要"创新仪式流程" | 仪式法定环节不动，可创新的是组织效率与配套活动 |
| H4 | 课间操要评比 | 出纪律/队列/到位率三维评比表——评比促规范不促表演 |
| H5 | 低年级集合慢 | 分批入场+教师定点引导——效率问题用编排解决不用批评解决 |

## 检查点

🔴 **动手前**：主题、年级、场合三要素确认。

🔴 **中途**：仪式流程逐项对照法规口径；讲话稿三检（主题/学段/价值观）。

🔴 **交付前**：集合方案含路线-站位-口令三件；无法条依据的动作标【按规定】。

## 输出规范

- 四件输出：升旗仪式流程（出旗-升旗奏唱-讲话-退场，各环节礼仪要求明确）/国旗下讲话稿（3-5分钟篇幅，学段适配）/集合整队方案（路线+站位+口令）/评比表（纪律/队列/礼仪分项）。
- 讲话稿政治性表述附出处；流程文案与法规口径逐字核对。

## 失败与异常处理

1. **信息不全**：补问三要素；按当周常规主题出框架版。
2. **天气突变（户外仪式改室内）**：出室内版流程（班级教室收看/奏唱要求不变）——礼仪要求不因场地降格。
3. **讲话稿政治表述拿不准**：留【按规定核实】标记——不带疑问上台。
4. **超范围**（大型活动开幕式）：转活动策划类流程——升旗环节按本技能规范嵌入。

## 边界

- **管**：升旗仪式流程、国旗下讲话稿、课间操组织、集合整队方案、评比表。
- **不管**：大型活动的整体编排（转活动策划）；少先队仪式（转young-pioneers——队礼队歌另有规范）。
- **不替代**：仪式主持与现场执行——AI出方案，主持执行由教师负责。
- **接不住就转**：涉及团队仪式转 young-pioneers。

## 分工说明

与young-pioneers（少先队）分工：升旗与课间操归本技能；入队仪式/队活动/队干部竞选归那边；两者在"活动方案结构"上同源。
