# 新教师培训 Skill · v2.0

## 一句话启动

打开就说「**带新教师**」，不用先描述格式。

## 核心心智模型

**模型1：第一年的核心任务是"活下来并站稳讲台"**——新教师培训的目标不是培养教育家，是帮新人在真实课堂里建立基本胜任感：能管住纪律、能上完整的课、能应对家长。心理存活（不崩溃、不逃离）与技能起步并重。依据：教师专业发展阶段论（生存关注期）；新教师离职高发期的归因研究。应用：培训内容按"明天就要用"排序（纪律管理/常规流程/家长沟通先行），理念文化课精简。局限：部分成熟人才转岗入职（有经验教师），按"适应性培训"变体处理，不走全流程。

**模型2：做中学，培训只是脚手架**——讲座听十次不如上一次课被人点评一次。集中培训压缩到最短，重心放岗位实践：跟岗听课→模仿上课→被听被评→独立上课。依据：教师学习的实践性；成人学习721法则。应用：培训方案中实践类活动（跟岗/磨课/试讲）学时占比不低于60%。局限：师德师风、安全责任等底线内容必须集中讲授并考核，不能只靠实践体会。

**模型3：双导师=教学+班级两条腿**——学科导师管"课上得好不好"，班主任导师管"班带得稳不稳"，两条线独立推进互不替代。依据：教学胜任与班级管理胜任是两个能力簇；单导师制容易顾此失彼。应用：每位新教师配双导师，两线任务单与评价分开。局限：小规模学校可一人兼双导，但任务单仍分两线记录。

## 决策启发式

1. **第一课比第一讲重要**——新教师入职最先得到的应是"开学第一周怎么办"清单（座位表/第一句话/第一个规矩），不是办学理念。
2. **本校骨干优先于外请专家**——骨干讲的是"在这所学校怎么办事"，专家讲的是"教育应该怎样"；第一年先解决前者。
3. **留白课时是成长投资**——新教师第一年不排满课，留出的时间用于听课与被听课，这比多上几节课值钱。
4. **每周一次"最近一件难事"**——新教师周会不谈感想只谈难题，当场给对策；积攒一学期的难题清单就是下一年的培训教材。
5. **转正考核看证据链**——出勤+汇报课+教案+模拟家长沟通四件证据齐了再鉴定，不凭印象。

## 执行规范

老师说"帮我做新教师培训方案"即可。缺信息先问：几位新教师、什么学科、入职时间、培训周期。信息齐了，做四样：

1. 培训方案：集中培训（入职第一周，校情文化/规章制度/师德师风/安全须知）+ 岗位实践（第一学期，课堂教学/班级管理/家校沟通）两段式。
2. 课程表：模块 / 主讲人 / 时长 / 形式（讲座/工作坊/跟岗）/ 考核方式——优先安排本校骨干讲实操，少请外部理论课。
3. 导师安排：与青蓝工程衔接，每位新教师配学科导师+班主任导师双导师。
4. 考核评价：培训出勤 + 结业考核（一节汇报课+一份教案+一次模拟家长沟通）+ 转正鉴定意见。

## 检查点

🔴 **动手前**：确认新教师构成（应届/转岗/有经验）与人数——不同构成的方案重心不同。

🔴 **中途**：课程表实践类占比核算——低于60%回到排课重排。

🔴 **交付前**：转正考核四件证据的判定标准写明（合格线是什么），不留"视情况而定"。

## 输出规范

- 培训方案/课程表/双导师任务单/考核表四件套齐全，可直接打印。
- "开学第一周怎么办"清单单独输出（新教师最急需的一页纸）。
- 周会难题记录模板附后，学期末汇编成《新教师难题TOP20》反哺培训。

## 失败与异常处理

1. **新教师中期严重不适（哭/想辞职）**：立即转心理支持+校长面谈，培训进度暂停；人的状态优先于培训计划。
2. **导师与新教师节奏不合**：学期中允许调整一次导师配对，按青蓝工程的调整机制走。
3. **新教师人数过少（1-2人）**：集中培训模块与区级新教师培训合并，校内只做跟岗与双导师部分。
4. **转正考核不合格**：按人事规定延长试用，考核证据与鉴定意见留痕归档，程序透明。

## 边界与提醒

- 新教师第一年不安排满课时——留出听课与磨课时间，这对成长最值钱。
- 培训内容重实操轻理论：新教师缺的是"明天上课怎么上"，不是教育学概论。
- 转正考核不合格的按人事规定延长试用，程序透明、依据留痕。
- **不替代**：导师的真实带教——AI 出方案与脚手架，师傅的言传身教没法程序化。
- **接不住就转**：师徒结对细节转 mentoring-program；培训学时记录转 teacher-training-record。
