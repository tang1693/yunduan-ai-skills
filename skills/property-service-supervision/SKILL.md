# 物业服务监督 Skill · v2.0

## 一句话启动

打开就说「**督物业服务**」，不用先描述格式。

## 核心心智模型

**模型1：合同是唯一的裁判尺**——评价物业好不好，唯一标准是"合同写了什么、做到了没有"，不是"感觉好不好"。监督的起点是把服务合同拆成可检查的条款清单（保洁频次/绿化标准/维修响应时限/安保巡逻路线）。依据：合同管理与绩效管理的基本原则；"感觉差"引发的纠纷九成源于合同没拆解。应用：所有考核表从合同条款派生，检查项标注"依据合同第X条"。局限：合同未覆盖的临时需求，走"增值服务协商"通道，不硬塞进考核。

**模型2：检查看痕迹，不看现场表演**——保洁做得好不好，看的是"非检查时段的常态"，不是检查前一小时的突击。痕迹管理：巡检记录、耗材领用、报修闭环时间等过程数据比现场光亮更可信。依据：服务行业的常态质量规律；"迎检式服务"是物业行业的普遍问题。应用：考核以过程记录+随机时点抽查为主，提前通知的检查只用于安全底线项。局限：随机抽查需要学校侧投入人力，频次按重点区域优先。

**模型3：扣分不是目的，整改闭环才是**——发现问题的价值在于"限期整改→复查销号"。每月考核报告的核心不是分数，是"未闭环问题清单+责任+期限"。依据：PDCA闭环；物业纠纷升级的共性是"问题提了没人跟"。应用：月度例会第一个议题永远是上月未闭环问题，逐条过。局限：物业公司人员流动大，闭环提醒要同步到具体责任人而非只发函。

## 决策启发式

1. **合同拆解先于考核表**——没有条款清单的考核是印象分，印象分在结算扣款时站不住。
2. **报修响应超时是第一红线**——维修响应时限是合同里最可量化、最影响师生体验的条款，先抓这条。
3. **过程记录月度归档**——保洁巡检表/维修工单/安保巡逻记录按月归档，结算与续约谈判时是弹药库。
4. **扣款前先给整改机会**——首次违约发整改通知，再犯才扣款；流程正义换来的是结算时少扯皮。
5. **续约评估提前三个月启动**——用足一个学期的过程数据做去留决定，不等到到期前一个月仓促决定。

## 执行规范

老师说"帮我督物业"即可。缺信息先问：监督什么（保洁/安保/维修/绿化）、日常考核还是月度结算还是续约评估。信息齐了，按需做四样：

1. 合同条款拆解表：服务内容 / 合同标准 / 检查方式 / 检查频次 / 考核权重——从合同到考核表一步到位。
2. 月度考核表：检查项 / 合同依据 / 本月结果 / 扣分/扣款 / 整改期限——分数与条款对应。
3. 整改闭环单：问题 / 责任人 / 期限 / 复查结果 / 销号——月度例会的核心议题。
4. 续约评估报告：全年考核趋势 / 未闭环问题历史 / 师生满意度 / 续约建议——数据说话。

## 检查点

🔴 **动手前**：拿到服务合同文本——没有合同的监督按"行业标准+双方确认的临时标准"出清单，并标注非合同口径。

🔴 **中途**：考核表每项必须能回溯到合同条款或双方书面确认的标准，"我觉得应该"不算依据。

🔴 **交付前**：未闭环问题清单单独成页——扣了分没跟整改的问题，下月还会出现。

## 输出规范

- 四类交付物均标注合同依据（条款号或书面确认日期），可直接用于结算与谈判。
- 月度考核一页汇总+明细附表；续约评估不超过三页，结论先行。
- 所有扣分项给"整改后可恢复"路径——考核是为了服务变好，不是为了省物业费。

## 失败与异常处理

1. **物业经理频繁更换**：建立"监督档案随合同走"机制——每次对接更新责任人清单，历史问题清单当面交接签收。
2. **物业抱怨亏损要撤场**：区分真亏损与谈判策略——调出全年考核数据与合同单价对照；真亏损走合同变更协商，策略性哭穷用数据顶回。
3. **学校自用区域与物业区域责任不清**：出"责任分区图+界面清单"（如教室内部 vs 公共走廊），模糊地带书面确认归一方。
4. **突击整改应付检查**：明说"本次只记录常态"——检查时点随机化，同一问题连续两次出现在整改通知里，按重复违约处理。

## 边界与提醒

- 本技能管监督与考核，不替代学校与物业的合同谈判——AI 出数据与依据，谈判桌是总务主任的。
- 物业人员的人事纠纷（用工/社保）不介入，只按合同考核服务输出。
- **不替代**：电梯/消防等特种设备的法定检测——那是专业机构的事，物业只负责日常巡查记录。
- **接不住就转**：维修单闭环进校园巡查台账（campus-patrol）；安全隐患转 hazard-inspection。
