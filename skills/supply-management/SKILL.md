# 物品领用管理

本包仅整理材料。本校签字、补签期限、盘点频次与库存阈值以经确认的现行制度为准；正文管理建议须由总务人员选用，不能作为跨校统一规定。未提供制度时标记待确认，不自动退单、发放或采购。

## 一句话启动

打开就说「**管物品领用**」，不用先描述格式。

## 核心心智模型

**模型1：申领与发放分离（双人制衡）**——申请人填单、保管人发货、两人签字，任何单人完成的领用都是库存失真的起点。依据：内部控制的不相容岗位分离原则；学校物品"说不清去哪了"的共性根因。应用：领用单必须有申请人与保管人双签；代领需书面授权。局限：紧急教学用品可先发后补签（24小时内），补签率进月报。

**模型2：先进先出（FIFO）与最小库存**——耗材按批次先进先出，库存设定上下限：低于下限触发采购申请，高于上限暂停采购。依据：库存管理经典原则；学校仓库"粉笔过期三年、A4纸断货两天"并存的现象。应用：台账加"批次/入库日期"字段，出入库按入库先后排序；月报列超储与临期预警。局限：学期性波动大的品类（开学季）单独设季节性安全库存。

**模型3：领用数据是预算的舌头**——各部门领用历史是下一年度预算申报的最硬依据，"去年实际用了多少"比"今年想要多少"有力。依据：零基预算与历史基线法。应用：每学期出部门领用汇总，年底出年度领用分析（品类/部门/趋势）供预算会议用。局限：新增项目（新实验室/新科室）无历史数据，按定额标准另估。

## 决策启发式

1. **双签的领用单才有效**——一人经手的领用，盘点差异时永远说不清。
2. **低值易耗品按"定额包"管理**——粉笔/粉擦/白板笔按班级/教研组月定额打包发放，省去逐次登记的繁琐又不失控。
3. **按本校制度核对重要物品领用**——先核对本校现行物资分类、金额口径、审批权限和归还要求，记录制度名称、版本与条款；没有依据时只整理申请材料，不自行设定100元等统一阈值，不代替保管人批准发放。
4. **每月盘点A类，每学期全盘**——高频领用品类月盘，全部学期盘，差异当月查清不结转。
5. **采购申请从台账里长出来**——申購量=定额消耗×在校规模-当前库存-在途，不从台账出发的采购申请都是拍脑袋。

## 执行规范

老师说"帮我管物品领用"即可。缺信息先问：什么物品（办公用品/清洁用品/教学耗材/劳保用品）、要做什么（领用登记/库存管理/采购申请/盘点）。信息齐了，按需做四样：

1. 领用登记：日期 / 领用部门 / 申请人 / 物品 / 数量 / 用途 / 保管人 / 双签。
2. 库存台账：物品 / 规格 / 批次 / 入库日期 / 库存量 / 安全库存上下限——FIFO排序。
3. 采购申请：从台账自动推导的采购清单（消耗定额-库存-在途），附历史领用依据。
4. 盘点与差异：月度A类盘点表 / 学期全盘表 / 差异说明与处理意见。

## 检查点

🔴 **动手前**：确认物品分类口径——低值易耗（定额包）、贵重（凭用途）、大宗（采购计划），三类管理方式不同。

🔴 **中途**：领用单双签栏不得空——代领、补签的标注清楚，月报汇总补签率。

🔴 **交付前**：采购申请必须带历史领用数据——没有依据的申请退回补依据。

## 输出规范

- 四类表单字段齐全可直接打印；库存台账含批次与上下限预警列。
- 月度领用汇总按部门出，年度分析含趋势与结构（品类占比）。
- 差异处理意见写到"查明原因+处理方式+防范措施"三要素，不写"待查"了事。

## 失败与异常处理

1. **教师嫌双签麻烦绕着走**：定额包+月度集中发放减少逐次登记；真贵重物品坚持双签——麻烦的流程只留给真正需要管住的品类。
2. **库存账实不符**：差异当月查明，查明前该品类冻结出入库；查不明按学校财务制度报批处理，不带病运行。
3. **学期末突击领用**：定额包按月控制天然抑制；确有结余指标的部门按"实际需要"复核，不为花钱而领。
4. **供应商断货**：安全库存下限就是为这事设的——触发紧急采购流程，同时评估替代品类。

## 边界与提醒

- 本技能管消耗性物品的领用流转，不管固定资产（转 asset-management）、不管食堂食材（转 cafeteria-management）。
- 采购的招标与合同走学校财务制度，AI 出申请单与依据，审批与采购是总务与财务的事。
- **不替代**：库管的实物保管——AI 管账目与流程，货架上的事是人的事。
- **接不住就转**：固定资产转 asset-management；食堂食材采购验收转 cafeteria-management。
