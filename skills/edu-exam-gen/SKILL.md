## 一句话启动

打开就说「**出卷**」，不用描述需求格式。

示例：「按这份蓝图出卷」

接着会这样跑：

蓝图来自 edu-blueprint 或自己贴的知识点 × 权重表。AI 按蓝图生成整卷（选择/填空/解答，含 SVG 图），
输出 Markdown 或 HTML 打印版（Ctrl+P 直接打印），答题卡一起给。

## 核心心智模型

**模型1：蓝图先行，题目后行**——命题从双向细目表（知识点×能力层级×分值分布）开始，不从"找题"开始；蓝图定了，题目只是填充。依据：教育测量学的测验设计规范。应用：命题流程第一件事与用户对齐蓝图，蓝图未确认不开题。局限：日常小测可用简化蓝图（知识点清单+分值）。

**模型2：情境是素养的容器**——新课标导向的命题，素养考查藏在真实情境里：无情境的题考记忆，有情境的题考应用与迁移。依据：2022课标的学业质量标准与命题建议。应用：每个题目标注情境属性（无情境/学科情境/生活情境/跨学科情境）。局限：低年级与基础技能（计算/识字）的熟练度考查，纯技能题仍正当。

**模型3：命题质量在审校中提升，不在初稿中诞生**——初稿题必有瑕疵（歧义/超纲/答案不唯一），审校三查（科学性/适纲性/答案唯一性）是命题的必经环节。依据：命题工作的审校制度。应用：Auto-Fix自检+人工复核双层把关，自检发现的问题标注出来而非静默修改。局限：时间极紧的随堂测验，审校压缩为一查（科学性）。

## 决策启发式

1. **蓝图未确认不开题**——双向细目表对齐是命题的第一道闸。
2. **每题标情境属性**——无情境/学科情境/生活情境/跨学科情境，素养占比一目了然。
3. **答案唯一性逐题过**——多答案题要么改题干要么给评分维度，不带病交付。
4. **Auto-Fix发现的问题亮出来**——标注而非静默修改，人工复核有依据。
5. **整卷难度阶梯排布**——由易到难护住学生的考试信心，第一题不难是铁律。

## 工作流程

1. 收蓝图：接收 edu-blueprint 产出的知识点×题型×分值×难度表，或用户口述的命题要求（范围/时长/难度定位）。
2. 出整卷：按蓝图逐题生成（选择/填空/解答），每题带知识点标签、难度标注、参考答案与评分点；几何/函数题配 SVG 矢量图。
3. 自检三样：题量与蓝图一致；难度比例符合设定（如期中6:3:1）；答案可由题干推出（无歧义、无超纲解法）。
4. 出配件：答题卡 + HTML 打印版（Ctrl+P 直接打印），A4 分页不溢出。

## 检查点

🔴 **动手前**：蓝图三要素（范围/时长/难度）缺一不动手——考什么都没定就出卷，返工是必然。

🔴 **中途**：每出完一种题型核对一次蓝图对齐度，跑偏立即回正，不出完再改。

🔴 **交付前**：整卷自检三样 + 试卷与答题卡题量一一对应。

## 输出规范

- 整卷结构：题号/题型/分值/难度标注齐全，总分与蓝图一致。
- 每题四件套：题干、知识点标签、参考答案、评分点（解答题分步给分）。
- 配图规范：几何/函数图用内联 SVG，线条与坐标清晰，打印不失真。
- 交付含 HTML 打印版与答题卡，双击可打印。

## 失败与异常处理

1. **蓝图缺失**：用户只说"出份卷子"——先问范围/时长/难度三要素，不凭默认值直接出卷。
2. **材料读不到**：教材/课标文件打不开时说明原因并给替代路径，不猜内容出题。
3. **难度失衡**：自检发现难度比例偏离蓝图 ±15% 时，回炉调整题目而不是硬交付。
4. **超出范围**：要求押题/透题、或超出课标难度——拒绝并说明，命题以课标为纲。
