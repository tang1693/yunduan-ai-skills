# 论文 / 课题 → 学术 PPT

把教育研究论文或课题报告转成真正可编辑的 .pptx，按研究范式的叙事逻辑走。

## 工作流程

1. **认范式**：判断是行动研究、调查研究、实验研究、案例研究还是课程设计，用对应的叙事逻辑（不是千篇一律的「背景-方法-结果」）。
2. **提骨架**：从论文提炼「问题→方法→过程→发现→结论」的主线，剔除细节。
3. **逐页成稿**：封面、问题、方法、数据、结论、致谢，每页一个要点，配图表。
4. **质检**：字号、图表清晰度、逻辑是否连贯，过一遍再交付。

## 检查点

🔴 **动手前**：这一步不对齐，后面全是返工。先确认手上有没有学科、学段、这一屏要讲清的一个核心点；缺哪项就直接问，不带着假设往下做。

🔴 **中途**：内容骨架（哪几屏、每屏一句话）定下来再动视觉；骨架没定就配色，返工代价最大。

🔴 **交付前**：把文件在手机尺寸下打开一次，看有没有文字溢出或串版。

以上三处只要有一处没过，就停在原地把缺口补上，不带着问题进入下一步。

## 输出规范

- 产出真正的 .pptx 文件，可独立编辑，不是截图拼贴。
- 图表从论文提取关键数据，清晰可读，字号课堂可读。
- 叙事逻辑贴合研究范式，突出「结论」和「证据」。

## 失败与异常处理

1. **信息不全**：如果用户没给教学主题、学段学科和目标页面/课件形态，先问清「什么主题、给几年级、要什么形态（幻灯片/网页/单页图）」，问清再动手；实在拿不到，就按最保守的假设出一版，并在开头标注「假设：…」，不编造未提供的信息。
2. **材料读不到**：如果上传的文件打不开、为空或格式不支持，说清具体原因（损坏/需转换/内容为空），并给替代路径（截图、粘贴文本、换格式重传）；不猜文件里的内容。
3. **条件冲突**：如果用户的要求与已给材料或学校规定冲突，不直接照做也不直接拒绝，先列出冲突点，给 2 个可选处置方案，等用户选。
4. **超出范围**：如果请求属于代做学校宣传物料、对外发布的商业设计，说明这部分不在本技能范围，按「转教学设计类技能」处理，不硬答。


## 边界

- 只做「论文→PPT」的转化，不代写论文内容。
- 数据以论文原文为准，不臆造。
