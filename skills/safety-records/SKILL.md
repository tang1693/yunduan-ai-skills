# 安全台账管理 Skill · v2.0

## 一句话启动

打开就说「**记安全台账**」，不用先描述格式。

## 核心心智模型

**模型1：台账的法律本质是"证据链"**——安全记录不是"工作痕迹"，是事故追责与免责的法律证据。每条记录要能回答"何时、何地、何人、查了什么、发现什么、处置了什么、谁确认"。依据：《中小学幼儿园安全管理办法》与安全生产台账规范；事故调查中"没有记录=没有做"。应用：表单设计按证据要素组织，签字栏与时间戳是台账的灵魂。局限：不为记录而记录——与检查清单脱节的台账是废纸。

**模型2：闭环原则（发现→整改→复核→销号）**——任何一条隐患记录必须走到"销号"才算结束；只记"发现问题"没有"整改复核"的台账，在事故追责时反而是"明知不管"的自证。依据：PDCA闭环与隐患排查治理双重预防机制。应用：台账每条记录带状态字段（开放/整改中/已销号），周报只看开放条目。局限：外部原因（如市政维修）长期无法销号的，标注"已上报待外部"并留痕。

**模型3：一次采集、多处复用**——同一份检查数据可生成：安全检查台账（对内）、隐患整改单（对责任方）、月度安全报告（对校领导）、专项汇报（对教育局）。依据：信息管理"单源多用"原则；学校重复填表的痛点。应用：录入时按最细颗粒度记，输出时按用途聚合，不重复录入。局限：不同上报口径的固定模板需单独适配。

## 决策启发式

1. **当天的事当天记**——安全记录的时效性就是可信度，隔周补记的台账经不起追问。
2. **"正常"也要记**——"查过且正常"与"没查"在法律上是两回事，空白的日期格就是空白的责任证据。
3. **照片是台账的一部分**——关键部位检查附照片（有时间水印），文字+影像双证据。
4. **每月看一次"开放清单"**——挂账超两周的隐患升级提醒，拖是最常见的隐患扩大原因。
5. **纸质电子双轨不并存**——选定电子台账就以电子为准，纸质只留签名页，两套并行必然打架。

## 执行规范

老师说"帮我记安全台账 / 出安全台账模板"即可。缺信息先问：哪个条线（校园巡查/消防/食品/实验室/校车）、日常记录还是专项检查。信息齐了，按需做四样：

1. 台账模板：日期 / 检查人 / 检查部位 / 检查项 / 结果（正常/异常）/ 隐患描述 / 整改措施 / 整改期限 / 复核人 / 销号日期。
2. 隐患整改单：一患一单，责任到人、期限明确，复核签字后才销号。
3. 月度汇总：检查次数 / 发现问题数 / 已销号 / 未销号及原因 / 下月重点——一页给校领导。
4. 专项台账：消防（月检+年检）、食品（日检）、实验室（危化品双人双锁）、校车（行车前后检查）各自的专用表格。

## 检查点

🔴 **动手前**：确认条线与上报口径（对内管理 or 教育局专项），模板字段差很多。

🔴 **中途**：每条记录必须能连到"检查清单的哪一项"——凭空记的条目是孤证。

🔴 **交付前**：未销号条目单独列出并标挂账天数——藏着不报等于没有台账。

## 输出规范

- 台账表格字段完整（时间/人/项/果/处置/销号），可直接打印或入电子表。
- 月度汇总不超过一页，核心是"未销号清单+原因"。
- 专项台账按监管模板格式出，不自创字段名（监管对不上=白做）。

## 失败与异常处理

1. **历史台账缺失要补**：按"如实标注补记"处理——补记记录标注"补记"字样与补记日期，不伪造原始时间。
2. **整改责任部门推诿**：台账如实记录"X月X日转交X部门"，推诿本身也是记录——升级路径按学校安全责任制走。
3. **检查人与整改人是同一人**：小规模学校难免，但复核人必须换人——自查自核等于没核。
4. **迎检前突击整理**：可以帮做的是"格式规范+缺项清单"，不做的是编造记录——编造的安全台账是违法证据。

## 边界与提醒

- 台账的安全责任在安全管理干部与校领导，AI 管格式、闭环提醒与汇总，不代替签字。
- 重大隐患（消防系统失效/建筑结构问题）立即报校长与专业机构，不走台账月报节奏。
- **不替代**：专业检测机构出具的法定检测报告——台账记录"检测已做"，报告本体归档另存。
- **接不住就转**：隐患排查清单本身转 hazard-inspection；食品安全台账转 cafeteria-management 联动。
