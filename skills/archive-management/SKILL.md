# 档案归档 v1.0

> 文书档案天天收、年年理——分好类、编好号，要查时一翻就到。

## 执行规范

老师说"帮我归档这些材料"即可。缺信息先问：什么类型、哪个年度。信息齐了，做三样：

1. 分类：按文书 / 人事 / 教学 / 财务 / 基建等大类归位。
2. 编目：给每个文件编档号（类别 + 年度 + 序号）。
3. 归档清单：档号 + 文件名称 + 成文日期 + 密级 + 保管期限。

## 核心心智模型

**模型1：「档案的价值在'一翻就到'」**
- 定义：归档不是"收起来"，是"需要时30秒内找得到"——分类、编号、清单三件事全部服务这个标准；查不到的归档等于没归。
- 依据：本技能定位句"把天天收的文件理成一翻就到的档案"；文书档案管理实务。
- 应用：每次归档后随机抽一份文件做"30秒检索测试"；测试不过重来。
- 局限：电子检索与纸质检索速度不同——纸质档以"柜-盒-件"三级定位到分钟级为合格。

**模型2：「涉密不贴AI，框架照给」**
- 定义：涉密档案的内容不出现在AI对话里，但目录框架、编号规则、保管期限表是通用知识——AI给框架，内容线下填。
- 依据：本技能边界条款"涉密档案不贴AI——只给目录框架和编号规则"。
- 应用：识别涉密材料（人事/纪检/涉稳）时主动降级为"框架模式"；编号连续性由人工维护。
- 局限：密级判断是人的职责——AI只提示，不判定。

**模型3：「档号是档案的身份证，一经赋予不变更」**
- 定义：档号（类别+年度+序号）唯一且终身——变更档号等于销毁档案的追溯链；报废档案的档号封存不重用。
- 依据：档案管理的基本原则；本技能编目规则。
- 应用：编号按学校档案制度的规则生成；规则没覆盖的新类别先补规则再编号，不临场造号。
- 局限：历史遗留的无规则档号——原号保留，新规则从新收档案起用，两套并行标注。

## 决策启发式

| # | 触发情况 | 动作 |
|---|---|---|
| H1 | 没说档案类型与年度 | 补问两要素——大类和年度定档号结构 |
| H2 | 材料疑似涉密 | 切框架模式：给目录框架+编号规则，内容线下处理 |
| H3 | 学校档号规则与默认规则不同 | 以学校档案管理制度为准，不臆造编号 |
| H4 | 要查一份旧档案 | 按"柜-盒-件"路径给检索方案；找不到的列排查清单 |
| H5 | 要电子归档方案 | 给电子档案目录结构+命名规范——双套制（纸质+电子）并存时标注对应关系 |

## 检查点

🔴 **动手前**：档案类型、年度两样确认；涉密判定过一遍。

🔴 **中途**：分类落位（文书/人事/教学/财务/基建）；档号按规则生成无重号。

🔴 **交付前**：归档清单五要素齐（档号/名称/成文日期/密级/保管期限）；"30秒找到"抽测过。

## 输出规范

- 归档三件：分类方案（五大类落位）/编目表（档号+名称+日期+密级+保管期限）/归档清单（可打印核对用）。
- 档号结构注明规则来源（学校制度优先）；涉密件在清单只留档号与密级，名称脱敏。

## 失败与异常处理

1. **信息不全**：补问类型与年度；拿不到按文书类+当年出框架版。
2. **档号规则冲突**（新旧两套）：原号保留，新规则从新档案起用——追溯链不断。
3. **找不到的旧档**：给排查路径（转库记录/借阅登记/移交清单）——不臆断"不存在"。
4. **超范围**（档案鉴定销毁）：提示走学校档案鉴定流程——销毁是组织行为不是AI建议。

## 边界

- **管**：文书档案的分类、编目、清单、检索方案、电子归档目录。
- **不管**：涉密内容处理（线下）；档案鉴定与销毁（组织流程）；人事档案（转人事口径）。
- **不替代**：档案管理员的制度执行——AI给规则，执行在人。
- **接不住就转**：会议纪要归档转meeting-minutes先整理。

## 分工说明

与用章证照管理（seal-certificate-management）衔接：用印文件归档时档号规则同源；与周报/公文技能的产出归档共用本编目规则。
