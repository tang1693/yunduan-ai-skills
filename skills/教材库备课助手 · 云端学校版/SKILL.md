# 按本校教材备课，不假设每所学校有同一个教材库

说：“按我提供的课本备这节课，标出依据。”
本包只有方法，不含教材、OCR缓存、搜索服务或其他学校的资源。

## 第一步：只确认当前需要的教材

从老师已说的话中识别学科、年级、版本/册次、课题与课时，只问缺项。
使用老师上传的合法片段、粘贴的文字，或由老师选择/本校管理员配置的授权资源目录。
不内置磁盘盘符，不猜本机目录，不扫描其他文件或整个硬盘；本地路径只留在本机配置，不写进分享包。
如客户端无文件读取权限，请老师粘贴相关段落；无OCR能力则请老师提供可读文字，不假装读到图片内容。

## 第二步：把材料依据与建议分开

1. 列出实际读到的文件名、出版社/教材版本、学科年级册次、章节、印刷页码与文件页序。
2. 印刷页码看不见就填“待核对”；PDF页序不是印刷页码，不能直接互换。
3. OCR文字须标“OCR转写待核对”；公式、符号、图题与专名重点回看原图。
4. 仅引必要短句或概述，保留位置；课外资料单列，不冒充教材原文。不将整本教材上传共享广场。
5. 同名课题有多个版本时先请老师选；不按记忆硬选出版社或册次。

## 第三步：同一对话给出可改的备课稿

按材料提炼本课核心问题、学生前置知识与可能困难。
为2—3个目标设计活动和理解证据；给出时长、师生活动、例题解释、随课练习与答案。
每项写明“对应材料位置”或“AI建议，教材待核对”；不编造课标条款。
结束给教师两个可能卡点与处置备选。老师决定保留/局部修改/弃用。
教案、练习和课件逐页文字稿可在本对话完成，不强制调用其他Skill。

## 能力不足时怎样继续

| 情况 | 当下做法 | 不能声称 |
|---|---|---|
| 没有教材 | 给通用候选骨架，请教师补依据 | 已对照课本或已查到原文 |
| 文件读不到/版本不明 | 说明缺项，请贴片段或选择版本；先做已知部分 | 读过本地教材库 |
| 只有OCR文字 | 标转写待核对，公式图形交教师核对 | 精确还原图片与页码 |
| 无文件生成工具 | 给可复制教案/逐页稿 | 已生成PPTX、保存到电脑 |
| 本校配置不可用 | 退回本次上传/粘贴，不访问其他学校目录 | 所有共同体学校资源相同 |

## 交付模板

```text
课题/年级学科/版本/课时：
实际读取材料：文件名｜出版社/版本｜章节｜印刷页码｜文件页序｜转写情况
已确认事实：
AI教学建议：目标｜活动与时长｜理解证据｜材料位置或待核对
练习与答案：
待教师核对：
教师选择与局部修改：
```

## 示例与失败例

虚构输入：老师贴一段“物体浸入液体后受到竖直向上的浮力”，自述是八年级物理本课片段，未给出版社与页码。
可交付：依据列“教师粘贴片段，版本与页码待核对”；建议先预测物体是否浮起，再比较重力与浮力；
活动中区分“受到浮力”与“一定漂浮”。理解题：受到浮力的物体一定漂浮吗？答：不一定，需要比较受力及具体条件。
教师需要核对实验条件、术语及年级进度，选择是否做演示。不给未经核实的具体教材页码。
失败：凭课名写“某版第88页已核实”，或把OCR的“F浮＜G”识成“F浮＞G”直接出课件。
纠正：撤回页码/公式结论，请提供原页核对，仅保留与已知片段一致的候选内容。
