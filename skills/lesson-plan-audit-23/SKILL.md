# 教案对照 23 条（老道理第 12 条）

> 一旦拿它算分，它第二天就退化成客气话，第三个月就没人真用——只用于改进，不进考核。

## 一句话启动

打开就说「**对照 23 条**」，把教案全文粘进来。示例：AI 出 23 行体检表——条号｜有没有落点（✅/⚠️/❌）｜落点在第几段；没落点的那格留白，不写一个字的建议。

| 部 | 条 | 老道理 |

| | 3 | 一个班是好几种状态的学生（分层） |

## 工作流程

1. **收教案**：教案/教学脚本全文；问一句学科年级（个别条目的落点判断与学段有关）。
2. **逐条对照**：23 条各判一档——
   - ✅ 有落点：教案里能找到对应动作，标注在第几段；
   - ⚠️ 弱：有影子但不完整（如只写了「提问」没写随机点 3 人），标段落+一句差距事实；
   - ❌ 没有：留白，不写一个字。
3. **汇总行**：末尾一行报数——✅X 条、⚠️Y 条、❌Z 条，落点最密的三条是哪三条。
4. **闭嘴**：不评价教案好坏、不给改进建议、不排优先级——哪条该补，是作者的决定。

## 输出规范

- 23 行表格：部｜条号｜老道理（≤10字）｜落点判定｜位置或差距事实。
- ⚠️ 的差距事实只描述「缺什么」，不用建议语气（写「未标随机点人」不写「建议标随机点人」）。
- ❌ 行留白——留白本身就是信息，写满了反而没人看。
- 表尾附教研规矩一句：「讨论任何课堂现象，先说『这是第几条的事』，再说观点。说不出条号的，翻速查表再开口。」

## 检查点

🔴 **动手前**：确认教案是环节级以上——只有课题名的一行教案对照不了，退回补全。

🔴 **中途**：⚠️ 档是最大的灰色地带——每条 ⚠️ 必须能说出「差的那一截是什么」，说不出的升 ✅ 或降 ❌。

🔴 **交付前**：抽查 ✅ 行的位置标注——引错段落的一律改对；位置对不上的降 ⚠️。

## 失败与异常处理

1. **教案是 PPT 大纲**：按屏当段处理，位置标「第 X 屏」；只有标题没有内容的条目一律 ❌，不猜。
2. **跨学科融合课**：23 条通用，学科差异在「条 13 知识四分类」的落点判断里体现，先问清两科各自的目标。
3. **短教案（复习课）**：复习课不是所有条都适用——条 19（挖缺口）在复习课常为 ❌，这是正常形态，不硬凑落点。
4. **作者追问「那我补哪条」**：如实答——体检表不给优先级；教研组共同决定先补哪条，正是本条存在的意义。

## 边界

- **管**：23 条对照、落点标注、汇总报数。
- **不管**：好坏评价、改进建议、分数排名——一旦进考核，本工具即死。
- **不替代**：教研组的讨论——表只是锚点，「这是第几条的事」之后的观点交锋仍然是人的事。
- **接不住就转**：要改教案，转 teacher-prep；要六角色深度评审，转 teaching-review-board；要三事实自查，转 lesson-plan-mirror。
