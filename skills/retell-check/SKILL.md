# 复述检验（老道理第 4 条）

> 「这个我讲过了」讲的是客观的知识，学生带走的是各自的版本。这三个人的原话，就是你第一次看见那些版本长什么样。

## 一句话启动

打开就说「**他们真的懂了吗**」。示例：备课阶段说「这节课讲浮力，出 3 档复述要求」；课后阶段直接把三个孩子的复述原话粘进来，AI 每人一句：漏了什么、哪里讲错了。

## 工作流程

1. **备课出要求**：给本课知识点出 3 个复述要求，每个都能一句话答完、老师当场听出对不对，分三档：
   - 基础版（复述结论）／进阶版（说清怎么想到的）／挑战版（举个例子）。
2. **课中采样**：随机点 3 人（不是举手的 3 人），手机录一下，课后转文字。
3. **课后判读**：三段原话粘进来，每人两句——①漏掉了什么；②哪里讲错了或讲反了。每人一句话，不展开。
4. **找交集**：最后单独一行——三个人都漏掉的那个点是什么。明天开场只重提这一个点。

## 核心心智模型

**模型1：「讲过了 ≠ 存下了」**
- 定义：教师讲的是客观的知识，学生带走的是各自的版本——同一个知识点，四十几个孩子脑子里是四十几个版本。"这个我讲过了"是事实陈述，不是效果陈述。
- 依据：二十三条第4条的原话设计；复述三档判读的交集机制。
- 应用：复述检验的目的不是打分，是让教师第一次"看见"那些版本长什么样——判读只标"漏、错"，不打分不评价学生。
- 局限：复述只能检验"能说出来的部分"——缄默的理解存在，但初判以复述为准，深度诊断另走错因分析。

**模型2：「随机点人，别点举手的」**
- 定义：举手的样本永远偏乐观——敢举手的大概率掌握了；随机采样（不是举手的3人）才反映班级真实分布，这是复述检验作为"学情采样"的方法论底线。
- 依据：本技能提醒句"随机点人，别点举手的"；教育测评的抽样原理。
- 应用：课中随机点3人（手机录音转文字）；班级人数不足20人点2人也够，交集改两人共有。
- 局限：随机也可能连续抽到高成就学生——一个月内保证每人至少被抽一次的轮换底账更公平。

**模型3：「交集才是明天的课」**
- 定义：三段原话判读后，最有价值的产出是"三个人都漏掉的那个点"——它证明这是讲解的盲区而非个体的走神，明天开场只需重提这一个点。
- 依据：本技能工作流第4步找交集；四十几个版本的共性漏洞=系统性教学缺口。
- 应用：交集行加粗单列；只有两人共有的放"次要交集"，不混进明早重点。
- 局限：三人漏洞完全不同同样是重要发现——按人数最多的点走，其余进错因库（版本多样性本身说明讲解触达不均）。

## 决策启发式

| # | 触发情况 | 动作 |
|---|---|---|
| H1 | 复述用在了复习课旧知识上 | 停——判不出今天的账；复述检验的对象必须"这节课刚讲的" |
| H2 | 学生一句不说 | 换基础版问题（"用一句话说说今天讲的X是干嘛的"）；再不开口记"未采样"，不强采 |
| H3 | 录音转写失败 | 学生当场写一句交上来，效果一样；或教师记关键词，AI按关键词判 |
| H4 | 三人漏洞完全不同 | 按人数最多的点走，其余进错因库——版本多样性本身是发现 |
| H5 | 判读结果被拿去评价学生 | 拒绝——这是学情采集不是课堂评价；判读只标漏错，不进考核 |

## 输出规范

- 3档复述要求：每档一句话、老师当场听出对错（基础版复述结论/进阶版说清怎么想到/挑战版举个例子）。
- 判读表：每人两行（漏了什么/错了什么），一行一句，**不写教学建议、不打分**。
- 交集行：三个人共有的漏洞，加粗，一行——这是明天开场唯一要重提的点。
- 提醒句固定输出：随机点人，别点举手的——举手的样本永远偏乐观。

## 检查点

🔴 **动手前**：知识点是"这节课刚讲的"——复习课旧知识复述判不出今天的账。

🔴 **中途**：判读只标"漏、错"，不打分不评价——越界成课堂评价立即纠正。

🔴 **交付前**：交集行必须是三人共有；两人共有的放次要交集，不混进明早重点。

## 失败与异常处理

1. **录音转写失败**：改书面（当场写一句交上来）或教师凭记忆记关键词，AI按关键词判——采样方式可以变，采样本身不能省。
2. **学生一句不说**：换基础版问题降门槛；仍不开口记"未采样"——强采出来的不是学情是配合表演。
3. **三人漏洞完全不同**：按人数最多走，其余进错因库——这本身就是"四十几个版本"的实证。
4. **班级人数太少**（不足20人）：点2人也够用，交集改两人共有。

## 边界

- **管**：复述要求生成、原话判读、交集提炼。
- **不管**：点谁、什么时候点——随机采样的公正性，教师的公信力比 AI 的随机数重要。
- **不替代**：教师当场追问——AI判的是文本，学生眼神里的犹豫只有站在讲台上的人看得见。
- **接不住就转**：整班学情分析转考试与成绩分析助手；错因归类转作业批改类技能。
- **分工说明**：化学学科教师可用 chem23-lesson-cycle 第04条（含化学专属复述要点）；本技能面向全学科。
