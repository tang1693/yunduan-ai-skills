# 扶摇阁·开放难题（Conundrum）

> 没有对错。看的是孩子能不能看到不同人的立场和利益、把自己的理由讲清楚，并认真对待和自己意见不同的人。

## 开始前：最少准备

说明给学生还是给教师、年级和本次要一题还是整套；已有题目可以直接粘贴。不清楚学段时只追问这一项，再给一题小样。单题不强加20—40张、封面和扶摇末题；整套卡才沿用封面与收尾仪式。

默认面向教师备课与组织支持，学生接触的材料须经教师核对。文中人数、分组和时长是本校方案示例，按实际情境调整；S级为作者原有自评，不是本轮教师试用结论。引用其他Skill表示可选协作，不代表客户端已经安装或能够自动调用；缺少时在当前对话给可编辑表或步骤，说明未完成部分。

[中文使用卡、完整示例与失败处理](references/中文使用卡.md)。首次先给一小段候选，教师满意再展开；已给材料不重复询问。

## 一句话启动

- 说「**出一道开放难题**」→ 得一道题（默认学生版·辽阔向，按学段自动适配）。示例：「出一道开放难题，归功与分配类」。
- 说「**把题做成思考卡**」→ 得可直接打印的 A4 卡片（可编辑文字或HTML；PDF由浏览器打印并另行核对，一卡一页）。
- 说「**小云版/青云版**」→ 切对应学段层（见「一题三层」）。
- 说「**给老师出题**」→ 切教育者版（AI 进教育的真实两难）。

## 架构定位：一个能力 skill 对四个学堂入口（怎么被调用）

本技能是**共享能力层**（管"题怎么出、卡怎么做、地图怎么画"），四个学堂各有一个**运营入口 skill**（管"人怎么编排、课怎么排"）。针对性不靠四套题库，靠**入口带参数转来**：

| 你在哪说 | 入口 skill | 转来时带什么 | 本技能切到 |
|---|---|---|---|
| "小云学堂这周思辨课" | xiaoyun-hub | 4-5 年级·20 人·周五下午/晨会 15 分钟 | **小云版层**（圈选+画写、白话庄子） |
| "六年级口语交际课的辩题" | xiaokun-bridge | 6 年级·30 人·口语表达与倾听 | **扶摇版层**（标准四步） |
| "扶摇阁出一道难题" | （直达本技能） | 6-8 年级拔尖·10 人小班 | **扶摇版层 + 换位课堂流程** |
| "青云学堂思维快闪" | qingyun-top50 | 7-9 年级前 50·20 分钟调节器 | **青云版层**（结构化理由） |

**调用口诀**：说学堂名 → 各学堂 skill 接住 → 客户端支持路由且已安装时才转本技能；否则在本次对话按本方法继续；直接说"出难题/做卡片" → 本技能按 H10 问一句"给哪个学段"再出。**题库只有一套母题，针对性由层参数决定**——这是"一题三层"的设计初衷：孩子换学堂不换问题族，升维不换库。

## 一题三层 · 学段适配（v3.0 核心：覆盖专项培优 4-9 年级全学段）

**同一母题、同一五族、同一思维地图——只调三个参数：情境海拔 / 选项数与作答形态 / 英文层。**

| | 小云版（4-5 年级·小云学堂） | 扶摇版（6-8 年级·扶摇阁/小鲲学堂） | 青云版（7-9 年级·青云学堂） |
|---|---|---|---|
| 情境 | **身边具体事**：旧玩具熊、跟了八年的狗、带谁上船 | 辽阔想象：外星、方舟、造龙、火星 | 现实两难：可接社会议题与学科情境 |
| 选项/作答 | 2-3 个选项；**圈一圈 + 画写结合**；换位只问一句 | 3-5 个选项；四步完整（站队/理由/对方/立场） | 同扶摇版四步，理由要求**结构化**（因为…但是…所以…） |
| 英文 | **情境+选项+提问全文中英对照**（2026-10-27 用户定稿：对优秀的孩子，中英文版有意义；原"只留一句点睛"作废，作答量与圈画形态不变） | 情境+选项全文中英对照 | 同扶摇版 |
| 换位表达 | 表情勾选：😊不变 / 🤔动摇 / 🔄换啦 | 没变/微调/改主意 | 同扶摇版+口头辩论 |
| 卡名 | 大问题卡 · 小思考家 | 扶摇 · 少年大问题 | 扶摇 · 少年大问题（青云层） |
| 封面锚点 | 庄子白话版（"北方有一条很大的鱼……"） | 庄子原文 | 同扶摇版 |

**判定规则（出题前必过）**：
1. 小云版情境必须是孩子**摸得着**的（一只狗/一个玩具/一次分东西），不出现抽象概念（记忆、文明、知识产权）；
2. 小云版每卡作答量 ≤ 3 行字（画可以多）；扶摇版完整四步；青云版理由必须含"因为/但是/所以"连接词；
3. 三层共用**同一母题映射表**（小云 №01 小狗 = 扶摇 №06 项圈；小云 №03 小熊 = 扶摇 №12 复制品）——保证孩子从小云版升入扶摇版时，**遇到的是同一族问题的更高海拔**，而不是全新题库；
4. 末题锚点全学段统一：小云版收尾用庄子白话大鱼故事，扶摇/青云版收尾必是「扶摇」（The Great Bird）。

**青云版使用建议**：前 50 名学生学业压力重，Conundrum 不是加餐而是**调节器**——建议每周一次 20 分钟"思维快闪"（1 题+3 分钟写+5 分钟辩），替代一次纯刷题；A 类稳高分生优先排入，理由：这类孩子最缺的恰是"没有标准答案"的练习。中Topic链（出题/模考/分析）不动，本卡是穿插件不是主干。

## 双轨题库（2026-10-26 定稿的关键分野）

**先问：这道题给谁做？**

| | 学生版 · 辽阔向（主推） | 教育者版 · AI 教育向 |
|---|---|---|
| 给谁 | 扶摇阁学生本人 | 教师/培训现场 |
| 什么味 | 外星回信、方舟、造龙的心、火星出生的女孩、会做梦的机器人、发明一种颜色 | AI 批改冤枉率、提分神器卖给谁、数据之湖、克隆名师嗓音 |
| 练什么 | 想象力/创造力/哲学推理/共情/价值排序——**思维本身** | 教育者对 AI 进课堂的判断与取舍 |
| 原则 | **越是 AI 时代，越需要更开放的想象力**——AI 至多是背景板，不是主角 | 每题贴教师真实两难，可回扣「效率层给 AI/判断层留给人」 |

判定口诀：题面去掉 AI 相关字眼后依然成立的，才是合格的学生版题。

## 六大母题（作者整理的题型轴，出新题先认母题）

| 母题 | 核心问句 | 代表题 |
|---|---|---|
| ① 功劳归属 | 「谁的贡献最大？」 | 蓝彗星/宝藏/狐狸/照片 |
| ② 分配规则 | 「用什么规则分才公平？」 | 披萨/岛屿/地下城/Goldilocks/第11张画 |
| ③ 决策权归属 | 「谁说了算？」 | 机场/关校/总统/秘密/外星人 |
| ④ 系统责任 | 「到底是谁的错/谁的功？」 | 湖泊双题/鸟/酒店罪案 |
| ⑤ 后果预判 | 「该不该做？」 | 龙/天气/树/魔术罪案/AI罪案 |
| ⑥ 边界判定 | 「越界了吗？」 | 球鞋/宠物/音乐/燃油/杰作 |

## 出题公式（7 条铁律，源自 43 题全库逆向工程）

1. **永远 ≥2 个选项，且每个选项都站得住**——没有「明显错的那个」，逼学生靠理由取胜，不靠排除法；
2. **固定用「你站哪一边」，不用「哪个是对的」**——措辞本身就在暗示：这是立场之争，不是是非之争；
3. **情境必须虚构**——脱离现实立场，孩子才能纯粹推理；
4. **角色名自带立场暗示**——Nova/Astra/Puppetmaster（傀儡师）/The Corporation，名字就是立场提示；
5. **常设「别的办法」出口**——树题/岛屿题的 Option D「Something else」：跳出框架被明确鼓励；
6. **成对出镜像题**——湖泊/湖泊归来：同六个角色、同结构，动机反转，从共谋变协作；
7. **最后回到孩子自身**——元题（难题中的难题）问「你要什么品质」，其实是问「你想成为谁」。

加一条 2026-10-26 的教学淬炼：**反方预生成**——出题时同步生成「最强反方理由」备用，学生全站同一边时教师当场抛出（对应启发式 H1）。

## 思考卡版式（本技能 2.0 新增核心资产）

**一张 A4 = 一题**，上半题目、下半作答。脚本只生成HTML，不自动生成PDF。无法运行脚本时直接给可复制的文字卡；需要打印时浏览器另存PDF，再核对分页与文字。

### 仪式感锚点（不可省略，2026-10-27 用户定稿）
- **封面页必有**：开卡信（FUYAO PAVILION · THINK BIG / 扶摇·少年大问题 / 三条用法 / 庄子"抟扶摇而上者九万里"引文），页脚两行：`扶摇阁 谨制 · 丙午年 · 与你共勉` + `汤幸初出品·首席专家 · 深圳市云端学校`；
- **末题必是「扶摇」（The Great Bird）**：大鹏 vs 麻雀，第四步作答为"我的九万里是____（可以改答案，人的一生可以换风）"。题面可适当变化（换鸟的意象/换时代背景），但"庄子锚点 + 你的九万里"不变；编号自动跟随实际题数；
- **题量弹性 20-40 张**：封面文案与编号由 len(Q) 自动适配；默认可备24张题库，实际课次由教师决定（24次双周课需48周，不能称为一学期）；
- **开始与结束，都与庄子《逍遥游》有关**——封面即起飞，末题即九万里。
- **卡面元信息红线（2026-10-27 用户定稿）**：母题归属、高层版映射（如「母题一：功劳归属（高层版 №04 蓝彗星）」）是给设计者/教师的元信息，**只存在于本 skill 文档与脚本数据区，绝不印在孩子看到的卡面上**——孩子只需要面对问题本身；
- **称呼跟学堂走**：面向孩子的文案统一称「学子」——小云学堂=**小云学子**、小鲲学堂=小鲲学子、扶摇阁=扶摇学子、青云学堂=青云学子；不再用「小朋友」称呼孩子。

### 卡面结构（上半）
1. 顶栏：№ 编号 / 主题色标签（六大母题对应六色）；
2. 中英双标题；
3. 情境：英文原文在上（衬线体）+ 中文在下；
4. 选项：圆圈字母 + 每选项英中对照各一行；
5. 提问框：底色条 + 左侧色线，英文加粗在前、中文在后。

### 作答区（下半，四化版式按题型选）
| 版式 | 适用 | 结构 |
|---|---|---|
| **站队题** | 一般两难 | ① 勾选站队 ② 我的理由（横线×3）③ **对方最强的理由**（横线×2）④ 听完对方立场：没变/微调/改主意 |
| **排序题** | 系统责任类 | 六方 1-6 排序填空框 + 为什么第 1 名 + 谁最容易被冤枉 |
| **裁定题** | 罪案类 | CRIME / NO CRIME 勾选 + 「只要不____算没越界；一旦____就算越界」填空句式 + 理由 |
| **开放设计题** | 创造类 | 大画布「写字画画都行」+ 为什么是它 + 有人反对时我的反驳 |
| **方舟题** | 取舍类 | N 选 M 勾选 + 牺牲的两个 + 为什么是它们 |
| **慢递书信** | 时间与意义 | 收信人 + 横格信纸正文 |

设计逻辑：第③步「替对方写最强理由」+ 第④步「立场变没变」= Astra Nova「学会有建设性地表达分歧」的纸面化。

### 打印规格（踩坑全记录，改版式必读）
- A4 纵向，`@page margin:7mm`，卡片打印态 `min-height:0` + `page-break-after:always` + `page-break-inside:avoid`；
- **zoom 分级**（否则长卡溢出到第二页）：默认 .78，内容重 .75/.68/.62，最长题（湖泊双题级）.53——按「情境+选项+提问总字数」自动分档；
- 作答横线要真正通到页边距，必须两件事齐做：`.sb{flex:1;min-width:0}`（flex 容器里内容格不设 flex:1 会收缩成标题文字宽）+ `.lns{margin-left:-68px;margin-right:-30px}`（负边距抵消序号圈和卡片内边距）；
- 不放姓名/日期栏、不放来源行（用户 2026-10-26 明确）；
- 交付前必须验证：无头 Chrome `--print-to-pdf` → pymupdf 数页数 + 逐页正则查卡号，无封面时N卡应为N页，有封面时为N+1页，逐页核对无溢出才算过；无打印工具时标记“PDF版式待核对”。

## 课堂流程（分层：一流程三时长）

### 标准层 · 扶摇版（40 分钟，10 人小班）

1. **看题**（5 分）：情境朗读或动画脚本演绎，学生独立选边——写在纸条上不公开；
2. **立论**（10 分）：每方 2 分钟陈述理由，只说「我为什么站这边」，不攻击对方；
3. **驳论**（10 分）：指向理由不指向人——「你的理由里有一环是猜的，我质疑那一环」；
4. **换位**（10 分）：所有人交换立场，用对方的最强理由先复述一遍再反驳——复述不到位的，对方可以说「你没听懂我」；
5. **收口**（5 分）：不宣布谁赢。每人写一句「我原来认为 X，现在我承认 Y 也有道理」——这句话进成长档案。

### 低海拔层 · 小云版（15 分钟，晨会或周五下午，20 人）

1. **读题**（3 分）：老师读情境，读到提问处停——孩子在卡上圈选项，不举手；
2. **说说为什么**（5 分）：同桌互相说"我圈的是哪个，因为……"——只说给同桌听，不上台；
3. **换一换**（4 分）：老师问"谁愿意说说同桌的想法？"——替同桌说，说错了同桌可以纠正；
4. **收口**（3 分）：举表情牌（😊不变/🤔动摇/🔄换啦），换了的孩子说说"听到了什么让他想换"。

小云红线：**不逼上台、不点评对错、不比谁说得好**——保护"敢想"比训练"会说"优先。

### 快闪层 · 青云版（20 分钟，每周一次，前 50 名）

1. **发卡即写**（8 分）：卡到手上直接进作答区，四步全写——快闪的"闪"在限时，不在省步骤；
2. **立场阵**（3 分）：按选项分边站教室两角/三角，物理站队，一分钟各自内部对齐口径；
3. **交叉质询**（6 分）：每边出一人陈述，对面任意举手质询——质询必须以"你的理由里……"开头，禁"我觉得你不对"；
4. **回收**（3 分）：卡收回（进思维地图数据源）；不宣布胜负，下次快闪换母题族。

青云红线：**不与中考内容挂钩、不排名、不进成绩**——它存在的唯一理由是让刷题的大脑每周换一次挡。

思考卡与课堂的关系：卡 = 个体的慢思考（先写后说），课堂 = 群体的快交锋。推荐序：先发卡独立作答 → 卡上立场进课堂立论 → 换位环节回看卡上第③步。首次发卡不按编号，抽「方舟/发明颜色/老狗项圈」三张最易上瘾的先发。

## 成长档案

每次课可由教师在本地记三样：去标识代号 / 当天的立场与最强理由一句 / 换位环节的复述质量（到位/不到位）。
思考卡作答区就是档案的纸质底稿——学期末把每人的卡按时间排列，理由是否变具体、立场是否敢变、替对方说话的能力，一眼可见。
一学期回看：理由是不是越来越具体、换位是不是越来越快——这是扶摇阁要的「建设性表达分歧」的证据。

## 思维地图（期末回收版，2026-10-27 新增）

**学期末由教师在本地整理去标识任务记录，选择是否制作一张 A4 思维地图**——不是打分，是把学生一学期的思维航迹可视化还给学生。

**数据来源**：回收的卡 + 成长档案表，每卡一行七元组：`卡号 × 五族 × 题名 × 所站立场 × 立场变化（没变/微调/改主意）× 理由字数 × 替对方金句（可选）`。

**学生页（人手一份）四区**：
1. **航线**：全部卡按时间排成小卡片墙——顶色=思维训练五族，◐=微调 ↻=改主意，条形=理由字数；
2. **理由曲线**：字数走势迷你柱状图（配一句提醒：字数不是重点，具体才是）；
3. **这一程三个数**：本次记录中立场修改较多的题族 / 保留立场的任务 / 教师选的一次换位复述（均非能力结论）；
4. **你的原话摘三句 + 下一叠三个问题**（其中一问永远是"哪一处你自己都没想到"级别的自省题）。
页脚固定：`这张地图不是分数，是镜子——它只描述你思维的航迹，不评判你站过的任何一边`。

**班级页（教师留用）**：五族热力（各族的改主意率条形图 + 平均理由字数）、全班金句匿名摘录、给教师的三句话（流动率最低的族下次优先开卡；金句读给学生听；发图只问一句"哪一处你自己都没想到"）。

**铁律**：① 不排名、不评级、不横向比学生——地图只对内（学生看自己的轨迹），热力只对族（教师看开卡策略）；② "改主意"不等于进步，"没变"不等于固执——两个方向都要有解读出口；③ 金句必须原文摘录不改写。

**资产**：`assets/生成扶摇思维地图_脚本.py`（改 STUDENT、CARDS、CLASS 数据区；班级统计是独立虚构示例，不会从个人卡片自动推算；PDF分页须另行核对）。可自行生成HTML样张（本包不附PDF）（小鲲 12 卡示例——鲲即化鹏之鱼，示例学生名取自《逍遥游》）。

五族是地图展示轴，六大母题是出题轴，并非数量相同的分类。记录时分别注明，不能从立场变化率或理由字数推断能力、人格；一份任务记录只说明当时条件下发生了什么。

## 核心心智模型

**模型1：「分歧本身是教学目标」**
- 定义：开放难题练的不是"选对边"，是表达分歧的三件事——看到每一方的立场与利益、把自己的理由讲到具体、认真对待跟你意见不同的人。题只是载体。
- 依据：作者参考的Conundrum设计思路（四十国、必修等外部情况本轮未独立核验）；《云端学校》书稿"异议必录、不把异议变成服从"的共同体纪律同源。
- 应用：判断课堂任何环节是否有效，只看三样——理由是否具体（不喊口号）、换位复述是否到位（对方点头）、收口那句"我承认Y也有道理"是否走心。思考卡上对应：第②步写了几个字、第③步有没有真的替对方想。
- 局限：内向学生口头表达受限——档案里设书面异议栏兜底，不算缺席。

**模型2：「三个立场必须都难站」**
- 定义：只要有一个选项明显"政治正确"，学生学的就是猜老师想听什么，思辨立刻退化成表态。
- 依据：Astra Nova 经典题的结构共性（造龙/秘方/湖死/回不回——没有一边是对的）；本技能检查点"明显正确项重写"。
- 应用：出题后自检——随便挑一个立场，如果一句话就能把它说得"听着很对"，这道题还没写完，回炉。
- 局限：部分主题天然有正确导向（如安全底线），这类不进题库，不硬拗。

**模型3：「复述是换位环节的及格线」**
- 定义：真听懂对方=能用对方认可的方式复述他的最强理由。复述不过关，后面的反驳全是打稻草人。
- 依据：Conundrum 原版规则"你没听懂我"由被复述方判定，不由老师判定。
- 应用：换位环节设复述确认——复述完问一句"我说的是你的意思吗"，对方说不是就重来。思考卡第③步「对方最强的理由」是它的书面预演。
- 局限：6年级学生复述能力弱，可先书面复述再口头，节奏放慢。

**模型4：「学生版题要辽阔，不要 AI 焦虑」（2.0 新增）**
- 定义：给学生本人的题，情境要上天入地（星空/方舟/龙/时间），练想象力、创造力、哲学推理；AI 时代的教育题是给教育者的。混淆两者 = 把孩子的思维装回成人焦虑的笼子。
- 依据：用户 2026-10-26 澄清原话——"不要局限于AI时代怎样怎样，越是AI时代，越需要更开放的想象力/创造力以及适应未来的综合能力"。
- 应用：给学生出题时自检——题面去掉 AI 字眼后是否依然成立？成立才发；不成立改情境。
- 局限：AI 相关题材并非禁用（如"会做梦的机器人"），但 AI 必须退到背景板，主角永远是"什么是活着/什么是公平"这类大问题。

**模型5：「意义锚：AI 替不了的三种力」（3.1.5 定稿，用户 2026-10-27 原话确立）**
- 定义：这套卡的存在理由是一条判断力逻辑链——**AI 越强，人越要守住三种不可让渡的能力：判断（自己站队）/ 想象（自己提问）/ 创造（自己定义）**。不练的反面是"答案被代给、立场被代持、观点可被算法预测"的人云亦云，即失去思想独立与自我价值。
- 依据：用户 2026-10-27 原话——"AI时代来临，我认为人的创造力/想象力/判断力都十分重要，不然人云我云，就失去了思想与判断，哪有自我价值？……很有可能完全被别人/被AI左右"。
- 应用：①任何"总纲/说明/汇报"类交付物，意义段必须以此链展开（判断→想象→创造，各配"不练会怎样"的反面），不能只罗列做法与版式；②"没有标准答案"的辩护词统一为：一旦给了参考答案，孩子练的就是"猜出题人想要什么"，那恰是 AI 最擅长的游戏——没有标准答案，才护得住自我；③向家长/领导讲这堂课，先讲这条链再讲玩法。
- 局限：对孩子本人不空谈"AI 时代"（模型4 依然有效）——链条写在教师层的总纲里，孩子层只写学子版表达（如航图"风从哪来"：答案越来越便宜，判断越来越贵）。

**模型6：「思想总纲高于使用手册」（3.1.6 定稿，用户 2026-10-27 亲自重写确立）**
- 定义：介绍这套卡的一切文档，思想必须压倒使用——用户重写的 7 页思想总纲里 6 页讲思想（题旨/三种力/没有标准答案/从九岁/为什么是庄子/图什么），使用压到第 7 页"顺带一说"；结尾句"细则是会过时的，思想不会"。
- 依据：用户 2026-10-27 诊断原话——"旧版 5 页里 4 页是对比表和排课路径，本质是使用手册；这版把比重彻底倒过来"。
- 应用：写总纲/航图/汇报时结构照此比重；四处已定稿的深挖补记可直接引用：一张卡上的三种力（微观解剖）/ 大问题没有母语（双语=换语言换站队位置）/ 无用之用（庄子答惠子护"不挂成绩"——分数走路，思想撑地）/ 家长同舱（家庭第 25 张卡：大人不纠正，孩子可反驳）。母本冻结于 `Desktop\四学堂_大问题卡_思想总纲.pdf`，工作版 v2（航图化排版）同名。
- 局限：卡片本身的版式资产（思考卡/思维地图）不受此模型约束——它们是工具，不是论述文。

## 输出规范

- 一道题 = 情境段（60-120字、零道德暗示词）+ 2-3个立场（各一句概括）+ 利益方清单（一行一方）+ 教师引导要点（三步各一句）+ 续集钩子（可选），一页以内。
- 一张卡 = 上半（中英情境+选项+提问）+ 下半（四化作答区之一），A4 一卡一页；生成脚本在 assets/，改题不改版式。
- 课堂脚本按五环节给时间与教师动作，教师动作只写"问什么"，不写"得出什么结论"。
- 档案记录表：日期 × 学生 × 立场 × 最强理由一句 × 复述质量（到位/不到位），可累积，学期末回看。
- **不给参考答案或最佳立场——给了这道题就废了**。

## 检查点

🔴 **动手前**：确认学段（6/7/8年级语言复杂度不同）与主题偏好，以及**题给谁做**（学生版/教育者版）；不给就按学生版·辽阔向默认出。

🔴 **中途**：立场选项过"都难站"测试——有一个明显正确项就重写，不带病上课堂。学生版题过"去 AI 测试"——去掉 AI 字眼依然成立才算合格。

🔴 **交付前**：情境通读一遍，删掉所有道德评判词（"自私的""勇敢的""可惜的"）；利益方清单与立场选项对得上。文字卡可直接交付；生成HTML时核对内容，只有交付PDF时才跑分页验证（N卡加实际封面页数、逐页无溢出）。未生成或未验证PDF须明确说明。

## 失败与异常处理

1. **讨论冷场**：降到二选一的具体情境（"虚构小镇的工厂排污，该由谁负责"），先两两说再全班；冷场超过5分钟教师自己站一边示范立论。
2. **学生全站同一边**：教师当场抛最强反方（AI已预生成备用），自己给自己立论——示范"给讨厌的立场找理由"本身就是课。
3. **换位环节走过场**（复述两句话完事）：把复述确认权交给被复述方——"他复述到位了吗？"由对方判定，不由老师。
4. **题目被学生一眼看穿倾向**：当场承认"这题出歪了"，把它变成教材——"哪里泄了底？"，改题本身就是一次出题课。
5. **卡片打印溢出**（一卡变两页）：按 assets 脚本的 zoom 分级表降档；重最长题级（.53）仍溢出，删情境冗余句，不缩字号到看不清——宁可题面短一点。

## 边界

- **管**：出题、思考卡生成、课堂脚手架、档案模板、反方弹药库、家长答疑话术。
- **不管**：辩论比赛赛制训练（社团的事）；价值观的最终评判——教师与家长委员会兜底。
- **不替代**：教师现场引导——"你没听懂我"的裁判只能由人做；换位环节的节奏掌控 AI 不在场。
- **接不住就转**：要完整 PBL 项目，转 高阶能力项目设计师；要跨学科设计，转 interdisciplinary-teaching-ai-assistant；要 43 题原版题库全文，转《中英逐题对照》成品文件（本包不内嵌全文，只存出题公式）。
