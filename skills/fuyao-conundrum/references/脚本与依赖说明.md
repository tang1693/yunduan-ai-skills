# 脚本与依赖说明

教师可直接让小龙虾输出文字卡，不必运行脚本。以下供有需要的本地维护人员使用。

五个脚本仅依赖Python 3标准库，不联网、不上传，不自动安装或调用其他Skill。

运行 `python "assets/脚本名.py" --output "本地输出.html"`。默认输出到当前目录，目标目录须已存在；请勿用已有重要文件作为输出。修改题库Q或地图STUDENT、CARDS、CLASS时先保留副本。地图示例全为虚构，班级数据不会根据个人数据自动汇总。

Astra版另加 `--source "本人有权使用的中英逐题对照.html"`，需要配套43题q-hd格式；题库未随包附带。未获来源或使用许可时，不提供“原版全库”，转用本包原创情境；脚本核查不代表第三方题库再分发许可。

本轮已在隔离目录实际生成五份HTML，并检查缺失题库、空地图和扶摇末题顺序。HTML生成通过不等于PDF打印通过：请使用浏览器打印预览，含封面的N卡共N+1页，无封面的N卡共N页，逐页检查。若工具不可用，交付文字版并标明未生成PDF，不声称已完成打印验证。
