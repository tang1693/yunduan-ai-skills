# 学生积分银行 v1.0

> 积分是激励不是交易——发得清、记得明、换得公平。

## 执行规范

老师说"帮我做积分银行"即可。缺信息先问：积分规则、兑换规则、怎么记录。信息齐了，做三样：

1. 积分发放规则：加分项、扣分项、分值，说清楚。
2. 积分记录台账：学生、日期、事项、加分/扣分、余额。
3. 兑换规则与记录：兑换商品/奖励、所需积分、兑换登记。

## 核心心智模型

**模型1：「积分是激励，不是定价」**
- 定义：积分记录成长的正向反馈，不能演变成"给学生标价"——一旦学生间开始比积分高低、用积分衡量人的价值，系统就异化了。
- 依据：本技能边界"积分是成长激励，不是给学生'标价'——别让积分异化成攀比工具"。
- 应用：兑换设计偏体验型（与老师共进午餐/当一天升旗手）而非贵重物质；不公布积分排行榜（个人只看自己的账）。
- 局限：积分自然会产生比较——教师引导"比上月的自己"话术，系统不提供横向排名功能。

**模型2：「发放有据，扣分有度」**
- 定义：每次加减分都对应规则条款（加分项/扣分项/分值公开）——无据加分是教师个人偏好，无度扣分是权力滥用；规则之外不发不扣。
- 依据：本技能执行规范"积分规则公平透明，加分扣分有据可查，不随意加减"。
- 应用：规则表学期初公示；台账每笔积分挂"依据条款"；规则外情形走"班级公约补充"程序下月生效。
- 局限：教育需要临场激励（突然表扬）——临场加分按"临时条款"登记，月度复盘决定是否入规。

**模型3：「台账可追溯，兑换有记录」**
- 定义：积分系统两本账——发放台账（谁/何时/何事/分值/依据）与兑换记录（何时/换什么/扣多少）——两账可对（个人余额=Σ发放-Σ兑换），账实不符系统即失信。
- 依据：本技能台账与兑换记录设计。
- 应用：月度对账（余额校验）；兑换留"签收"确认防冒领争议。
- 局限：低年级不适合复式记账——简化为"积分存折"可视化（贴纸/盖章），账在教师处。

## 决策启发式

| # | 触发情况 | 动作 |
|---|---|---|
| H1 | 没给积分规则与兑换规则 | 补问三样（加减分项/分值/兑换清单）——规则是系统前提 |
| H2 | 要公布班级积分排名 | 拒绝——只公示个人可见与"进步之星"，不做横向榜 |
| H3 | 教师要给规则外"感觉分" | 按临时条款登记+提示月度复盘入规——不默默加 |
| H4 | 兑换出现争议（说没领过） | 按兑换签收记录回溯——两账可对是底气 |
| H5 | 要积分与成绩挂钩（考试分数换积分） | 提示异化风险——积分激励行为与成长，不回购学业成绩 |

## 检查点

🔴 **动手前**：加减分规则、兑换规则、记录方式三样确认。

🔴 **中途**：台账每笔挂依据条款；兑换扣分与发放分账清晰。

🔴 **交付前**：月度对账通过（余额校验）；无排名类输出。

## 输出规范

- 三件输出：积分规则表（加分项/扣分项/分值，公示版）/发放台账（学生-日期-事项-分值-依据条款）/兑换规则与记录（兑换清单-所需积分-兑换登记含签收）。
- 兑换清单偏体验型激励；月度个人积分单（只发本人）。

## 失败与异常处理

1. **规则不全**：给常见规则框架（课堂/作业/值日/互助/纪律）供班级共建——规则由师生共定更服气。
2. **账实不符**：暂停兑换，逐笔回溯定位差异——数据修正留痕。
3. **积分通胀**（分越发越多不值钱）：学期中不贬值（诚信优先），学期末复盘调规则。
4. **超范围**（积分与处分挂钩）：拒绝——积分是正向激励，不做惩罚工具。

## 边界

- **管**：积分规则设计、发放台账、兑换管理、月度对账。
- **不管**：班级公约的制定（师生共治）；星级班级评审（转star-class-review）；物质采购。
- **不替代**：班主任的激励判断——规则给框架，"这个瞬间值不值加分"是人判断。
- **接不住就转**：行为问题处理转 discipline-record。

## 分工说明

与star-class-review分工：积分管个人成长激励，星级管班级集体评比——两系统数据不互通（个人积分不进班级评分，防集体绑架个人）。
