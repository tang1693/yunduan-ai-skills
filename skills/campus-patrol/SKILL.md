# 校产巡查 Skill · v1.0

## 一句话启动

打开就说「**排校产巡查**」，不用先描述格式。

## 执行规范

老师说"帮我安排校产巡查"即可。缺信息先问：查哪片（全校/教学楼/食堂/操场）、什么频次（日/周/月）。信息齐了，做四样：

1. 巡查计划表：区域 × 频次 × 责任人 × 重点部位（开学季/汛期/台风前加密）。
2. 巡查记录表：日期 / 巡查区域 / 巡查项目 / 状况(正常/异常) / 问题描述 / 处理意见 / 巡查人 / 整改完成——发现异常当场拍照编号。
3. 问题流转：设施损坏 → 维修工单（报修-派单-完工-验收四步）；重大隐患同步报安全处隐患台账。
4. 月度小结：巡查覆盖率 / 发现问题数 / 已闭环数 / 未闭环清单（红标）。

## 核心心智模型

**模型1：「'查过且正常'与'没查'是两回事」**
- 定义：巡查记录"正常"也要留痕——出事追责时，有记录的正常巡查证明履职，空白记录等于没查；留痕是巡查的合规产出而非额外负担。
- 依据：本技能边界条款；安全责任追究的履职认定实务。
- 应用：巡查表逐区域逐项记录（含正常项）；巡查人签字与时间戳完整。
- 局限：留痕不等于走过场——记录配合照片编号才是完整证据链。

**模型2：「问题流转四步闭环，报修不等于修好」**
- 定义：发现损坏→报修→派单→完工验收四步，缺验收的维修随时返工；巡查台账的价值在"问题从发现到闭环"全程可追。
- 依据：本技能执行规范问题流转设计。
- 应用：每个异常项生成维修工单号；完工项须复查签字销号；超期未闭环项周报红标。
- 局限：重大隐患不走慢流程——同步报安全处（hazard-inspection）即时处置。

**模型3：「巡查密度跟着风险走」**
- 定义：日查（门卫值守区/重点机房）、周查（功能室/活动区）、月查（全楼宇）、节前专项——频率与风险等级匹配；平均用力的高频巡查是资源浪费。
- 依据：本技能巡查计划设计（区域×频次×责任人）。
- 应用：汛期/台风前对门窗排水加密专项；开学季设施满负荷前全面查一轮。
- 局限：新投用区域首月提级查（磨合期故障率高），稳定后回落常规档。

## 决策启发式

| # | 触发情况 | 动作 |
|---|---|---|
| H1 | 没说范围与频次 | 补问两要素；按全校月查默认出计划框架 |
| H2 | 发现设施损坏 | 生成维修工单（四步流转）；重大隐患同步报hazard-inspection |
| H3 | 维修完工 | 复查签字销号——不验收不闭环 |
| H4 | 某设备反复维修 | 台账标记"建议报废评估"转asset-management |
| H5 | 高处设施（吊灯/外墙） | 目视检查为主，登高作业转专业维保——不冒险 |

## 检查点

🔴 **动手前**：范围、频次、责任人三要素确认。

🔴 **中途**：记录逐项（正常也留痕）；异常项即生成工单号。

🔴 **交付前**：月度小结含闭环率与未闭环红标清单。

## 输出规范

- 四件输出：巡查计划表（区域×频次×责任人×重点部位）/巡查记录表（八列：日期/区域/项目/状况/问题/处理/巡查人/整改完成）/维修工单（报修-派单-完工-验收四步）/月度小结（覆盖率/问题数/闭环率/红标清单）。
- 异常项附照片编号栏；季节专项（汛期/台风/开学季）计划单列。

## 失败与异常处理

1. **信息不全**：补问范围与频次；按全校默认出框架。
2. **巡查力量不足**：优先保高风险区（用电/消防通道/活动设施），低风险区降频——密度跟着风险走。
3. **工单超期未闭环**：周报红标+升级总务负责人协调——不静默挂起。
4. **超范围**（安全隐患类）：安全口径转hazard-inspection——设施损坏与安全风险两个台账分工。

## 边界

- **管**：巡查计划、巡查记录、维修工单流转、月度小结。
- **不管**：安全隐患排查口径（转hazard-inspection）；资产台账（转asset-management）；专业维保（外委）。
- **不替代**：巡查的脚程——AI管记录与流转，巡查靠人走。
- **接不住就转**：反复维修的资产转 asset-management 报废评估。

## 分工说明

总务三查分工：本技能管设施状况巡查（坏了修），hazard-inspection管安全隐患排查（险了改），safety-education管安全教育培训（教了防）——三表数据互通，隐患项流转到对应台账。
