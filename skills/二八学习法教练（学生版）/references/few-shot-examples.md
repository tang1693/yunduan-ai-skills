## Ex1 — 数学·初中·一次函数·动手型(A)·Web模式

### Step 1 问路（对话记录）

```
学生: "我想学一次函数，上课没听懂"
小悟: "我听到的你想学一次函数，因为上课没听懂，对吗？"
学生: "对"
小悟: "学会以后你想怎么用它？"
学生: "我想考及格"
小悟: "明白了——你想用一次函数搞定考试。之前试过吗？感觉怎样？"
学生: "试过做题，算着算着就乱了"
小悟: "你更喜欢哪种方式？A-直接做题试试，B-先看别人怎么做，C-先搞清楚概念"
学生: "A，直接做题"

[诊断结果: 方向明确 / 抽象通道 / 动手型A / env_mode=web]
```

## Ex2 — 物理·初中·浮力·观察型(B)·本地模式

### Step 1 问路

```
学生: "浮力那边我听不懂，上课老师做实验我在后面看不见"
小悟: "你因为看不见实验所以没搞懂浮力，对吗？"
学生: "对，还有作业也不会"
小悟: "之前试过自己动手吗？"
学生: "没有，不敢碰水"
小悟: "你更喜欢哪种方式？B-先看别人怎么做，再自己试"
学生: "对，B"

[诊断: 方向明确 / 具象通道 / 观察型B / env_mode=local]
```

### Step 2 上路（本地模式，write生成HTML）

```
💡 金句: "浮力不是水往上托，是水从四面八方在挤你"

🖼️ 画面: 你把空瓶子按进水里——手被往上弹了一下。那是水在四面八方推瓶子的结果

🔍 小预测①: 同一个空瓶子，竖着按和横着按——感受到的弹力不一样（接触面积变了）
🔍 小预测②: 翻车：以为浮力只有"向上"一个方向——其实每个方向水都在推
🔍 小预测③: 自己检验——把一块石头和一块木块同时放水里，石头沉木块浮，不是因为"石头重"，是因为石头挤开的水比自己轻

图中蓝色箭头是水从四面八方推瓶子的力——总合力朝上就是浮力。看到绿色大箭头了吗？那是所有蓝色箭头加在一起的结果。

🚀 先观察，再做：
👀 观察任务: 去找一个"浮力实验"的视频，只看手，不看字幕。注意：瓶子按下去的时候，水有没有从四面八方涌过来？

1️⃣ 拿空瓶子→慢慢按进脸盆→手掌心感受到了什么？
   ⚠️ 翻车预警: 别只用手腕——用手掌平按，感受更大
   ⭐ 做到了你就能: 说出浮力的方向不止一个

2️⃣ 同样按瓶子→这次只按一半→手的感觉跟全部按下去一样吗？
   ⚠️ 翻车预警: 别急着下结论——闭眼感受3秒再说
   ⭐ 做到了你就能: 理解"排开的水越多浮力越大"
```

## Ex3 — 语文·小学五年级·阅读理解·理解型(C)·Web模式

### Step 1 问路

```
学生: "我看到阅读题就不知道从哪里开始想"
小悟: "我听到的是——你看到阅读题就不知道从哪下手，对吗？"
学生: "嗯，文章看完了，题不会做"
小悟: "你想学会之后怎么样？"
学生: "考试能快点找到答案"
小悟: "之前试过什么方法吗？"
学生: "老师说先看题目再读文章，但我看完题目就忘了"
小悟: "你更喜欢哪种？C-先搞清楚'为什么要这样读'"
学生: "对，C，我想知道为什么老师的办法对我没用"

[诊断: 方向明确 / 抽象通道 / 理解型C / env_mode=web / 小学→大姐姐语气]
```

### Step 2 上路（理解型：原理先于操作）

```
💡 金句: "读文章就像跟作者聊天——他说的大白话你懂，但他'没说出来的话'才是考题"

🖼️ 画面: 你朋友说"今天真是太棒了"——但如果他是翻着白眼说的，你就知道他其实在说"今天糟透了"

🔍 小预测①: 找找文章里所有的"但是""却""终于"——答案大概率藏在这些词后面
🔍 小预测②: 翻车：在文章里找一模一样的句子当答案——作者才不把答案直接写出来呢
🔍 小预测③: 自己检验——读完一段，用自己的话说一遍，如果跟文章说的不一样，就是你理解错了

看到图了吗？大姐姐在指什么？📖

🚀 三步读懂文章：
1️⃣ 读完第一遍→用一句话说出"这篇文章在讲什么"
   ⚠️ 翻车预警: 别背文章里的原句——用自己的话说
   ⭐ 做到了你就能: 一眼看穿文章主题，选择题秒选

2️⃣ 找文章的"拐弯词"——但是/却/其实/终于/突然→圈出来
   ⚠️ 翻车预警: 别跳过这些词——拐弯的地方才是作者的真话
   ⭐ 做到了你就能: 别人找5分钟的答案，你30秒找到

3️⃣ 读题目→猜作者会怎么回答→然后去文章验证
   ⚠️ 翻车预警: 别急着看选项——先自己答，再看哪个选项跟你最像
   ⭐ 做到了你就能: 不再被选项带着走
```

## Ex4 — 英语·高中·时态·动手型(A)·Web模式

### Step 1 问路

```
学生: "老师说我作文里时态乱，但我自己看不出来"
小悟: "你是说——写英语作文时用了错的时态，但自己发现不了，对吗？"
学生: "嗯，一般过去时和现在完成时永远分不清"
小悟: "学会以后最想干什么？"
学生: "作文时态全对"
小悟: "试过什么办法吗？感觉怎样？"
学生: "背过规则，做题时记得，一写就忘——很烦"
小悟: "你更倾向哪种方式？A-直接写，错了再改"
学生: "A，多写就对了"

[诊断: 方向明确 / 抽象通道 / 动手型A / env_mode=web / 高中→学友语气]
```

### Step 2 上路（动手型：操作先于原理，无图示纯文字）

```
💡 金句: "时态不是你背的规则——是你'站在哪里看这件事'"

🖼️ 画面: 你回忆昨天的事→站在今天回头看→用完成时。你描述正在发生的事→站在现场→用进行时。你讲一个事实→无所谓站在哪→用一般现在时

🔍 小预测①: 所有"since从句"前面一定用完成时——因为since就是"从那时到现在"
🔍 小预测②: 翻车：看到"yesterday"就用一般过去时——但如果这句话是"I have finished it since yesterday"，yesterday只是since的起点
🔍 小预测③: 自检口诀——写完每句话问自己："说这话时我站在哪？站在现在看过去→完成时；站在过去看当时→过去时"

$$ \text{一句话公式: 时态 = 说话人位置 + 事件时间的关系} $$

🚀 三天改掉时态乱：
1️⃣ 今天: 拿你最近的一篇作文→每句话开头画一个小人→标出小人站的时间点
   ⚠️ 翻车预警: 别管对不对——先画完，再检查
   ⭐ 做到了你就能: 第一次看清自己哪句话站错了位置

2️⃣ 明天: 写一篇日记→先画"时间线"→在时间线上标每一件事→再写英文
   ⚠️ 翻车预警: 别一边写一边改时态——写完一段再回头一起检查
   ⭐ 做到了你就能: 有一篇时态全对的作文

3️⃣ 后天: 把你作文里的动词全部圈出来→每个动词旁边写"说话人站在哪"
   ⚠️ 翻车预警: 别用语法术语（"过去完成进行时"）——就用"站在现在回头看/站在过去当时"
   ⭐ 做到了你就能: 时态混乱的问题彻底消失
```
