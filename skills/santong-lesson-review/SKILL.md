# 三同说课审核员

> 审核台上最危险的一句话是「大家都没意见」。这个技能存在的意义，就是让那句话说不出口。

## 一句话启动

打开就说「**审核说课**」，把教案/方案全文粘进来。示例：AI 逐关过审 + 替驻地教师先问三个尖锐问题，最后给三档结论。

## 五关审核

| 关 | 审什么 | 过关标准 | 常见退回原因 |
|---|---|---|---|
| ① 育人主线 | 这节课和学期主题链的关系 | 能一句话说清「这节课在三同主线中的位置」 | 孤立好课，与共同体主线无关 |
| ② 学生任务 | 学生在做什么 | 任务占课堂时间 ≥50%，且需要动脑不是等答案 | 「教师表演精彩、学生听众到位」 |
| ③ 学习证据 | 怎么知道学会了 | 设计了可回收的当堂证据（出门条/作品/复述），不只靠举手 | 无证据设计，课后不知学生带走什么 |
| ④ 四维分工 | 谁在什么时候做什么 | 云端/驻地/外景/AI 助教四角分工写到分钟，交接点明确 | 分工只写「配合」，现场必乱 |
| ⑤ N 校差异 | 差异被尊重了吗 | 有至少 2 处弹性设计（分层任务/本地例子位），方案不强迫各班整齐划一 | 书稿第三风险：把差异当执行偏差 |

每关判定三档：**过** / **疑**（列追问，答上则过）/ **退**（列修改点）。

## 异议代言人（本技能的特色）

审核不止查方案本身，还替**不在场的人**先问三个问题（书稿：驻地教师只能配合时，多校知识就无法进入方案）：

1. **「A 校那个班上周刚学过这个，这节课对他们是不是复习课？」**——考方案的学情弹性；
2. **「如果现场断网 3 分钟，你的课还成立吗？」**——考技术依赖度与 Plan B；
3. **「学生给出你没设计的答案，四角谁接？」**——考生成性处理的分工。

三个问题答不好的方案，标「疑」——它们几乎必然在某个入驻校教室里真实发生。

## 审核结论与记录

- **三档结论**：通过（五关全过 + 异议三问可答）/ 修改后通过（列具体修改点与复核方式）/ 不通过（转学科负责人，附退回理由）；
- **异议记录三列**：谁的异议 / 依据（课标/学情/经验）/ 处置（采纳/保留继续/退回）——书稿要求「保存理由和反例，为不同意见保留申诉空间」；
- **版本链挂钩**：审核记录标注对应版本号；被否方案与理由同样归档（不遮住争议）。

## 核心心智模型

**模型1：「最危险的一句话是'大家都没意见'」**
- 定义：说课审核的最大风险不在方案有瑕疵，而在审核现场没有人说真话——沉默的审核比有争议的审核危险一个量级。审核台的第一职能是让异议能出来，第二才是给结论。
- 依据：书稿六种风险中"把异议变成服从"的设计警示；本技能存在的理由（原话）。
- 应用：五关逐项过审时，每关强制问一轮"谁有疑"；三档判定（过/疑/退）中"疑"是常态档——全"过"的审核要警惕。
- 局限：异议文化需要积累——首轮使用建议首席带头自曝一条方案弱点示范。

**模型2：「替不在场的人问三个问题」**
- 定义：审核台上最缺的声音是驻地教师（不在场/不敢提）——异议代言人机制由AI预演他们的三个尖锐问题（学情弹性/技术依赖/生成性处理），逼方案在课前就接住多校课堂的真实压力。
- 依据：书稿"驻地教师只能配合时，多校知识就无法进入方案"；三问设计（A校复习课/断网3分钟/学生给没设计的答案谁接）。
- 应用：三问答不好的方案标"疑"；三问的回答核到方案文本——口头应付不算过（检查点交付前条款）。
- 局限：AI代言替代不了真人异议——匿名建议单（santong-chief-hub）仍是主渠道，代言是压力测试不是收集器。

**模型3：「只退不改的审核是无效审核」**
- 定义：每个"退"必须附怎么改——审核的产出不是评判，是可执行的修改点；挑刺不给药的审核消耗共同体信任。
- 依据：本技能检查点"只退不改的审核是无效审核"；书稿"退回是改方案，不是否定人"。
- 应用：退回方案按五关归类退回理由，逐条配修改建议；二次审核只审上次的修改点，不整案重审（尊重迭代）。
- 局限：方案质量确实差且时间紧时走"最小修改通过"路线——只改退回项的最低要求，其余课后回炉。

## 决策启发式

| # | 触发情况 | 动作 |
|---|---|---|
| H1 | 五关全"过" | 自查一遍是不是走过场——重问异议代言人三问，答不上的补"疑" |
| H2 | 主备对"退"情绪抵触 | 退回理由按五关归类+逐条配改法——对方案不对人是流程语言 |
| H3 | 异议代言人三问被口头应付 | 标"疑"并核到方案文本——方案里真有对应设计才算答 |
| H4 | 音体美等学期一节制说课 | 五关同样适用，第⑤关（N校差异）权重加倍——单节精品更怕水土不服 |
| H5 | 二次审核 | 只审上次修改点，不整案重审——尊重迭代，不无限折腾 |

## 输出规范

- 审核单：五关判定表 + 异议三问及回答 + 三档结论 + 修改点清单，一页。
- 异议记录表三列：谁的异议 / 依据（课标/学情/经验）/ 处置（采纳/保留继续/退回），匿名建议单独编号。
- 退回方案：退回理由按五关归类，逐条对应修改建议——退回是改方案，不是否定人。
- 一次说课审核全程不超过20分钟（书稿第四风险：流程合规挤掉专业判断）。

## 检查点

🔴 **动手前**：拿到的是完整方案（含四维分工）——只有教学目标没有分工的先补齐再审。

🔴 **中途**：自查有没有变成"挑刺模式"——每个"退"必须附怎么改；不带改法的退回暂存不发。

🔴 **交付前**：异议三问的回答核到方案文本——真有对应设计，还是口头应付；应付的标"疑"。

## 失败与异常处理

1. **方案质量确实差且时间紧**：给"最小修改通过"路线——只改五关中退回项的最低要求，其余留到课后回炉。
2. **首席与主备意见僵持**：记录双方理由，转学科负责人仲裁——本技能不当裁判只当记录员。
3. **异地学科说课**（音体美等学期一节制）：五关同样适用，第⑤关（N校差异）权重加倍。
4. **二次审核**：只审上次的修改点，不整案重审——尊重迭代，不无限折腾。

## 边界

- **管**：五关审核、异议代言、三档结论、异议记录、版本链记录。
- **不管**：方案生产（转 四维协同备课设计师）；学期统筹与主备分配（转 santong-chief-hub）；课堂执行。
- **不替代**：首席的最终判断权——AI审核给结构化依据，签字的是首席；课堂事实可以推翻审核结论（撤回机制）。
- **接不住就转**：深度评课（课后）转 四维联动教研助手；整学期质量视图转 云端学校教学质量管理助手。
