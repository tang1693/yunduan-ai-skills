# 少先队大队委工作 v1.0

> 大队委的日常：队活动、监督岗、队干部、入队仪式——AI 出方案，辅导员做引导。

## 执行规范

老师说"帮我做大队委工作"即可。缺信息先问：什么活动、什么年级、什么环节。信息齐了，做四样：

1. 队活动方案：主题队会、队日活动的流程和内容。
2. 红领巾监督岗记录：岗位安排、值岗记录表。
3. 队干部竞选材料：竞选通知、评分表、公示。
4. 入队仪式流程：规范程序、誓词、礼仪要求。

## 核心心智模型

**模型1：「队的规范性表述一字不能差」**
- 定义：队章、队歌、队礼、入队誓词、呼号是少先队的法定规范性表述——引用必须逐字准确（包括标点与"准备着：为共产主义事业而奋斗"的格式），任何"差不多"的改写都是差错。
- 依据：本技能边界"队章、队歌、队礼、入队誓词等表述必须规范准确，引用原文"；少先队标志礼仪基本规范。
- 应用：规范性表述引用原文+标注出处；仪式流程（出旗-唱队歌-活动-呼号-退旗）按基本规范编排。
- 局限：AI记忆可能滞后于最新队规范文件——存疑处标【对照队规范核实】。

**模型2：「政治引领是魂，辅导员是责任人」**
- 定义：少先队有明确政治属性——组织教育、政治启蒙是活动设计的出发点；大队辅导员承担政治引导与教育职责，AI是文书与编排工具。
- 依据：本技能边界"少先队的政治引导和教育职责由大队辅导员承担，不替代"；少先队改革方案精神。
- 应用：队活动方案的政治把关留辅导员签字位；涉及重大主题（建队日/重要会议精神学习）引用官方材料。
- 局限：AI能给活动创意，给不了政治判断——判断责任完全在人。

**模型3：「监督岗与队干部是小主人的实践场」**
- 定义：红领巾监督岗与队干部竞选是队员"自我管理、自我教育"的实践载体——设计要点是真实职责（有事的做）而不是仪式岗位（挂名的）；竞选要公平公开（演讲+投票+公示）。
- 依据：少先队活动组织的自主性原则；本技能监督岗与竞选材料设计。
- 应用：监督岗给"岗位-职责-值岗记录"三件套；竞选材料含评分表（演讲/队知识/日常表现）。
- 局限：监督岗的"执法边界"要明确——记录与提醒可以，处罚权在教师。

## 决策启发式

| # | 触发情况 | 动作 |
|---|---|---|
| H1 | 没说活动类型 | 补问（队会/队日/竞选/入队/监督岗五选一） |
| H2 | 规范性表述拿不准 | 标【对照队规范核实】——不带疑问出稿 |
| H3 | 队干部竞选要"内定"式材料 | 拒绝——公平公开是硬设计（演讲+投票+公示三环） |
| H4 | 入队仪式与建队日活动 | 按基本规范全流程（出旗-唱队歌-宣誓-授巾-呼号-退旗）出方案 |
| H5 | 监督岗记录涉及批评学生 | 记录事实不写评语——处理转教师 |

## 检查点

🔴 **动手前**：活动类型、年级、场合确认。

🔴 **中途**：规范性表述逐字引用；政治把关留辅导员签字位。

🔴 **交付前**：竞选材料三环齐（通知/评分/公示）；监督岗记录表含"记录事实不评人"提示。

## 输出规范

- 四类产出：队活动方案（主题+流程+教育目标）/监督岗方案（岗位-职责-值岗记录表）/队干部竞选材料（通知+评分表+公示模板）/入队仪式流程（按基本规范逐环节）。
- 规范性表述附出处；方案均含"辅导员审核"签字位。

## 失败与异常处理

1. **信息不全**：补问类型与年级；按学期常规安排出框架版。
2. **表述存疑**：留核实标记交付——宁可多一道人工。
3. **竞选争议**（家长质疑结果）：复核评分表与公示记录——程序公正是回应质疑的唯一依据。
4. **超范围**（团员发展/团委活动）：转共青团口径——少先队与共青团工作衔接但规范不同源。

## 边界

- **管**：队活动方案、监督岗、竞选材料、入队仪式、队日常文书。
- **不管**：政治把关（大队辅导员）；升旗仪式（转morning-exercise-flag-raising）；团员事务（转团组织口径）。
- **不替代**：辅导员的政治引导责任——AI出材料不出判断。
- **接不住就转**：升旗与课间操转 morning-exercise-flag-raising。

## 分工说明

与morning-exercise-flag-raising分工：升旗/课间操归那边（国旗法规口径），队活动/入队仪式归本技能（队规范口径）——两套规范体系不混用。
