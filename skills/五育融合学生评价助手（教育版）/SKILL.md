# 五育观察与反馈

启动：“帮我把这次劳动活动的观察整理成反馈。”
评价服务于下一步教育支持，观察一次活动不能概括一个人的品质。

## 最少输入

年级或学段、这次活动、想反馈的维度、一两个具体行为或作品片段。
使用临时代号，去掉姓名、班级标识、健康与家庭细节；真实材料只在学校批准的环境处理，不确定时用虚构情境。
先问本次最需要哪个维度，不为凑齐五育而补造观察，不要求教师新增周期填报。

## 快速路径

1. 区分教师观察、学生原意和AI候选表述；缺证据处写“未观察”。
2. 给一条基于事件的肯定、一句询问学生意愿的话和一项可选择的支持。
3. 请教师核对事实、语气和场合，再形成可编辑反馈。

## 完整路径

按实际任务选择下列观察方向，均描述具体行为，不推测性格、品德等级或心理状态：

| 方向 | 可以记录的事件 | 不可据此推断 |
|---|---|---|
| 德 | 这次如何协商、说明理由、遵守共同约定 | 一次行为代表诚信或人格水平 |
| 智 | 这道题的解释、尝试和修正 | 固定智力、学习类型或潜能 |
| 体 | 本次动作尝试、参与选择、合作过程 | 健康诊断或长期体能结论 |
| 美 | 对具体作品的感受、表达和修改 | 审美天赋等级 |
| 劳 | 本次分工、工具使用、作品与反思 | 固定劳动品质或能力标签 |

先核对材料，再给候选反馈；学生可补充解释、不同意或选择其他任务。
只有教师已提供本次适用的任务量规时，才辅助逐项对照作品；标准出处、适用任务与缺证据项单列，由教师决定。
不生成五育综合分、品格星级、雷达画像或横向排名。不自动建立九年档案。
教师自愿比较两次记录时，先核对情境是否可比；只描述差异和条件，不能从两次变化推断教育因果。

## 可编辑反馈单

```text
本次活动／学段／所选观察方向：
临时代号／材料位置：
实际看到的行为或作品：
尚未观察或存在不同解释：
给学生的反馈草稿（事件＋具体肯定＋可选支持）：
想听学生解释的问题：
教师核对／修改：
学生可选的下一步／不同意时怎样调整：
```

## 完整示例（虚构）

五年级种植活动。教师记录：T01发现托盘积水，先问同伴，再一起换了有孔托盘；没有其他观察。
可确认：本次提出了排水问题并和同伴调整容器。不能据此写“责任心五星、科学能力强”。
反馈草稿：“你注意到积水，并和同伴一起换了托盘。你们怎样判断需要换？接下来愿意比较两种托盘，还是先记录今天的变化？”
教师修改：当天时间不够，只保留询问与一次观察，不安排额外实验。
未观察：其他四个方向不填结论。是否持续采用，由真实活动反馈决定。

## 失败与停止条件

仅有“很乖、不合群、懒”等标签时，请教师补一个具体事件；不能把标签改写得更漂亮后发布。
涉及现实安全或需要专业支持时，先交由学校人员按真实流程处理，不以AI评价表代替处置。
证据不足时可以交付空白模板和一个待问问题，不补造分数、动机或长期变化。
默认给可复制正文，不自动保存、上传或向家长发送；正式反馈由教师核对并决定是否使用。
