# 教育研究学术图表 Skill（精简版）

为教育研究论文制作规范、可读的学术图表。核心原则：**图表服务于论点，而非炫技**。

## 和教育研究最相关的8种图表类型

| 图表类型 | 教育研究典型用途 | 示例 |
|----------|-----------------|------|
| **分组柱状图** | 实验班vs对照班对比；不同年级/性别的成绩对比 | 实验班语文成绩高出对照班8.2分 |
| **堆积柱状图** | 问卷维度得分构成；能力水平分布 | 学生科学素养各维度达标率 |
| **折线图** | 前后测成绩变化趋势；多轮干预效果追踪 | 三轮行动研究中学生成绩变化轨迹 |
| **散点图/气泡图** | 两变量关系探索；效度分析 | 学习时间与成绩的相关性 |
| **热力图** | 课堂行为分布；知识点掌握矩阵 | 不同知识点班级错误率矩阵 |
| **雷达图** | 多维度能力画像；素养维度对比 | 实验班vs对照班核心素养5维度对比 |
| **词云图** | 学生访谈/反思日志/课堂话语的高频词分析；教育政策文本关键词提取 | 学生"科学课体验"反思日志的高频词云 |
| **桑基图** | 学习路径流向；知识点迁移路径；教学资源流向 | 从"前概念"→"教学干预"→"概念转变"的学习路径流 |

> **词云图工具**：推荐 `wordcloud` 库 + `jieba` 中文分词。注意：词云图需要先清洗停用词（"的""了""是"等），再分词统计。教育质性研究论文中，词云通常配合原文引用一起呈现。
> **桑基图工具**：推荐 `plotly`（`go.Sankey`），交互式且中文兼容好。也可用 `pySankey` 做静态版。教育研究中的桑基图常用于展示学习路径或知识迁移流向，节点标注意义而非纯数值。

## 制作流程（先签约再画图）

### 第1步：图表合约

在写代码之前，先明确：

1. **核心结论**：这张图要证明什么？（一句话）
2. **证据链**：每张子图承载什么独特证据？（不要两张图说同一件事）
3. **图表类型**：上面8种中选一种
4. **输出规格**：尺寸/格式/分辨率

### 第2步：Python快速开始

```python
import matplotlib.pyplot as plt
import matplotlib as mpl

# 中文支持（教育图表必须）
mpl.rcParams['font.sans-serif'] = ['SimHei', 'Microsoft YaHei', 'WenQuanYi Micro Hei']
mpl.rcParams['axes.unicode_minus'] = False   # 解决负号显示

# 学术图表基础样式
mpl.rcParams.update({
    'font.size': 11,
    'axes.spines.right': False,
    'axes.spines.top': False,
    'axes.linewidth': 0.8,
})
```

### 第3步：教育图表配色约定

| 用途 | 配色原则 | 示例 |
|------|----------|------|
| 实验班vs对照班 | 实验班用深色（#2C5F8A），对照班用浅灰（#AAAAAA） | |
| 前后测对比 | 前测浅色→后测深色，同一色系 | 前测 #AED6F1，后测 #1A5276 |
| 多组对比 | 使用2-4种区分度高的颜色 | ColorBrewer Set2 |
| 成绩高低 | 高→红/暖色，低→蓝/冷色（中国A股习惯） | |

### 第4步：导出规则

- 主输出：**PNG 300dpi**（教育期刊投稿最通用格式）
- SVG可选，但不是教育期刊必需
- 图注字号比正文小1-2号
- 图表中的所有文字必须和论文正文一致（术语、单位、缩写）
- **图要又大又精致**：图表尺寸足够大、分辨率清晰（300dpi），字号/标签清晰可读，线条 ≥2px；用渐变/阴影/高光，配色统一，不用平涂色块和单线，比例坐标准确。

## 教育图表常见雷区

| ❌ 不要做 | ✅ 应该做 |
|-----------|----------|
| 3D柱状图/饼图 | 2D 平面图更精确 |
| 纵轴不从0开始（误导效应量） | 纵轴从0开始，或明确标注截断 |
| 无误差棒/无样本量标注 | 标注标准差/标准误 + n=XX |
| 颜色过多（>5种） | 2-4种，或使用一个色系的渐变 |
| 图例远离数据区 | 图例放在图表内或紧邻 |
| 图表标题 ="Figure 1" | 标题应有信息量，如"图1 实验班与对照班期末测试成绩对比" |

## 图表审核清单（画完必查）

- [ ] 图表能在不读论文正文的情况下被理解吗？
- [ ] 所有轴都有标签吗？单位标注清楚吗？
- [ ] 颜色对色盲友好吗？（可用 www.color-blindness.com 检查）
- [ ] 样本量标注了吗？
- [ ] 误差标注了吗？（标准差/标准误/置信区间）
- [ ] 显著性标注了吗？（* p<.05, ** p<.01, *** p<.001）
- [ ] 图表标题有信息量吗？
- [ ] 导出分辨率 ≥ 300dpi 吗？

## 失败与异常处理

1. **信息不全**：如果用户没给教学主题、学段学科和目标页面/课件形态，先问清「什么主题、给几年级、要什么形态（幻灯片/网页/单页图）」，问清再动手；实在拿不到，就按最保守的假设出一版，并在开头标注「假设：…」，不编造未提供的信息。
2. **材料读不到**：如果上传的文件打不开、为空或格式不支持，说清具体原因（损坏/需转换/内容为空），并给替代路径（截图、粘贴文本、换格式重传）；不猜文件里的内容。
3. **条件冲突**：如果用户的要求与已给材料或学校规定冲突，不直接照做也不直接拒绝，先列出冲突点，给 2 个可选处置方案，等用户选。
4. **超出范围**：如果请求属于代做学校宣传物料、对外发布的商业设计，说明这部分不在本技能范围，按「转教学设计类技能」处理，不硬答。


## 边界

1. **不做统计分析**：数据统计计算由用户自行完成，本 skill 只负责可视化呈现
2. **不支持3D图表**：学术图表规范要求2D视图，不支持3D图表生成
3. **不处理非教育数据**：仅适用于教育研究数据
4. **不生成交互式图表**：输出为静态SVG/PNG图片

## 图表类型速查

| 数据类型 | 推荐图表 | 适用场景 |
|---------|---------|---------|
| 前后测对比 | 堆叠柱状图 + 折线图 | 实验组/对照组成绩对比 |
| 问卷调查 | 柱状图/雷达图 | 量表各维度得分对比 |
| 成绩分布 | 箱线图/直方图 | 班级成绩分布特征 |
| 课堂观察 | 热力图 | 学生参与度/注意力分布 |

## 图表规范

- 字号: 中文标签 >= 10pt
- 配色: 学术风格，蓝/橙/绿/灰四色
- 分辨率: 300dpi，适合论文印刷
- 输出: 默认SVG矢量图，可按需转为PNG
