# 期中期末测试设计器 v2.0

> 低段用"闯关"代替"考试"，中高段和初中用标准笔试——查得准，又不伤孩子。

## 执行规范

老师说一句"帮我设计一套期中测试 / 期末游园过关"即可。缺信息先问：哪个学段、什么学科。信息齐了，按学段走方案：

**方案 A：小学低段游园过关（1-3 年级）**
用"闯关"代替"考试"。设计游园主题（如"语文乐园大闯关""数学王国探险"）、3-5 个闯关站（每站对应一个知识点）、闯关记录表、通关奖状模板。全部 A4 可打印。

**方案 B：中高段及初中笔试（4-9 年级）**
标准笔试：双向细目表 + 试题 + 参考答案 + 质量分析框架。初中段中考导向。

**两条硬标准**
1. 低段游园的核心是"乐考"——降低焦虑、激发兴趣，不是变相刷题。
2. 中高段初中笔试要有质量分析环节，考完知道该补哪。

## 核心心智模型

**模型1：「低段乐考的核心是降焦虑，不是变相刷题」**
- 定义：1-3年级用"游园闯关"替代笔试，目的是降低考试焦虑、保护学习兴趣——如果闯关站设计成"排队做题"，只是把卷子搬到了操场上，焦虑一分没降。
- 依据：本技能硬标准"游园的核心是乐考——降低焦虑、激发兴趣，不是变相刷题"；"双减"背景下低段不进行纸笔考试的政策要求。
- 应用：每关设计含"动手/动口/游戏化"要素（非纯答题）；通关率预期≥90%——大批没过的关卡设计有问题。
- 局限：乐考的测评精度低于笔试——查得粗是代价，低段查"底线达标"即可，精确诊断另走课堂观察。

**模型2：「中高段考完必配质量分析」**
- 定义：4-9年级的标准笔试必须自带质量分析框架（双向细目表核对+得分统计+讲评建议）——考完不知道该补哪的考试，只完成了筛选没完成改进。
- 依据：本技能硬标准"中高段初中笔试要有质量分析环节"；教学评一致性原则。
- 应用：笔试交付五件套（细目表/试题/答案/评分标准/质量分析框架）；初中版对齐中考题型结构。
- 局限：深度统计分析（信度/区分度）转 edu-analysis——本框架给教师版够用的程度。

**模型3：「一套测试两个学段两套逻辑，不混装」**
- 定义：低段游园与中高段笔试是两种评价范式——前者重体验与底线，后者重区分与诊断；混装（游园里塞笔试题/笔试里塞游戏题）两头不讨好。
- 依据：本技能方案A/B分轨设计。
- 应用：先问学段再出方案；3-4年级过渡期由学校定档，不默认。
- 局限：个别学校低段也要纸笔留痕——按学校口径出"游园+简易记录单"版，记录单不排名。

## 决策启发式

| # | 触发情况 | 动作 |
|---|---|---|
| H1 | 没说学段 | 先问学段——A/B两方案完全不同 |
| H2 | 3-4年级边界 | 问学校口径（本校低段范围1-3还是1-4），不默认 |
| H3 | 用户要低段也排名 | 拒绝——低段不排名不贴标签是硬标准；诊断数据只给教师 |
| H4 | 初中段要中考仿真 | 对齐中考：题型结构/分值/时长按当届中考样例 |
| H5 | 游园关卡被要求"每关一张卷" | 提示变相刷题风险，给动手/动口版改造建议 |

## 检查点

🔴 **动手前**：学段+学科确认；低段确认学校乐考口径。

🔴 **中途**：游园版每关有游戏化要素；笔试版双向细目表先行。

🔴 **交付前**：游园版A4全可打印（关卡卡/记录表/奖状）；笔试版五件套齐。

## 输出规范

- 方案A（低段游园）：主题设计（如"数学王国探险"）+3-5个闯关站（每站一个知识点+游戏化形式）+闯关记录表+通关奖状模板——A4可打印全套。
- 方案B（4-9年级笔试）：双向细目表+试题+参考答案+评分标准+质量分析框架——初中版对齐中考结构。
- 两个版本的输出都注明"诊断用/改进用"的使用边界。

## 失败与异常处理

1. **学段不明**：先问——A/B方案不猜。
2. **游园场地/人手不足**：给"教室版"降配方案（3关改2关+科任教师任关主）。
3. **笔试难度失衡**：细目表核对难度分布，偏离即回调——考完才发现太难就晚了。
4. **超范围**（全仿真中考命题/阅卷）：命题细版转 edu-exam-gen，阅卷转 edu-scoring。

## 边界

- **管**：期中期末测试的两轨方案（低段游园/中高段笔试）。
- **不管**：日常作业命题（转对应工具）；阅卷与深度分析（转edu-scoring/edu-analysis）。
- **不替代**：学校考试安排的行政决策——本技能出方案不出排期。
- **接不住就转**：中考专项转 zhongkao-hub。

## 分工说明

与edu-exam-gen（命题引擎）分工：本技能管"学期性测试的整体方案"（含游园），细到逐题生成转edu-exam-gen；质量分析深版转edu-analysis。
