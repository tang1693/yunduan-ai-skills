## 完整工作流：报销材料闭环

用户启动“报销材料闭环”或要求完成整件工作时，优先读取[完整流程与模板](references/完整任务补充.md)，在同一对话维护同一份可编辑产物。默认覆盖所需环节，不要求用户拼装其他Skill、逐段确认或重填已给材料。
用户只需局部时保留以下原有专项做法；用户可修改、拒绝或暂缓。实际观察、落实、验收、审批和效果只能依据真实记录，未发生就留空。


# 报销材料预核对：先读本校制度，再核材料

启动：“帮我检查这份培训报销缺什么，按我提供的本校制度。”
本方法帮助经办人减少材料往返，不代替财务人员审批，不鉴定发票真伪，不作税务或法律意见。

## 最少需要什么

从现有材料提取费用类型、业务发生时间、经费来源、明细与拟报金额，只追问缺失的关键项。
请提供本校适用制度相关段落、通知或审批要求，记录制度名称、版本/文号、生效时间、适用人员和条款位置。
规则是否适用于该时间、地区、人员与专项经费，需要财务人员确认。不同文件冲突时列差异，暂停对应判断。
不预设住宿、伙食、交通、采购、报销期限或档案年限的全国通用数字。

## 两条工作路径

- **没有制度也可先做**：核对明细加总、重复条目、材料是否可读、日期与数量是否自洽，列出待问财务的问题。状态只能是“材料/规则待补充”，不能写合规、退单或可报销。
- **已有适用规则**：把条款转成规则表，请经办人或财务核对适用性，再逐项做材料比对。AI提出疑点，由财务人员决定处理。
原始票据、账户、税号及个人信息只在获准的本机环境处理；共享时使用去标识样例，不能把真实票据上传广场。

## 五步核对

1. 读规则：费用类别、限额计算口径、附件、审批链和例外条件，逐条标出处；没有明文就填未知。
2. 整理材料：按通知/合同、票据、行程或数量、审批、验收等分类；所需附件取决于本校规则，不一律要求全部。
3. 核算：逐项列数量×单价、合计、票面金额与拟报金额；币种、人次、天数、晚数分别写清，不混用。
4. 比对：事实、条款、差异、需补什么分列；对不清晰图像不推断税号或签字，对真实性问题建议走本校正式查验流程。
5. 交付：给一份可编辑清单，状态用“已按所给材料核对／待补材料／待确认规则／转财务复核”，不承诺补材料后必定报销。

## 规则与输出模板

```text
任务/费用类别/业务时间/经费来源/材料范围：
规则表：制度名称与版本｜有效时间｜适用范围｜条款位置｜具体要求｜适用性确认人
核对表：项目｜已知事实/材料位置｜引用规则｜计算与差异｜建议动作｜待确认人
金额核算：明细×数量→合计→与拟报差额
尚未核实：真实性/授权/例外/制度冲突等
下一步：经办人补__；财务确认__
AI材料预核对，未经财务审批。教师或财务可修改/放弃本建议。
```

## 完整示例（全部虚构，仅演示规则读取，不是财务标准）

经办人提供：某校本次培训通知附件B第2条，适用本次获批培训，住宿每人每晚不超过300元；本次一人两晚，票据明细280元×2，申请合计580元。
规则表：名称“本次培训通知附件B”，版本与批准时间由财务补核；第2条住宿300元/人/晚，仅本示例条件。
核算：280×2=560元，与申请580元差20元。
比对：明细每晚280不超过所给300，但不能仅凭此判可报销；需确认该通知有效且适用、其他材料与审批要求。
输出状态“金额差异待更正；规则适用性待财务确认”；建议经办人核对20元来源，财务核对有效通知与审批。
若经办人说“本校已改标准”，立即停止沿用旧条款，请提供新制度，不凭旧例继续判断。

## 失败与边界

| 失败 | 正确做法 |
|---|---|
| 无制度就按住宿350、餐补100等旧数字判超标 | 撤回数字规则，只做材料与算术核对，请财务补适用制度 |
| 把“补说明”写成“补后即可报销” | 改为提交财务判断例外条件，AI不承诺审批结果 |
| 发票模糊却填入税号/签章 | 标不可辨，请重拍或人工核对，不猜 |
| 报价或票据疑似重复 | 列出匹配依据与可能差异，交人工核对，不指控个人违规 |
| 制度冲突/专项经费范围不明 | 暂停对应结论，记录双方依据，交有权人员裁定 |

不得建议变更真实事由、拆单绕限额、伪造签字或挪用经费。保留原材料，修改建议与原事实分开。
文件保管期限、采购程序和例外审批均依本校适用制度，由财务人员决定。
