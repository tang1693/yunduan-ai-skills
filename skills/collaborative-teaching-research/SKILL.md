# 同备同研同教 Skill · v2.0

## 一句话启动

打开就说「**组织协同教研**」，不用先描述格式。示例：「跨校集体备课，下周数学组」——出协同备课议程+分工+产出物清单。

## 核心心智模型

**模型1：三同是流水线，不是三场活动**——同备（共建方案）→同研（共验课堂）→同教（共施教学）是同一条价值链的三个环节：备的方案在研中检验、研的发现回改教的实施。割裂着做三场活动，三头落空。依据：云端学校"一域二伴三同四维"教学模式的协同教研机制。应用：任何单环节方案都要标注"上游输入是什么、下游输出给谁"。局限：单次活动可以只做一个环节，但学期计划必须三环齐备。

**模型2：学情差异是核心资产**——跨校教研最有价值的不是"统一口径"，是各校学情的差异及其应对：同一个教案在A校要降梯、在B校可提速——适配点清单比统一教案更值钱。依据：1+N共同体的 heterogeneous 学情现实；差异化教学理论。应用：同备的产出物清单必含"N校适配点清单"，同课异构的研讨聚焦"设计差异背后的学情差异"。局限：需要绝对统一的考试命题场景（联考），以统一为要，差异适配退位。

**模型3：四维分工观察，每人只看一维**——同步教研的观课不搞"人人都看全场"：主讲看内容、驻地看学生、外景看场景、AI看数据——分维度采集比泛泛而看深十倍。依据：课堂观察的分工范式（LICC）；注意力资源有限性。应用：观察量表按四维分列，研讨时每人只说自己观察的维度。局限：小规模教研（<4人）合并维度，两人对两维。

## 决策启发式

1. **六步一步不跳**——同备的"定内容→分主备→学情反馈→汇总→说课审核→二轮定稿"，跳步的代价是二轮返工。
2. **适配点清单与统一教案同等重要**——只交统一教案不交适配点的协同备课是半成品。
3. **研讨只说观察维度，不说整体印象**——"我觉得这节课不错"不是反馈，"我看的维度里学生提问了7次"才是。
4. **改进清单不超过五条，条条有主**——没有责任人的改进项=下次教研的道歉开场白。
5. **四件套归档（议程/签到/观课表/改进清单）**——学期末汇编就是共同体成果的原始素材，平时不归档期末抓瞎。

## 执行规范

老师说"帮我组织协同教研"即可。缺信息先问：什么学科、哪些学校参加、什么形式（集体备课/同步教研/同课异构）。信息齐了，按形式出方案：

**协同备课（三同的"同备"）**
1. 议程：定内容（首席+主讲）→ 分配主备 → 各校学情反馈 → 主备汇总 → 说课审核 → 二轮修改定稿——六步一步不跳。
2. 分工表：环节 / 责任人（哪校哪师）/ 交付物 / 截止时间。
3. 产出物清单：统一教案 + N校适配点清单 + 学情采集表（各校课前回收）。

**同步教研（同研）**
1. 观察量表：四维分工观察（主讲看内容/驻地看学生/外景看场景/AI看数据）。
2. 研讨议程：授课 → 分维度反馈（每人只说自己观察的维度）→ 改进清单 → 下次跟进事项。

**同课异构**
两校同课题独立备课 → 双向观课 → 对比研讨（设计差异背后的学情差异）。

## 检查点

🔴 **动手前**：确认三同环节定位（本次做哪环、上下游是什么）——单环节方案标注接口。

🔴 **中途**：方案的每个环节有明确责任人（哪校哪师）——"大家共同负责"等于没人负责。

🔴 **交付前**：产出物清单含适配点清单与学情采集表——缺这两样的协同备课方案退回补。

## 输出规范

- 按形式出对应方案包（议程/分工表/观察量表/产出清单），字段齐全可直接发群。
- 改进清单条条有主有期限，不超过五条。
- 活动四件套（议程/签到/观课表/改进清单）当天归档。

## 失败与异常处理

1. **某校临时缺位**：议程不变、该校环节顺延或线上补位；学情反馈缺的标注"待补"，不虚构。
2. **研讨跑题成吐槽大会**：主持人（方案里预设）拉回"只说观察维度"规则；情绪问题记下来另渠道处理。
3. **主备成果被质疑推翻**：按说课审核的异议机制走——记录异议、二轮修改、版本链留痕，不现场争执。
4. **远程线路故障**：启动预案——本地研讨+录播回看，下次补双向环节；技术检查单参照四维协同授课策划器。

## 边界与提醒

- 跨校教研的核心资产是**学情差异**——各校"不一样的地方"是最有价值的信息，不追求整齐划一。
- 远程协同提前测线路（参照四维协同授课策划器的技术检查单）。
- 活动记录归档：议程/签到/观课表/改进清单四件套，学期末汇编成共同体教研成果。
- **不替代**：首席与各校教研组长的现场组织——AI 出方案与模板，把人聚起来是人的事。
- **接不住就转**：首席统筹与审核工作台转 santong-chief-hub；四维深度备课转 四维协同备课设计师；课后深度复盘转 teaching-postmortem。
