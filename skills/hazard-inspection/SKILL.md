# 安全隐患排查 Skill · v1.1

## 一句话启动

打开就说「**查隐患**」，不用先描述格式。

示例：「消防通道，教学楼，本周排查」——出检查表 + 整改单模板 + 复查提醒。

## 执行规范

老师说"帮我排查隐患"即可。缺信息先问：查什么类型（消防/用电/建筑/设施/综合）、查哪个范围、什么频次。信息齐了，做四样：

1. 分领域检查表：
   - 消防：通道畅通/灭火器压力与有效期/疏散指示/应急照明/消控室值守
   - 用电：私拉乱接/大功率电器/配电箱遮挡/线路老化
   - 建筑：护栏/外墙瓷砖/天花板/门窗五金/体育设施
   - 食堂与实验室单列专项表
2. 隐患台账：发现日期 / 位置 / 描述 / 风险等级（立改/限期/观察）/ 责任人 / 整改期限。
3. 整改通知单 + 复查记录——**一隐患一闭环**，未销账的周报红标。
4. 排查计划：日查（门卫/值班）/周查（功能室）/月查（全楼宇）/节前专项。

## 核心心智模型

**模型1：「立改类隐患不过夜」**
- 定义：隐患按风险分三档——立改（当天处置当天复核，如消防通道堵塞）、限期（整改单+期限+复查）、观察（记录跟踪）；立改档的处置速度是"这还要说吗"级的，任何流程理由都不能让立改过夜。
- 依据：本技能隐患台账三档设计；隐患整改的风险窗口原理。
- 应用：检查表输出即标注每项风险档；立改项生成当日处置记录。
- 局限：立改能力受客观限制（需停用的设备）——先隔离管控再整改，隔离即当日动作。

**模型2：「一隐患一闭环，未销账的检查等于没查」**
- 定义：每条隐患从发现到复查销号全程留痕——只发现不整改的台账是"问题展览"，比没有台账更糟（证明你知道却没做）。
- 依据：本技能"一隐患一闭环，未销账的周报红标"设计。
- 应用：台账四要素（发现-整改-期限-复查）逐条闭环；周报红标未销账项。
- 局限：长期整改项（预算类改造）单列"督办清单"——与可即改项分账管理。

**模型3：「专业检测让位专业机构」**
- 定义：电梯/锅炉/消防系统/电气检测有法定检测主体与周期——学校自查是日常巡查层，专业检测是法定层；AI不替代专业检测出技术结论。
- 依据：特种设备与消防检测法规；本技能边界条款。
- 应用：专业项在检查表中列"送检状态"栏（检测日期/下次到期）；到期前60天预警。
- 局限：日常巡查能发现专业项的外在异常（异响/渗漏）——发现即上报转专业，不停留在自查。

## 决策启发式

| # | 触发情况 | 动作 |
|---|---|---|
| H1 | 没说排查类型与范围 | 补问（消防/用电/建筑/综合×范围） |
| H2 | 发现立改级隐患 | 当日处置+当日复核——隔离管控是最低动作 |
| H3 | 专业设备异常征兆 | 上报并转专业机构——自查不停留不硬判 |
| H4 | 整改到期未完成 | 红标+升级总务/安全负责人——不静默延期 |
| H5 | 节假日/汛期前 | 出专项排查表（按季节风险点定制） |

## 检查点

🔴 **动手前**：排查类型、范围、频次确认。

🔴 **中途**：四领域检查表逐项（消防/用电/建筑/设施）；风险档逐项标注。

🔴 **交付前**：台账闭环率统计；未销账红标；专业项送检状态核对。

## 输出规范

- 四件输出：分领域检查表（四领域各一张，风险档标注）/隐患台账（发现日期-位置-描述-风险档-责任人-期限-复查结果）/整改通知单（问题描述-依据-期限-复查安排）/排查计划（日/周/月/节前专项）。
- 复查未通过项循环再整改（第二轮期限），连续两轮不过升级督办。

## 失败与异常处理

1. **信息不全**：补问类型与范围；按综合排查默认出。
2. **整改资源不足**（预算限制）：转"督办清单"+风险管控措施（隔离/警示）并行——整改不至、管控必达。
3. **专业检测到期**：提前60天预警转总务安排送检——不停在提醒层。
4. **超范围**（设施损坏维修）：转campus-patrol工单流程——隐患排查管"险"，设施巡查管"坏"。

## 边界

- **管**：四领域隐患检查表、隐患台账、整改流转、专项排查计划。
- **不管**：专业检测执行（法定机构）；设施维修工单（转campus-patrol）；安全教育（转safety-education）。
- **不替代**：安全负责人的现场判断——AI管表与流转，险情的临场处置在人。
- **接不住就转**：应急演练预案转 emergency-plan-drafting 口径。

## 分工说明

总务三查分工：本技能管"险了改"（隐患），campus-patrol管"坏了修"（设施），safety-education管"教了防"（教育）——发现的设施类问题转工单，设施巡查发现的险情转本台账。
