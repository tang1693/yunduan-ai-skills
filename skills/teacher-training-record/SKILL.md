# 教师培训记录 Skill · v2.0

## 一句话启动

打开就说「**记培训台账**」，不用先描述格式。

## 核心心智模型

**模型1：台账的效力=证据完备度**——一次培训是否"有效"，唯一标准是四件证据齐不齐（方案/课件/签到/总结）。证据链完备才计学时，"办了没留痕"按未开展处理。依据：继续教育学时认定的材料要求；职称评审中学时争议的裁定口径。应用：台账每条记录带"证据四件"核查列，缺件的标黄提醒补交。局限：线上培训的证据形态不同（平台学时截图/回放记录），单独口径。

**模型2：学时是教师的"职业信用"，错一个都伤人**——学时数字直接关系职称评审与继续教育达标，台账的每个数字必须逐笔可回溯（哪次培训/什么依据/谁确认）。依据：职称评审的追溯核查机制；学时误记引发的申诉成本极高。应用：学时统计逐笔生成明细，汇总数=明细求和，不做"估报"。局限：教师跨校调动时段的学时由原校与本校分段记录。

**模型3：培训的闭环在"返校转化"**——外出培训花的钱，价值兑现在返校后的二次分享与实践转化；只出去学不回来讲，是培训经费的最大浪费。依据：培训转化的"70-20-10"落地规律；教师培训经费绩效审计口径。应用：外出培训台账强制带"返校汇报要求"字段（报告/分享会/实践任务三选一），完成情况单独跟踪。局限：个人学历提升类进修不强制二次分享。

## 决策启发式

1. **四件证据不齐不算数**——方案/课件/签到/总结缺一不可；"下次补"的补件期限不超过两周。
2. **逐笔记、月度结**——培训当周入账，月度小结对账；学期末突击补台账的数字不可信。
3. **外出必回流**——外出培训的报销与返校汇报挂钩：先汇报后报销，倒逼转化。
4. **教研与培训分账**——教研活动（教研组内部）与培训（师资建设口径）分开建账，混账后两头数据都失真。
5. **缺口提前亮牌**——年度学时缺口在10月就标红提醒（还有两个月可补），不留到12月才发现。

## 执行规范

老师说"帮我记培训台账 / 汇总学时"即可。缺信息先问：校本培训还是外出培训、涉及哪些教师、什么时间段。信息齐了，做四样：

1. 校本培训台账：日期 / 主题 / 主讲人 / 形式 / 参加人员签到 / 学时 / 材料存档编号（方案+课件+签到+总结四件齐才算一次有效培训）。
2. 外出培训台账：教师 / 项目名称 / 主办单位 / 时间地点 / 费用 / 返校汇报要求（外出培训须提交学习报告或做二次分享）。
3. 学时统计：按教师逐人汇总年度学时（校本+外出+线上），对标继续教育要求，缺口标红提醒。
4. 教研活动记录：教研组 / 主题 / 主讲 / 过程要点 / 结论与后续——与培训台账分开建账。

## 检查点

🔴 **动手前**：确认台账用途（日常管理/学时申报/职称评审佐证）——用途决定颗粒度与佐证深度。

🔴 **中途**：每条记录的"证据四件"核查列必须逐条过——批量入账最容易出现"看起来都有"。

🔴 **交付前**：学时汇总与明细求和复核一遍——数字对不上是台账的死穴。

## 输出规范

- 四类台账表单字段齐全；学时统计逐人一页（年度累计/分类明细/缺口提示）。
- 外出培训单独出"返校汇报完成情况"跟踪表，与报销状态联动。
- 台账支持按学期/学年导出，格式对齐继续教育申报口径。

## 失败与异常处理

1. **历史台账证据缺失**：如实标注"证据不全"，不倒签补造；能联系到主讲的补课件，不能的标注说明。
2. **教师对学时有异议**：调出该教师逐笔明细当面核对——争议按"谁主张谁举证+台账为准"处理。
3. **线上培训学时认定模糊**：按平台官方学时证明认定，无证明的按实际学习时长×0.5折算并标注口径。
4. **跨校调动教师的学时衔接**：调入时段本校记、调出前时段由原校出具证明，分段合计。

## 边界与提醒

- 台账以签到和材料为准——"办了没留痕"的按未开展处理，不补签。
- 学时统计关系教师职称评审，数字必须逐笔可回溯。
- 个人培训经历（证书等）由教师本人保管，学校台账只记集体口径。
- **不替代**：继续教育管理平台的官方申报——台账是校内底账，平台申报按上级要求走。
- **接不住就转**：新教师系统培训方案转 new-teacher-training；师徒带教记录转 mentoring-program。
