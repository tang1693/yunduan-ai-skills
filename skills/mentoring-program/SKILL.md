# 青蓝工程 Skill · v2.0

## 一句话启动

打开就说「**安排青蓝结对**」，不用先描述格式。示例：「这学期 5 对师徒，物理组」——出结对协议 + 月度任务 + 期末考核表。

## 核心心智模型

**模型1：师徒关系的本质是"实践共同体"，不是课程传授**——新手教师最缺的不是知识（师范教育已给），是"在真实课堂里做判断"的实践智慧。师傅的价值是带徒弟进入教学实践共同体：怎么看学生、怎么临场取舍、怎么复盘。依据：Lave & Wenger 情境学习理论（合法的边缘性参与）；教师专业发展的实践性知识研究。应用：带教活动以"共同做事"为主（同备一课/同听一课/同析一次作业），讲授为辅。局限：学科本体知识确实薄弱的徒弟，需补学科研修，不靠带教解决。

**模型2：成长证据链胜过终结性表演**——一节汇报课定优劣是失真的；真实的成长记录在过程里：听了多少课、磨了几轮、反思写了多少篇。依据：过程性评价理念；"汇报课漂亮日常课照旧"的普遍现象。应用：出师考核四项合成（汇报课评分+资料完备度+徒弟自评+师傅鉴定），过程证据占大头。局限：汇报课仍是必要项——出得不了公开课的带教不算完整。

**模型3：配对即机制设计**——好师徒不是随机分配的：同学科（有共同话语）、跨年级（避免同备课组的评价竞争与保留）、风格兼容（师傅善表达、徒弟能接受）。依据：师徒制的匹配研究；"同组竞争"导致师傅留一手的教训。应用：配对方案给出原则+候选对名单，双方见面确认后再定。局限：小学科（全校一人）只能跨校结对，走区域师训渠道。

## 决策启发式

1. **先听课后上课**——第1月徒弟听师傅（每周≥2节）比急着上汇报课重要：先看懂再做。
2. **磨课磨三轮起**——一轮是修改不是磨课；三轮（说课-试讲-复盘）才能磨出风格。
3. **师傅书面意见每月至少一次**——口头意见随风散，书面意见进成长档案。
4. **徒弟反思月度一篇，写具体不写感想**——"本月在作业设计上学到X，我试了Y，学生反应Z"式反思才有积累价值。
5. **延长带教不是惩罚**——如实记录短板与原因，第二年少走弯路；把"延长"污名化的学校带不出信任。

## 执行规范

老师说"帮我安排师徒结对"即可。缺信息先问：几对师徒、什么学科、带教周期。信息齐了，做四样：

1. 结对方案：师徒配对原则（同学科/跨年级优先，避免同备课组直接竞争关系）+ 结对协议（双方职责/带教目标/周期）。
2. 带教计划：按学期分段——第1月随堂听课（每周≥2节）/第2-3月上汇报课（师傅指导磨课≥3轮）/第4月起独立公开课；师傅听徒弟课每周≥1节并留书面意见。
3. 过程记录：听课记录 / 磨课记录 / 师傅指导意见 / 徒弟成长反思（月度一篇）。
4. 出师考核：汇报课评分（教学目标/过程/效果三维）+ 资料完备度 + 徒弟自评 + 师傅鉴定四项合成，考核结果分优秀/合格/延长带教三档。

## 检查点

🔴 **动手前**：确认师徒名单与配对原则的约束（同学科/跨年级），有特殊关系的（亲属/评价利益冲突）调整配对。

🔴 **中途**：过程记录按月归档提醒——学期末补记录的档案没有证据价值。

🔴 **交付前**：考核方案四项权重写明，过程证据（听课/磨课/反思）合计不低于50%。

## 输出规范

- 结对协议/带教计划/记录表单/考核表四件套齐全，可直接打印签字。
- 月度任务单一张纸：本月做什么、留什么证据、下次交流时间。
- 考核结果三档（优秀/合格/延长带教）附证据清单，不搞单一分数。

## 失败与异常处理

1. **师徒关系失和**：先由科研处/教务处了解原因，可调整配对（学期中允许一次）；关系修复优先于带教进度。
2. **师傅忙不过来（毕业班/行政兼职）**：降级为"双师傅制"（一位主讲教学、一位专管班会管理），分担压力不中断带教。
3. **徒弟成长快于预期**：提前出师走简化考核（过程证据齐全即可），师傅转为科研带教（论文/课题方向）。
4. **全校同学科仅一人的小学科**：跨校结对或区域教研结对，本技能出"外部结对协议"变体。

## 边界与提醒

- 配对结果需双方确认，强扭的师徒带不出真东西。
- 考核重在成长证据链（听课节数/磨课轮次/反思篇数），不搞一次性表演课定优劣。
- 延长带教不等于不合格——如实记录原因，第二年重点补短板。
- **不替代**：师傅的真实投入——AI 管方案、记录与考核框架，师傅的时间与用心没人能替代。
- **接不住就转**：新教师系统性入职培训转 new-teacher-training；培训学时台账转 teacher-training-record。
