# 小鲲学堂·小初衔接

> 初一的台阶不在知识多难，在「换了一种学法」——六年级这一年，先迈半步。

## 开始前：最少准备

说明六年级本次需要、实际教材版本及目录、已有去标识作答。教材和数据未知时先给轻量体验与观察表，不假定章序、不虚构摸底结果；不要为了生成方案重新填已有信息。

默认面向教师备课与组织支持，学生接触的材料须经教师核对。文中人数、分组和时长是本校方案示例，按实际情境调整；S级为作者原有自评，不是本轮教师试用结论。引用其他Skill表示可选协作，不代表客户端已经安装或能够自动调用；缺少时在当前对话给可编辑表或步骤，说明未完成部分。

[中文使用卡、完整示例与失败处理](references/中文使用卡.md)。首次先给一小段候选，教师满意再展开；已给材料不重复询问。

## 一句话启动

打开就说「**小初衔接**」。示例：「六年级 30 个学生，做衔接规划」——AI 先摸底三科，再出个性化衔接计划 + 三大坎诊断。

## 三大坎（衔接期真正要过的）

| 坎 | 小学怎么想 | 初中要变成 | 怎么练 |
|---|---|---|---|
| **字母表示数** | 算的是具体的数 | 字母是「可以代表任何数」的变量 | 从「一个数不知道，先用 □ 顶着」过渡到 x；用面积公式（a×b）做第一课 |
| **方程思维** | 从已知算未知（顺着算） | 设未知数、找等量关系（倒着建） | 天平图起步：左边放什么右边放什么才平 |
| **负数** | 数从小往大、减法不能不够减 | 数轴双向、减法永远可以 | 电梯楼层（地下车库）做第一课，先有方向感再谈运算 |

三坎没过，初一的第一次月考崩的不是「难」，是「听不懂老师在说什么」。

## 工作流程

1. **摸底**（开学初）：三科各出 8 道诊断题——数学重点扫三坎，语文扫阅读速度与概括（初一说明文起步），英语扫词汇量与音标；出具体任务支持表（本次独立完成/提示后完成/待再观察；非学生类型）；
2. **个性化路线**：按摸底结果给每人一份「初一预备路线」——立足初一教材前两章（须读取实际教材目录，不预设章名、章序或版本），按具体任务证据选择补先备知识或进一步探究，由教师决定；
3. **周节奏模拟**：每周一次「初中的一天」——按 45 分钟课时坐得住、三科作业轮转（小学是单科做完再玩）、自己记作业本不用家长转述；
4. **月度复诊**：每月一次三坎小测（各 4 题），进步/退步都记入档案；六年级下学期把模拟频率提到每周两次；
5. **家长同步**：每月一段话同步（孩子过了哪坎、还差哪坎、家里怎么帮一句）——不制造焦虑，只报进度。

## 核心心智模型

**模型1：「衔接的台阶是学法，不是知识」**
- 定义：初一第一年的崩点不在知识变难，在"换了一种学法"——科目从3科变7科、老师从1个变7个、学习从"盯着学"变"自己学"。衔接课练的是学法预演，不是提前抢跑。
- 依据：本技能"三大坎"诊断框架；初一首次月考崩盘学生的共性归因（听不懂的不是内容，是组织方式）。
- 应用：所有衔接活动过一道筛——这个动作在练"学法"还是在抢"进度"？抢进度的砍掉（每天不超过30分钟的加餐红线）。
- 局限：家长普遍把衔接理解为提前学——用模型2的坎诊断数据说话，不用道理说服。

**模型2：「三坎是分水岭，逐坎过不齐推」**
- 定义：字母表示数/方程思维/负数三大坎各自独立、各有心理机制——算术思维的孩子把字母当"未知谜底"，代数思维把字母当"可运算的对象"。一次只推一个坎，三坎齐推等于都没推。
- 依据：初中数学教育研究的"算术-代数过渡"共识；本技能三大坎教案（天平图/面积公式/电梯楼层三个第一课的设计逻辑）。
- 应用：摸底后每人锁定本月主攻坎（一个坎的一个侧面）；月底没过的坎下月继续，不换目标。
- 局限：语文英语的坎（阅读速度/词汇量）同样真实——三科并行摸底但每月只推一个主坎，轮换制。

**模型3：「不制造焦虑的进度同步」**
- 定义：家长同步只用事实语言——"过了哪坎/还差哪坎/家里怎么帮一句"，禁用"落后/跟不上/别人家已经"这类定性词。
- 依据：本技能家长话术三版（进步/持平/退步）的设计；退步版必须含一句"具体怎么帮"。
- 应用：每月一段话同步，配家庭配合动作一条；话术生成后过"定性词黑名单"再发。
- 局限：真需要干预的滞后（如运算障碍迹象）要另走面谈，不靠月度同步传递。

## 决策启发式

| # | 触发情况 | 动作 |
|---|---|---|
| H1 | 家长要求"多刷题加速衔接" | 给坎诊断数据——三坎没过刷题无效（字都认不全刷什么），过了坎再上量 |
| H2 | 学生已自学完初一内容 | 路线改"初一纵深"——往前走的同时做小升初总复习双线，不原地等 |
| H3 | 摸底数据缺失 | 先摸底再规划，不按年龄猜坎——具体任务支持表（本次独立完成/提示后完成/待再观察；非学生类型）是分组依据 |
| H4 | 六上就要模拟初中节奏 | 轻量试——45分钟课时先试，作业轮转放下学期，一次只改一个变量 |
| H5 | 三科坎同时亮红灯 | 按坎的严重度排序，本月只推最狠的一个，其余进观察名单 |

## 输出规范

- 摸底卷3张（各8题、30分钟内）+ 具体任务支持表（本次独立完成/提示后完成/待再观察；非学生类型）。
- 个人衔接计划一页：现状 / 本月目标（限一个坎的一个侧面）/ 教材对应章节 / 家庭配合一句话。
- 三坎教案骨架各一份（天平图/面积公式/电梯楼层三个第一课），可直接上课。
- 家长同步话术三版（进步/持平/退步），退步版必含"具体怎么帮"一句；全部过定性词黑名单。

## 检查点

🔴 **动手前**：制定章节路线或个体计划时核对实际教材目录与作答；材料未知仍可给轻量体验草案，章序、个体判断留待确认。

🔴 **中途**：本月主攻坎唯一——出现"三坎齐推"的计划立即砍成单坎；月底没过的坎不换目标继续推。

🔴 **交付前**：家长话术零定性词复核；个人计划的目标句能答"这个坎的哪个侧面"。

## 失败与异常处理

1. **坎诊断与教师直觉冲突**：核对题目、作答、提示条件和教师观察，冲突时保留两种解释并再观察；单题或小样本不能认定稳定错因。
2. **学生抗拒"预备学习"**（觉得是加作业）：把包装换成"初中的一天"体验制——节奏模拟做成闯关，坎训练藏在里面。
3. **家长拿别人家进度施压**：亮双底线——加餐每天不超30分钟（保护六年级本体课程）；坎没过刷题无效（数据说话）。
4. **小升初政策变动**（对口调整/分班考变化）：衔接主线不变，模拟频率与侧重点按新政策微调，不推倒重来。

## 边界

- **管**：摸底、三坎诊断与教案、个性化路线、节奏模拟、家长同步。
- **不管**：初中校的教学进度对接（开学后由初一教师接手）；分班考训练。
- **不替代**：六年级本身的国家课程——衔接是加餐不是替代，每天不超过30分钟红线。
- **接不住就转**：要初中完整备考，转 zhongkao-hub；学习习惯问题，转 学生自主学习力培养教练；思辨表达课（六年级口语交际"表达观点/倾听不同意见"正好对接）转 fuyao-conundrum·**扶摇版层**（6-8 年级标准层：完整四步作答，中英对照）。

## 分工说明

与 zhongkao-hub（中考入口）的关系：本技能管六年级的"迈半步"，zhongkao-hub 管初三的"冲刺跑"——中间七八年级的常态教学不归两者管。
