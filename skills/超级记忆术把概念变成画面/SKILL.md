# 超级记忆术 v2.0

> 把概念变成画面——抽象的东西记不住，画面化的东西忘不掉。

## 执行规范

学生说"帮我记住 XX"即可。缺信息先问：记什么内容。信息齐了，用"地点-角色-动作"编码，输出三样：

1. 画面：把抽象信息转成夸张、生动的画面
2. 联想故事：给一小段串起来的记忆故事
3. 复习提示词：几个能勾起画面的关键词

**学段适配**：低段内容限制在 3-5 项以内（画面联想尤其有效）；高段用于背古诗、词语解释、省份简称；初中用于公式、历史年代、化学元素等高密度记忆。

## 核心心智模型

**模型1：「画面是记忆的母语」**
- 定义：大脑对图像的记忆效率远超文字——"地点-角色-动作"编码把抽象信息（公式/年代/词语）转译成生动画面，记忆从"背字符串"变成"看电影"。
- 依据：双重编码理论（Paivio）；记忆宫殿方法的通俗化转译；本技能定位"抽象的东西记不住，画面化的东西忘不掉"。
- 应用：每个记忆项必配画面（夸张/荒诞/动态优先）；画面生成后让学生闭眼"放映"一遍。
- 局限：画面编码不替代理解——先懂再记是前提（边界条款），死记的画面没有意义。

**模型2：「越离谱越好记——荒诞是粘合剂」**
- 定义：平淡的画面与日常记忆混在一起被遗忘；夸张荒诞的画面（会飞的鱼/说话的沙发）制造记忆的"凸起"，凸起才能被检索到。
- 依据：奇异效应（bizarreness effect）研究；本技能边界"越夸张越荒诞越好记——别怕离谱，就怕平淡"。
- 应用：画面生成遵守"离谱度"标准；串联故事允许逻辑跳跃，只要画面链不断。
- 局限：低段孩子天然产出荒诞画面（这是优势）；高段初期羞于荒诞——给"科学依据"说明降低心理阻抗。

**模型3：「关键词是放映的遥控器」**
- 定义：画面记住了还需要"调取开关"——复习提示词（3-5个关键词）是触发画面重映的线索；没有线索的画面是存了取不出的存款。
- 依据：提取线索（retrieval cue）原理；本技能三件输出之"复习提示词"。
- 应用：每个记忆组配3-5个提示词；复习法=看词→闭眼放画面→对照检查。
- 局限：提示词与画面的联结需要一次成功提取来固化——首日复习必做。

## 决策启发式

| # | 触发情况 | 动作 |
|---|---|---|
| H1 | 没说记什么 | 补问内容与学段——内容类型决定编码方式 |
| H2 | 学生对概念本身不理解 | 先停下——先懂再记（转费曼学习法讲懂），回头再编码 |
| H3 | 低段内容多 | 限3-5项以内——低段画面容量小，宁分批 |
| H4 | 高段嫌"幼稚" | 给出双重编码的科学说明+学术风格画面（不用卡通） |
| H5 | 记了三天就忘 | 检查提示词联结——首日是否做过"看词放画"提取练习 |

## 检查点

🔴 **动手前**：内容、学段确认；"先懂再记"前提核对。

🔴 **中途**：画面含"地点-角色-动作"三要素；离谱度达标（非平淡描述）。

🔴 **交付前**：联想故事画面链完整；提示词3-5个可独立触发画面。

## 输出规范

- 三件输出：画面（每项一景，夸张/动态/具体）/联想故事（串联画面的一小段，允许荒诞）/复习提示词（3-5个）。
- 附首日复习法：看词→闭眼放画→对照补漏；学段适配标注（低段卡通化/初中知识密度版）。

## 失败与异常处理

1. **信息不全**：补问内容与学段；按内容类型默认出示例版。
2. **内容不适合画面化**（纯逻辑关系）：如实说明，建议图表化（转康奈尔笔记结构整理）。
3. **学生画面感弱**：从"最熟悉的地方"（自己房间/上学路）起步建画面——地点锚定降低门槛。
4. **超范围**（理解性学习）：转费曼学习法——记忆术管"存得牢"，不管"想得通"。

## 边界

- **管**：抽象内容的画面编码、联想故事、复习提示词、首日复习法。
- **不管**：概念理解（转费曼学习法）；笔记结构（转康奈尔）；专注管理（转番茄）。
- **不替代**：理解——记忆术是辅助，先懂再记是铁前提。
- **接不住就转**：理解障碍转 费曼学习法。

## 分工说明

学习法五件套中本技能管"记得牢"（编码存储）——与费曼（讲明白=理解检验）、康奈尔（记结构）、番茄（专注）、西蒙（拆目标）组合；低段优先推荐本技能（画面天然优势）。
