# 一次对话，完成一份待教师复核的试卷

说：“出一份七年级数学有理数小测，20分钟，满分30分，附答案与评分点。”
本方法自含蓝图、命题与检查步骤；不要求安装资源搜索、审题Skill或artifact_save工具。

## 必要输入与停止条件

先从老师的话里提取学科年级、教材版本与章节/知识范围、时长、总分和用途；只问缺的关键项，一次最多两问。
范围未确认不生成整卷；教师可提供教材片段或自有题目。没有材料时先出“范围待核对”的蓝图，不编造教材页码。
不读取学生身份信息，不根据成绩给学生贴标签，不代替考试组织者确定制度或考试安排。

## 两种路径

- 小测快速版：确认范围后，给简短蓝图与3—5道题的候选，附答案和分值；老师可直接要求调整。
- 整卷标准版：确认蓝图后分批出题，完成整卷、答案、评分点和复核记录。需要时再展开变式或答题区。
不把阅卷、成绩分析与讲评强行加入每一次命题；老师要做这些后续任务时，使用本次已确认的题号与评分点继续。

## 标准工作流

1. **蓝图**：知识点×题型×分值×思维要求；核对题目数、总分、覆盖与预计作答时长。难度仅是设计预估，不冒充实测。
2. **教师确认**：展示少量需选择的内容，如“计算与解释各占多少”“是否包含未学内容”；老师确认后出卷，日常小测可在同次回复附候选。
3. **命题**：依蓝图生成清晰题干、完整条件和图表说明。新编题标“AI候选”；引入已有题须有授权与来源，不声称原创。
4. **解题复核**：重新求解每题，对照答案、量纲、条件、分值、唯一性或开放评分维度。自检是同一AI的检查，不叫独立审题。
5. **缺陷处理**：发现条件不足、答案冲突或无法核实的事实，把题撤出候选并给替换题；记录改动，不带病凑满题数。
6. **教师定稿**：输出学生卷、教师答案与评分点、蓝图、待复核清单；教师决定采用/修改/删除，不自动发布或发送给学生。

## 能力与缺失时的做法

| 能力 | 本包状态 | 无此能力时 |
|---|---|---|
| 蓝图、原创候选题、答案与可编辑文本 | 对话内完成，不依赖其他Skill | AI无法正确解答的题标待核对并撤换 |
| 外部资源搜索 | 可选，本包不附搜索工具 | 使用教师给定材料；不填虚构链接，不承诺搜到最新题库 |
| 独立审题 | 可选，需另一位教师或独立执行者 | 明确“仅AI自检、待教师审题”，不能标通过独立复核 |
| DOCX/PDF/ZIP保存 | 取决于客户端实际文件能力 | 输出分区文本及答题区示意，供复制；不得虚构下载按钮/保存成功 |
| edu-blueprint/edu-exam-gen | 可选择安装的深化方法 | 当前包直接完成，不自动调用或要求切换 |

## 可编辑交付模板

```text
标题/版本/范围/时长/满分/用途：
依据与缺项：
蓝图：题号｜知识点｜题型｜分值｜预计时间｜检查什么
学生卷：仅题干与答题区
教师稿：题号｜答案/示例｜推理｜评分点｜其他合理答案
检查记录：总分/用时/范围/条件/解答/图表/来源
尚待教师复核：
教师选择：采用 / 修改第__题 / 删除 / 暂不使用
```

## 示例：完整小测稿（虚构样例，非学业效果证据）

输入：七年级数学有理数，10分钟，10分，仅核对运算与解释，不含新授内容。
蓝图：第1题加法2分；第2题乘法2分；第3题混合运算3分；第4题解释符号3分。预计2+2+3+3分钟。
学生卷：①计算(-3)+5；②计算(-2)×(-4)；③计算6-2×(-3)；④判断“负数相加一定是负数”，举例说明。
教师稿：①2，结果2分；②8，结果2分；③12，先算乘法得-6计1分，再算6-(-6)=12计2分；
④结论正确1分，如(-2)+(-3)=-5计1分，说明两负数相加绝对值相加、符号仍负计1分；其他正确说明可同等计分。
自检：2+2+3+3=10分；第三题未混入未学运算；第四题的概括需要教师核对班级已学表述；不宣称难度适合所有班。
教师可说“第4题改成纠错题”，仅替换第4题及其评分点，蓝图对应更新。

## 失败案例与纠正

失败：题干是“一个三角形两边3、4，求面积”，却直接给6。
纠正：条件不足，不能默认为直角。撤下原题；请教师选补充夹角条件或改成“互相垂直的两边3、4”，同步重算答案与评分。
若题意、版权或学科事实仍存疑，标“未定稿”，宁可少一题，也不伪造工具复核或来源。
