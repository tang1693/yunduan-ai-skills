# 扶摇阁·第一性原理工作坊

> 拔尖的标志不是解难题快，是敢问「为什么非得这样」——然后把它拆了重来。

## 开始前：最少准备

说清年级、可用时间、要重设计的熟悉对象及已知限制。未提供时只追问影响本次设计的缺项；默认给一份教师可修改的五步课堂草案，不代替学生交提案。

默认面向教师备课与组织支持，学生接触的材料须经教师核对。文中人数、分组和时长是本校方案示例，按实际情境调整；S级为作者原有自评，不是本轮教师试用结论。引用其他Skill表示可选协作，不代表客户端已经安装或能够自动调用；缺少时在当前对话给可编辑表或步骤，说明未完成部分。

[中文使用卡、完整示例与失败处理](references/中文使用卡.md)。首次先给一小段候选，教师满意再展开；已给材料不重复询问。

## 一句话启动

打开就说「**重新设计一个东西**」。示例：「重新设计考试」——AI 按五步法带学生拆解重组，产出一份重设计提案。

## 五步法

1. **质疑默认**：这个东西为什么是现在这样？列出 3 条「大家都习惯了但说不清为什么」的默认设定（考试=闭卷 90 分钟、铃声=45 分钟一节）；
2. **拆到要素**：把它拆成不可再拆的基本要素——考试的真实目的（证明学会了？筛选？反馈？）、考试的物理形式（纸笔？限时？单人？），要素列到 5-8 个为止；
3. **追问目的**：每个要素问「它是为目的服务，还是只是历史习惯？」——标记出来，这一步最慢也最值钱；
4. **重组方案**：保留服务目的的要素，替换或删除只是习惯的——拼出一个新版本（「考试的目的是反馈，那么形式可以是：学完立刻互评，不用等一周」）；
5. **限制检验**：新方案撞上现实限制（公平性？家长接受？制度？）会怎样？每条限制给一个应对或妥协——没有这一步，重设计只是空想。

## 选题库（贴近学生生活）

- 校内：课程表 / 考试 / 作业 / 班级值日 / 校服 / 图书馆
- 身边：书包 / 自行车 / 城市公交站 / 快递包装
- 大胆些：学校本身（作为课堂设计练习，不代表现实学校已采用）/ 假期 / 金钱
- 教师可自定义任何主题，AI 按五步法生成脚手架

## 课堂流程（90 分钟工作坊，10 人小班）

- **选对象**（10 分）：从选题库挑或自报；一人一票，票数并列时教师定；
- **分组拆解**（30 分）：2-3 人一组过步骤 1-3，AI 供「追问清单」（这个要素删了会怎样？谁受益？谁受损？）；
- **重组提案**（30 分）：各组画出/写出新版本，海报一页；
- **提案答辩**（15 分）：组间互评，每组必须提一个「限制检验」问题；
- **归档**（5 分）：提案拍照存档；学年末编成《扶摇阁重设计年鉴》——六年级的提案到八年级时真的被学校采纳一条，就是这门课最好的成绩单。

## 核心心智模型

**模型1：「习惯 ≠ 目的」**
- 定义：任何习以为常的设计都由两类要素构成——服务真实目的的，和纯粹历史习惯的。第一性原理思维的核心动作就是把这两类分开。
- 依据：作者对第一性原理的教学转译；本轮未提供外部学校实践频次的原始证明。
- 应用：步骤3（追问目的）是全流程的分水岭——每个保留的要素必须说得出"它服务什么目的"，说不出就是习惯，进入替换候选。
- 局限：有些"习惯"实为隐性规范（如45分钟课时暗含注意力规律），删除前要在限制检验里撞一次墙再定。

**模型2：「拆到不可再拆为止」**
- 定义：要素拆解的深度标准是"再拆下去就变成另一个东西了"——考试拆到"证明学会了/筛选/反馈"三个目的即止，再拆就成了心理学。
- 应用：5-8个要素是经验区间；拆不出要素说明对象还太抽象，先用"物理拆解法"（想象成乐高一块块摆开）降维。
- 局限：低年级拆解粒度天然粗，正常——拆到他们能动手重组的粒度就是到位。

**模型3：「没撞过墙的重设计是空想」**
- 定义：重组方案必须经过限制检验（公平性/家长接受/制度/成本），每条限制给应对或妥协——这一步把"聪明点子"和"可用方案"分开。
- 依据：本技能检查点"没有应对现实的方案不归档"；年鉴采纳记录尚未随包提供；限制检验是待试用的方法建议，不是已有采纳成效证明。
- 应用：答辩互评环节每组必须提一个限制检验问题——这个设计逼着提案者提前想墙在哪。
- 局限：6-8年级的限制分析深度有限，教师提供限制清单供选择即可，不要求穷举。

## 决策启发式

| # | 触发情况 | 动作 |
|---|---|---|
| H1 | 学生跳过追问直接重组 | 退回来：每个保留要素说一句"它服务什么目的"，说不出的进替换候选 |
| H2 | 重组方案=恶搞（"取消考试天天玩"） | 不否定，走限制检验让它自己撞墙——撞完改的版本就是学习本身 |
| H3 | 学生说"拆不下去了" | 给"物理拆解"降维——想象成乐高一块块拆开摆桌上 |
| H4 | 教师不熟悉此方法 | 先用"考试"跑一遍教师版（AI陪练10分钟）再上课 |
| H5 | 提案想直接做成真产品 | 转出——原型/网页制作属 高阶能力项目设计师，本技能管思维脚手架 |

## 输出规范

- 五步脚手架表一张：步骤 / 学生要写什么 / 追问提示，一页。
- 提案模板五栏：对象 / 三个默认设定 / 要素拆解表（要素-目的-习惯？）/ 新方案 / 限制与应对。
- 答辩互评单：每组的"限制检验"问题 + 被评组回应，一页。
- 追问清单10条（要素删了会怎样/谁受益/谁受损/一直如此就对吗…），供步骤3卡壳时用。

## 检查点

🔴 **动手前**：确认对象是学生真熟悉的——陌生对象（央行/联合国）先换掉，拆不动的对象出不来好课。

🔴 **中途**：步骤3是分水岭——追问没做够就重组的，退回；每个保留要素挂一句目的。

🔴 **交付前**：提案有限制检验栏且每条限制有应对——没有应对的方案不归档，改完再交。

## 失败与异常处理

1. **全班选题撞车**：同对象不同组反而是好事——期末对比两份重组方案，差异本身就是教材。
2. **拆解停在表面**（只会列"有老师有学生有课桌"）：追问"没有它会怎样"逼出功能层——课桌的目的不是存在，是"写下/看见"。
3. **限制检验全过、方案完美**：警惕——大概率限制找少了，教师补一条最硬的限制（预算/法律）再检一次。
4. **学生提案被学校真采纳**：进年鉴归档，注明采纳环节——这是本课程最好的成绩单，也是下一届的动员材料。

## 边界

- **管**：五步脚手架、选题库、提案模板、答辩互评、年鉴归档、教师陪练。
- **不管**：提案是否真被学校采纳——决策在校级行政；原型制作——转 高阶能力项目设计师。
- **不替代**：学生的想象力——AI给脚手架不给答案，拆解与重组必须学生自己完成。
- **接不住就转**：团队模拟经营类，转 fuyao-synthesis。

## 分工说明

与 conundrum（开放难题/思辨）互补：本技能管"拆了重建"的设计思维，conundrum 管"没有对错"的立场思辨；两者共用扶摇阁小班档案。
