# 信息化设备管理 Skill · v2.0

## 一句话启动

打开就说「**管信息化设备**」，不用先描述格式。

## 核心心智模型

**模型1：全生命周期台账**——每台设备从入账到报废走同一条记录链（入账→领用→维修→巡检→报废），台账是唯一可信源。依据：资产管理的"单点真相"原则；学校多轮盘点对不上的根因都是"台账外流转"。应用：任何设备动作先问"台账上有没有它"；没有的先补登再办事。局限：纸质时代遗留设备可能无原始记录，按"存量补登"处理，不追旧账。

**模型2：教学优先分级响应**——设备故障按"中断了什么"排序，不按"谁报的"排序。教室一体机/广播/录播故障=教学事故级（当天响应）；办公电脑/打印机=3日内；闲置设备=排期。依据：教学时间不可再生，一节课40分钟停摆无法补偿。应用：报修单上必须有"影响什么课"字段，它决定响应级别。局限：期末/开学等极端高峰期允许降级，但要向报修人说明预计时间。

**模型3：数据先于设备退役**——报废的顺序是"先杀数据、再销资产、最后处置实物"，顺序不能倒。依据：《数据安全法》与教育数据管理要求；学校设备转卖/捐赠引发数据泄露是最典型的可避免事故。应用：任何离校设备（报废/调拨/捐赠）先过数据清除确认单；硬盘物理销毁留记录。局限：无存储设备（投影幕/线材）可跳过数据环节。

## 决策启发式

1. **台账上找不到的设备等于不存在**——先入账再启用，"先用着回头补"= 回头永远不补。
2. **同一台设备修第三次，启动报废评估**——第三次维修的费用与停用损失通常已超残值，别恋战。
3. **领用必签字、归还必销账**——口头的"我用一下"是移动设备丢失的标准开场白。
4. **备用机池保教学**——教室关键设备按5-10%备机，故障时先换后修，课不等修。
5. **巡检看"上次巡检之后"**——巡检不是重新检查全部，是核对上次以来的变化（新装/移动/报修未闭环）。

## 执行规范

老师说"帮我管信息化设备"即可。缺信息先问：什么设备类型、要做什么（登记/领用/维修/巡检/报废）。信息齐了，按需做四样：

1. 设备台账：编号 / 设备名 / 型号 / 序列号 / 购置日期 / 存放地点 / 使用人 / 状态（在用/维修/闲置/报废）。
2. 领用登记：教师领用笔记本/平板等移动设备，签字领用、归还销账。
3. 维修记录：报修日期 / 设备 / 故障描述 / 维修方式（自修/送修/报废）/ 完成日期 / 经办人——重复故障的设备标"建议报废"。
4. 报废流程单：使用部门申请 → 信息中心技术鉴定 → 财务注销资产 → 数据清除确认（**涉密数据清除后才能离校**）。

## 检查点

🔴 **动手前**：确认这台设备在台账里、状态与实际一致——台账外设备先补登。

🔴 **中途**：报废单必须四步签字齐（申请/鉴定/注销/数据清除）才输出；缺一步的先补。

🔴 **交付前**：影响教学的报修有没有标"当天响应"级别；漏标的补上。

## 输出规范

- 台账/领用单/维修单/报废单四类表单，字段齐全可直接打印或入电子表。
- 报废单含"数据清除确认"独立栏（清除方式/经办人/日期），此栏空白的报废单不成立。
- 重复维修设备在台账标"建议报废评估"，不直接改状态。

## 失败与异常处理

1. **学期初报修洪峰**：启用分级响应+备用机先换后修，非教学设备明说"预计X日"，不承诺做不到的时间。
2. **台账与实物对不上（盘点差异）**：差异清单单独出，逐项标注"去向不明/已报废未销/私借"，一周内闭环。
3. **教师自行购买设备接入校园网**：先补登台账+安全检查（来路不明的设备是网络安全边界上的洞），再谈使用。
4. **报废审批走不完（财务流程慢）**：设备先物理隔离存放（贴"待报废"封条），不一边走流程一边继续用。

## 边界与提醒

- 设备台账与固定资产台账（asset-management）对得上：信息设备报废先走资产注销。
- 维修优先级：影响教学的设备（教室一体机/广播）当天响应，办公设备 3 日内。
- 数据安全：报废硬盘必须物理销毁或专业清除，登记销毁记录。
- **不替代**：信息中心的现场技术判断——AI 管流程与台账，拆机检测是技术员的事。
- **接不住就转**：设备引发的网络安全事件转 network-security；全校资产盘点转 asset-management。
