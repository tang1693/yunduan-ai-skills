# 午餐午休 Skill · v2.0

## 一句话启动

打开就说「**排午餐午休**」，不用先描述格式。

## 核心心智模型

**模型1：人数是配餐的钱，准确率就是成本**——就餐人数统计偏差1%，一学期就是几百份餐的浪费或短缺。人数统计的准确率直接等于配餐成本的控制力。依据：配餐行业的按需生产逻辑；学校"报了不吃、吃了没报"的双向浪费现象。应用：就餐登记以月为周期固化（月度固定+临时增减），避免每日重新登记的漂移；配餐量=固定人数+临时增报-请假扣减，三步可核算。局限：开学首月人数波动大，按周调整。

**模型2：午休巡查是安全值守，不是纪律检查**——午休时段是校园安全管理的相对盲区（教师午餐轮值、学生集中休息），巡查的第一目标是异常发现（身体不适/情绪异常/安全隐患），纪律只是顺带。依据：校园安全网格化管理要求；午休时段突发事件的通报教训。应用：巡查记录以"异常事件"为核心字段，正常巡视留痕一句话即可，异常单独成条。局限：寄宿制学校的夜间巡查另行规范，不混用本表。

**模型3：餐费月结清、家长月度对账单**——餐费按月结算、当月公示明细，家长看到的不是"扣了多少钱"而是"吃了几次餐"。依据：中小学课后服务与餐费管理的公开透明要求；餐费纠纷的共性是"糊涂账"。应用：月度报表按学生出"就餐次数×单价=应缴"明细，请假未就餐的退费单独列示。局限：第三方配餐公司的结算口径以合同为准。

## 决策启发式

1. **固定人数月度固化，临时变化走增减单**——每天从零统计人数必然漂移，锚定基数只管变化量。
2. **配餐量宁少半份不多一份**——短缺可应急补，剩餐就是纯浪费；按95%峰值备餐留应急余量。
3. **巡查两次定频：午休开始10分钟+结束前10分钟**——头尾两巡覆盖入睡与起床两个异常高发窗口。
4. **餐费报表按学生出明细，不按班级出总数**——家长对账的是自己孩子的就餐次数，不是班级平均。
5. **食品留样与就餐登记联动**——同批次留样（125g/48小时）与当日就餐人数登记同表归档，出事能对上。

## 执行规范

老师说"帮我排午餐午休/统计就餐人数"即可。缺信息先问：哪个环节（就餐登记/配餐统计/餐费月结/午休巡查）、覆盖范围（年级/班级）。信息齐了，按需做四样：

1. 就餐登记表：班级 / 学生 / 固定就餐（月度）/ 临时增减 / 当日实就餐——月度固化+日变动。
2. 配餐统计：各班人数汇总 / 配餐量建议（含余量策略）/ 特殊餐（过敏/清真）单独列。
3. 餐费月报：学生 / 就餐次数 / 单价 / 应缴 / 请假退费——按学生明细，班级汇总附后。
4. 午休巡查记录：日期 / 时段（开始10分钟/结束前10分钟）/ 巡查人 / 异常事件（无异常一句话留痕）/ 处置与移交。

## 检查点

🔴 **动手前**：确认是月度固化登记还是临时变动处理——口径不同，表不一样。

🔴 **中途**：特殊餐需求（过敏/清真/忌口）必须单独成列，混在总人数里就是安全隐患。

🔴 **交付前**：餐费报表的请假退费栏逐条核对考勤依据——退错钱比收错钱更伤信任。

## 输出规范

- 四类表单字段齐全可直接打印或入电子表；就餐登记支持班级班主任直填。
- 配餐建议带"余量说明"（按95%峰值+应急补餐预案），不是光秃秃一个数。
- 月度餐费报表一页汇总+学生明细附表，公示版隐去学生姓名只留次数与金额。

## 失败与异常处理

1. **学生中途加入/退出**：临时增减单当周生效，餐费按实际天数折算——月底统一对账，不日结。
2. **配餐公司送餐量不符**：当日登记差异（送餐量vs登记人数），连续一周差异超3%触发合同交涉，记录归档。
3. **午休发现学生身体异常**：巡查记录异常条目立即移交校医与班主任——本技能只管记录与移交，处置转 medical 流程。
4. **家长质疑餐费**：调出该生当月就餐明细（次数×单价），一次说清；系统性质疑触发家长代表开放日。

## 边界与提醒

- 食品安全与留样的专业管理转 cafeteria-management，本技能管"人数-配餐-餐费-巡查"的流转。
- 餐费定价与退费政策以学校公示标准为准，AI 不建议定价。
- **不替代**：班主任与午休值班教师的现场职责——记录是管理工具，照看学生是人的事。
- **接不住就转**：食品卫生与留样转 cafeteria-management；学生请假数据核对转 student-attendance。
